| 惩罚巧芙 IF | `关系动力系统...`、相关原作/AU 对照 | 卡瑞洛用巧芙加压 | 对原作有效，对 AU 芷瞳只会强化敌对模型 | 卡瑞洛、芷瞳、巧芙 | 惩罚外部关系以迫使女主顺从 | 排除 | 外部把柄能否制造心甘情愿？ | 被排除 | 说明 AU 女主不会因把柄而真正回心转意 |
| 芷瞳哭崩提前止损 IF | `关系动力系统...`、`冷战眼神符号...` | 冷战爆发时卡瑞洛接住最后窗口 | 芷瞳哭着看他时，如果他停下，冷战可能不会那么惨 | 卡瑞洛、芷瞳 | 他看见伤害，但无法承认后几层，因此没接住 | 排除 | 男主是否有能力在最早窗口停手？ | 作为冷战反证 | 说明冷战之所以成立，是因为他当时还做不到 |

## C. 每条 IF 线的设定层结构功能分析

### C1. 不分离火葬场 IF

**1. 分叉点**  
日本事件仍发生，但结果改变：巧芙被救回家，芷瞳被卡瑞洛的人带回瓦雷斯。外部救走没有把芷瞳从卡瑞洛系统里切出去，冷战也没有进入主线三年分离。

**2. 设定概述**  
这条线不是简单删除分离，而是让日本事件保留为命运节点，同时取消“外部强制分离”的结果。巧芙回家后，芷瞳最初“为巧芙留下”的契约理由被抽掉；她仍然想回家，也仍然不承认卡瑞洛拥有她。卡瑞洛可以弥补、放宽、给书、给医生、减少靠近，但这些都仍然是“从他手里给出来”的东西。身体确认机制会从止痛变成更深的伤口：身体在，心不在；反应是真的，不愿意也是真的。卡瑞洛最终发现，只要芷瞳还在他的系统里，她所有愿意都无法被验证为真。因此主动放手不是温情升华，而是唯一能阻断坏循环的结构最优解。

**3. 测试的关系命题**
- 没有三年分离，主体性是否还能重建？
- 甜期和补偿能否自然修复起点不成立？
- 如果巧芙把柄消失，芷瞳是否会自动留下？
- 卡瑞洛能否在同一空间里痛到承认“我必须让她不回来也可以”？

**4. 男主变量**
- 放大：占有、求位、身体确认、补偿冲动、放手恐惧。
- 失败：用补偿替代自由、用身体反应证明在场。
- 转折：从“我给她更多”到“我必须让她离开我的系统”。

**5. 女主变量**
- 放大：解释权、能离开、拒绝把补偿当自由。
- 压缩：外部社会身份和完整分离篇能力重建。
- 关键：她不逃不是认命，而是“想走，但不做无效逃跑；爱他，但不承认他的拥有”。

**6. 关系变量**
- 起点仍不成立。
- 真反应被系统持续污染。
- 爱不能靠待遇改善洗白。
- 自由必须变成物理离开，而不只是生活条件放宽。

**7. 它为什么存在**  
它证明：如果没有主线的外部强制分离，关系不会自动变好，只会把“身体在、心不在”的痛拖长。它保存一种主线不能展开的低温酸涩，也反证主线分离的必要性。

**8. 为什么没有成为当前主线**  
作为主线，它会长期停在瓦雷斯内部耗损，女主外部身份、语言、学术、社会可见性重建都被压缩。它能逼出男主主动放手，但会让女主主体性路径不如主线完整。

**9. 关键设定句与论述摘录**
- “不分离火葬场线不是简单把主线的分离删掉，而是保留日本外部事件，只改变事件结果。”  
  关键：说明它是结构实验，不是删剧情。
- “巧芙被救回家。芷瞳被卡瑞洛的人带回瓦雷斯。”  
  关键：明确分叉点。
- “巧芙一旦回家，这个框架就被抽掉。”  
  关键：把留下理由从外部把柄转向关系本身。
- “她为什么还在这里？”  
  关键：这条线的核心追问。
- “身体在。心不在。反应是真的。不愿意也是真的。”  
  关键：身体确认机制耗尽。
- “只要她还在我的系统里，她的愿意就无法成立。”  
  关键：主动放手的结构理由。
- “主动放手不是温情选择，而是唯一能阻断恶性循环的选择。”  
  关键：这条 IF 的功能总结。

### C2. 不分离火葬场早死/被抓 IF

**1. 分叉点**  
不分离火葬场中，卡瑞洛最终主动放芷瞳回家；但此后没有及时重逢修复，暗夜倒台仍发生。

**2. 设定概述**  
这条线推演主动放手后的悲剧后果。卡瑞洛放走芷瞳后，不会废掉，仍然高功能运转，但求生欲下降。原作暗夜倒台时，芷瞳曾在关键时刻提供观察与预警；在这条 IF 中，她因为被放走而安全，也因此不在现场。卡瑞洛缺失这个外部校准器，叠加暗夜系统性崩塌和自己的高功能自毁，可能重伤、被抓、失踪或早死。芷瞳通过电视新闻、律师通知、遗产/保护安排迟发性地理解：他不是不想留下她，而是在怕自己继续留下她；他不是不爱了，而是终于学会爱不能再压迫她。这个理解来得太晚，只能成为迟到的墓志铭或开放伤口。

**3. 测试的关系命题**
- 学会正确爱法如果太晚，是否仍有修复意义？
- 放手是否会让复合更难？
- 不打扰的爱是否也会因为无法被对方及时理解而变成悲剧？
- 迟发理解能否替代现实修复？

**4. 男主变量**
- 放大：自我切断、不打扰、暗中保护、自毁。
- 压缩：主动索取、解释、重逢行动。
- 失败方式：学会不压迫，但失去时间窗口。

**5. 女主变量**
- 放大：迟发拼图、理解但无法回应。
- 压缩：当场选择权、现实重逢机会。
- 关键：她不能把他简单归为控制者，也不能轻松归为值得怀念的爱人。

**6. 关系变量**
- 自由成立，但关系接口被切断。
- 保护不转化为召回。
- 爱不再索取，却因此无法被验证、回应和修复。

**7. 它为什么存在**  
它保存“卡瑞洛终于学会正确爱法，但芷瞳已经没有机会或没有力量再把它当作安全”的痛感。它让重生柔和 IF 的温柔有代价来源。

**8. 为什么没有成为当前主线**  
它太彻底地切断重逢和修复窗口。主线需要让两人都经历分离、重建、重逢，在现实中处理旧系统责任，而不是只靠迟发理解完成精神清算。

**9. 关键设定句与论述摘录**
- “这条 IF 的核心痛感是：卡瑞洛终于学会了正确的爱法，但芷瞳已经没有机会，或者没有力量，再把它当作安全。”  
  关键：全线功能句。
- “他放她自由，所以她活下来。但也正因为她不在，他没有被她提醒。”  
  关键：命运反噬。
- “功能还在，求生欲下降。”  
  关键：高功能自毁定义。
- “他不是因为失恋就失能。”  
  关键：防止人物降级。
- “那不是冷淡。不是厌倦。不是放弃惩罚她。是他在学着不伤害她。”  
  关键：芷瞳迟发理解的核心。
- “这个理解来得太晚，成为迟到的墓志铭，而不是和解的起点。”  
  关键：说明为何难成 HE。

### C3. 不分离火葬场重逢 IF

**1. 分叉点**  
卡瑞洛主动放手后没有早死；多年后因外部事件、旧世界余波、雷厉风/东方倾城相关危机或命运重逢再次相遇。

**2. 设定概述**  
这条线建立在主动放手之后。卡瑞洛已经亲手承认芷瞳有权离开，因此他不能再主动打扰她；他可能暗中保护，但不会把保护变成召回。芷瞳当年误读他的冷淡为“厌倦、不要她”，因为一个长期强势占有的人突然减少出现并放人离开，更像厌弃而不是爱到不能再困住她。重逢后，修复不应靠“误会澄清”快速完成，而要等芷瞳已经主动回到他身边，卡瑞洛仍然过度克制、不敢接住时，她才说“我以为你不要我了”。这句话不是解释过去，而是打断他现在的自罚式克制：当年你这样我以为你不要我，现在你还要再退一次吗？

**3. 测试的关系命题**
- 放手后的克制是否会变成新的伤害？
- 男主不索取以后，是否还敢接住女主的自由选择？
- 女主主动回来时，男主若继续退开，是尊重还是自罚？

**4. 男主变量**
- 放大：不敢要求、过度克制、自罚、害怕牺牲变成把柄。
- 失败边缘：尊重过度后变成推开。
- 成长点：承认“永远不敢接住，不是答案”。

**5. 女主变量**
- 放大：自由后主动递出选择、迟到地承认当年也想被他要过。
- 压缩：主线式外部身份重建【待确认，视具体重逢背景】。
- 关键：她不是报恩，而是告诉他自己曾在“被不要”的位置上痛过。

**6. 关系变量**
- 选择自由，但接收选择的能力仍需修复。
- 牺牲不能成为新把柄。
- 克制不能替代回应。

**7. 它为什么存在**  
它测试“高贵放手”之后的另一面：放手是必要的，但如果男主把自己永远判出关系，也会再次伤到已经自由选择回来的人。

**8. 为什么没有成为当前主线**  
它需要前置主动放手，而主线设定中芷瞳是被救走，卡瑞洛没有完成这次训练。主线重逢因此必须保留他的欲望、压迫和理亏，而不能直接进入“不敢接住”的后期状态。

**9. 关键设定句与论述摘录**
- “他已经放手。她已经离开。然后他们在没有控制、没有把柄、没有孩子绑定、没有瓦雷斯结构的情况下重新相遇。”  
  关键：定义这条重逢 IF 的纯度。
- “‘我以为你不要我了’不能太早出现。”  
  关键：防止变成普通误会澄清。
- “芷瞳以为自己被厌弃。卡瑞洛以为自己终于没有再拖住她。”  
  关键：双向误读。
- “你以为你的克制是在保护我。可当年你这样，我以为你不要我。”  
  关键：这句话的真正杀伤力。
- “尊重不是把她推开；自罚不能替代爱。”  
  关键：修复命题。

### C4. 重生柔和 HE IF

**1. 分叉点**  
卡瑞洛从不分离火葬场的惨烈后果中重生，回到下属即将口头回禀芷瞳与巧芙谈话内容的节点。

**2. 设定概述**  
这条线的核心不是“卡瑞洛突然变好”，而是他已经在上一条命运线里走完不能承受的后果，因此终于能在同一个爆点前停住。他仍然痛、羞耻、想确认、想惩罚，也仍然不知道芷瞳到底有多少真。但他上一世已经迟来地知道：冷战前不是全假的；芷瞳确实有策略，但她的担心、动摇、羞耻、靠近也有真的部分。所以这一世他的核心恐惧从“她是不是骗我”变成“我会不会又把她的真毁掉”。他忍住，不把爱逼成证词。后续通过仆人事件，芷瞳知道他早已知道报告却没有伤害她；她最终说“我不是一直在骗你”，他回应“我知道”。回家通信和暗夜倒台失势补丁进一步让这条线扩展成：芷瞳在自由状态下仍想和他说话，甚至以学术身份主动回到意大利确认他。

**3. 测试的关系命题**
- 已经付过代价的男主能否提前停手？
- 在没有三年彻底分离重建的情况下，女主能否给出真实回应？
- 等待能否替代控制？
- “我知道”能否修复主线“别想再骗我”造成的伤口？

**4. 男主变量**
- 放大：忍受不确定、等待、克制、不索要更多。
- 保留：占有欲、主位感、危险性。
- 改写：控制力从控制她转为控制自己不控制她。
- 失败被避免：把一点假扩大成全假。

**5. 女主变量**
- 放大：在较柔和环境里逐渐承认真、自由通信、回家后仍选择靠近。
- 压缩：主线分离篇的硬重建、武装式主体性。
- 关键卡点：仍然是“我是被你买下的人”。

**6. 关系变量**
- 起点污染仍在。
- 真反应没有被报告毁掉。
- 自由需要后期回家与通信来证明。
- HE 成立点不是一切解决，而是“不再把可能性逼死”。

**7. 它为什么存在**  
它测试：如果卡瑞洛已经拥有主线后期才可能有的痛苦经验，关系能否避开最惨岔路。它也保存一种“代价换来的温柔”。

**8. 为什么没有成为当前主线**  
它以重生为前提，且卡瑞洛“功力已经到了”。如果放进当前主线，会偷走主线的冷战、分离、主体重建和重逢修复逻辑。

**9. 关键设定句与论述摘录**
- “他不是终于得到了答案，而是终于学会在没有答案时不毁掉可能性。”  
  关键：重生 IF 总命题。
- “这一次，他没有发作，没有把芷瞳所有反应都判成欺骗。”  
  关键：分叉核心。
- “我会不会又把她的真毁掉？”  
  关键：男主恐惧从被欺骗转为毁真。
- “他不是一开始就学会放手，而是先学会不毁。”  
  关键：避免圣人化。
- “我不抓你，但我还在这里。”  
  关键：柔和 IF 的第三路径。
- “我不是一直在骗你。”  
  关键：芷瞳式近乎告白。
- “我知道。”  
  关键：对“别想再骗我”的反向修复。
- “这一世，他知道她曾经爱过他，所以能放手；她也在自由里发现自己仍然想回来，所以能选择。”  
  关键：HE 成立点。

### C5. 无巧芙谈话/报告触发的柔和 HE 与黑暗共同体线

**1. 分叉点**  
巧芙谈话没有在最危险的时间触发，或报告没有刺穿卡瑞洛，或卡瑞洛忍住旧系统，不让冷战爆发。

**2. 设定概述**  
这条线与重生柔和不同：它不一定来自惨烈代价，而可能来自关键爆点被延迟。卡瑞洛继续柔和推进，芷瞳在更长时间里留在卡瑞洛系统内，逐渐承认自己在乎他。它不是降级甜宠，而是另一条完整 HE 结构：主线是芷瞳先脱出系统、建立外部独立身份，再自由回来；柔和 IF 则是芷瞳留在系统内部，逐渐长出主体性和权力位置，最终与卡瑞洛形成黑暗共同体式平等。它的上限不是低配夫人线，而是内部女大佬生成线。失势节点会成为她能力显现的机会：她不做战斗者，而用结构判断、信息流、人心观察、语言能力、管理盲区识别，帮助卡瑞洛重建一种不只靠恐惧维持的秩序。

**3. 测试的关系命题**
- 不离开系统，是否仍能长出主体性？
- 共同作战能否替代外部独立？
- 黑暗世界内部是否能生成平等，而不是夫人收编？
- 如果没有冷战创伤，爱是否会更顺，但自由证明更弱？

**4. 男主变量**
- 放大：信任、授权、共治、在强大时选择不控制。
- 压缩：失去后的绝望训练。
- 风险：因为现实上更适合他，可能滑向收编。

**5. 女主变量**
- 放大：系统内部能力、女大佬潜质、共同做题。
- 压缩：外部身份重建、离开后自由选择的硬证明。
- 风险：她是否真的有能力在不靠他时站稳【待确认】。

**6. 关系变量**
- 起点仍需处理。
- 平等来自内部共同作战，而非外部独立后被看见。
- HE 需要真正暗黑权谋棋盘承载，否则会变成夫人爽文。

**7. 它为什么存在**  
它保存“进入他的世界，并在其中共同生成”的原作式可能，也说明主线不是唯一 HE。它测试另一种平等来源：不是她离开他也能成立，而是她在他的战场里不是附属。

**8. 为什么没有成为当前主线**  
它需要另一本书级别的暗黑权谋配置。当前主线更聚焦心甘情愿悖论、冷战、分离、主体重建和自由选择。柔和共同体线会把项目重心转向权力棋盘。

**9. 关键设定句与论述摘录**
- “主线 AU：芷瞳先脱出卡瑞洛系统，建立外部独立身份，再自由回来。”  
  关键：主线定义。
- “柔和 IF：芷瞳留在卡瑞洛系统内部，逐渐长出主体性和权力位置。”  
  关键：柔和 IF 定义。
- “柔和 IF 不是降级甜宠，而是静默酷刑线。”  
  关键：防止误读成轻松线。
- “卡瑞洛第一次真正做到：控制自己不去控制她。”  
  关键：男主核心变化。
- “柔和 IF 的上限不能只是：芷瞳成为卡瑞洛的夫人。”  
  关键：排除低配夫人线。
- “主线让卡瑞洛学会不占有。柔和 IF 让卡瑞洛学会共治。”  
  关键：两线结构差异。
- “芷瞳如果要成为女大佬，她就得真的在棋盘上做题。”  
  关键：写作难度与设定约束。

### C6. 黑暗自毁占有稳态与孩子绑定/代际反噬线

**1. 分叉点**  
冷战后，卡瑞洛不走向放手，也不进入主线分离，而是接受“她不愿意也没关系，只要她在身边就够”的黑暗选择。

**2. 设定概述**  
这条线是主线最重要的黑暗反证。它的基本逻辑是：卡瑞洛知道自己毁掉了她心甘情愿的可能，但不能没有她，于是宁可让她恨也要她留在身边。两人可能形成长期稳定的黑暗关系：吃饭、同床、读书、处理事务、冲突日常化、低温共存。若进一步引入孩子，孩子不再是家，而是最强现实绑定：身体、身份、责任、下一代、家族系统把关系缝在一起。芷瞳不会浪漫化孩子；她会负责，但不把孩子当牢笼，也不把恨转嫁给孩子。卡瑞洛可能是可靠父亲，却不能用父爱洗白伴侣关系。孩子尤其女儿长大后，会在爱父亲、心疼母亲、理解系统后，成为代际反噬者：她用父亲给的能力和母亲给的边界意识，结束父亲对母亲的占有。

**3. 测试的关系命题**
- 孩子是否会成为新的收编机制？
- 长期日常和父亲责任能否洗掉起点错误？
- 爱和家庭温情是否能抵消自由缺失？
- 下一代是否会继承并审判上一代未解决结构？

**4. 男主变量**
- 放大：占有、欲望押注、父亲责任、长期保护、对自己也狠。
- 失败：放弃最高目标“她愿意”，退到最低目标“她在”。
- 反噬：女儿成为他亲手养出的审判者。

**5. 女主变量**
- 放大：边界、孩子教育、复杂公正、不把恨转嫁给孩子。
- 压缩：能离开、外部完整身份、自由选择。
- 关键：她负责但不浪漫化，不把现实锁链解释成愿意。

**6. 关系变量**
- 孩子绑定强化现实连接，却污染选择。
- 家庭外壳提供稳定，但不是修复。
- 爱存在、伤害也存在；爱不能替自由作废。

**7. 它为什么存在**  
它放大主线排除的危险：如果卡瑞洛不变量分离，而把未来押进不可逆结构，会产生长期稳定但不正当的黑暗家庭。它说明孩子作为 HE 不是圆满，而可能是封口和代际反噬。

**8. 为什么没有成为当前主线**  
它要求卡瑞洛放弃自己最深的欲望：芷瞳心甘情愿。当前主线卡瑞洛做不到只满足于人在身边；身体确认机制会耗尽，他仍想要愿意。

**9. 关键设定句与论述摘录**
- “我知道她不会爱我。我知道我毁掉了她心甘情愿的可能。但我不能没有她。所以宁可让她恨我，也要她留在身边。”  
  关键：黑暗稳态核心。
- “它是稳定的，但不是修复。”  
  关键：定义黑暗日常。
- “巧芙是外部把柄。孩子是内部结构。”  
  关键：孩子绑定强度。
- “你不是用来绑住我的工具。你不是我的牢笼。你是你自己。”  
  关键：芷瞳对孩子的价值线。
- “卡瑞洛用孩子绑住芷瞳，最后孩子成为芷瞳自由的执行者。”  
  关键：代际反噬。
- “爱是真的。离开也可以是真的。”  
  关键：女儿线成熟判断。
- “高贵确实是最优。早一点放手，是痛。晚一点放手，是痛加上不可逆的代际伤害。”  
  关键：黑暗线对主线的反证。

### C7. Marcello 私名污染线

**1. 分叉点**  
黑暗孩子/长期家庭线中，孩子、家族旧宅、医生、亲戚、旧仆役系统提前进入芷瞳生活，`Marcello` 这个 first name 提前暴露。

**2. 设定概述**  
主线中，`Marcello` 是后期才可能出现的温柔私名，应在自由和好后极少数私人瞬间出现。黑暗 IF 中，这个名字不再干净：芷瞳在不自由、长期同居、孩子和家庭场景里，从亲戚、医生、旧宅长辈口中反复听见它。她看见卡瑞洛不只是权力名，还有家族和私人生活，但她进入这个私人生活不是自由选择。因此 `Marcello` 变成被污染的温柔。她不叫这个名字，是少数还能掌握的语言边界；她可以对孩子说“你爸爸”，承认父亲位置，但不承认伴侣位置。

**3. 测试的关系命题**
- 私人亲密语言若在不自由条件下提前出现，是否会被污染？
- 承认父亲位置是否等于承认伴侣位置？
- 家族温柔能否修复强制进入家庭的错误？

**4. 男主变量**
- 放大：私人性、家族身份、被女主不叫私名刺中。
- 失败：无法用孩子、亲戚、日常家庭语法换来她的亲密命名。

**5. 女主变量**
- 放大：语言边界、称呼权、对孩子的公正。
- 压缩：物理离开、生活结构选择。
- 关键：不叫 `Marcello` 是安静但硬的边界动作。

**6. 关系变量**
- 私名成为语言绑定。
- 亲密不是信息，而是自由条件下的命名。
- 名字来得不对，会留下历史负担。

**7. 它为什么存在**  
它从语言层面补足孩子绑定线：孩子是现实绑定，私名是语言绑定。它说明即使温柔真实，来路不自由也会污染亲密符号。

**8. 为什么没有成为当前主线**  
主线需要保留 `Marcello` 的迟到性和洁净度。如果提前让它进入强制场域，会削弱后期私名作为自由亲密入口的功能。

**9. 关键设定句与论述摘录**
- “主线里，`Marcello` 是后期才可能出现的温柔私名。”  
  关键：主线称呼规则。
- “黑暗 IF 里，`Marcello` 是被迫提前暴露的私人领域。”  
  关键：黑暗线变义。
- “它仍然温柔，但这份温柔不再干净。”  
  关键：污染定义。
- “她越看见 `Marcello`，越难把卡瑞洛简单处理成一个纯粹的暴君；可她也越清楚，自己并不是因为愿意靠近，才获得了这个名字。”  
  关键：复杂痛感。
- “芷瞳不叫 `Marcello` 不是因为不知道，也不是因为发音困难。”  
  关键：不叫是边界。
- “孩子是现实绑定，私名是语言绑定。”  
  关键：与孩子线的结构关系。

### C8. AU 怀孕/孩子线与无子低调 HE

**1. 分叉点**  
亲密线后是否引入真实怀孕/孩子，或终局是否使用孩子、婚姻、公开身份完成 HE。

**2. 设定概述**  
原作孩子可以象征“家”的可能：缺家的卡瑞洛和更偏情感道德结构的原作芷瞳，可能通过孩子进入家庭化路径。但 AU 中孩子意义相反：对 INTJ 芷瞳来说，孩子首先触发身体主权、下一代安全、危险世界延续和永久绑定问题。她对孩子的责任不等于必须留在不平等关系里。卡瑞洛也不会把孩子当轻便控制工具；他知道孩子是风险、筹码、继承、弱点和不可控变量。当前主线正式设定是默认安全措施，不走怀孕/流产后果线；冷战可以有怀孕惊惧，但最优解是“惊惧成立，后果不成立”。终局上，主线更倾向无子低调 HE：不靠婚姻、孩子、公开夫人身份，而靠低可见度、强边界、弱标记、社会身份和持续选择成立。

**3. 测试的关系命题**
- 孩子能否让关系变成家？
- 在 AU 中，孩子是否反而加重主体性危机？
- 无子 HE 是否更符合“两个主体在自由条件下重新选择”？
- 婚姻/公开身份是否会把芷瞳重新写进卡瑞洛权力名下？

**4. 男主变量**
- 放大：风险判断、不会低级绑人、父亲能力与父亲愿望分离。
- 排除：用孩子作为现实锁链。
- 结局变量：保护要低标记，不能高调占有。

**5. 女主变量**
- 放大：身体主权、下一代安全、社会身份、外部可见性。
- 排除：为了孩子什么都忍的母性逻辑。
- 关键：她可以爱卡瑞洛，但不能替孩子选择出生在危险系统里。

**6. 关系变量**
- 孩子在原作是家，在 AU 是危险变量。
- 无子 HE 不削弱关系，反而防止生殖/家庭封口。
- 婚姻公开会增加追踪、定价和收编。

**7. 它为什么存在**  
它专门排除古早狗血常见的家庭化封口方案。它证明：当前 AU 的 HE 不需要孩子，因为主题不是找到家，而是自由条件下互相选择。

**8. 为什么没有成为当前主线**  
真实孩子线会把主题从主体性、解释权、自由选择转向生理后果、代际安全和家庭绑定，重量太大，会抢走当前主线最清晰的结构。

**9. 关键设定句与论述摘录**
- “原作的孩子线可以通向相对稳定的家庭化分支。”  
  关键：原作与 AU 对照。
- “AU 怀孕/孩子线：孩子不是家，而是主体性危机。”  
  关键：AU 孩子线定义。
- “正因为有孩子，更不能留在卡瑞洛身边。”  
  关键：INTJ 芷瞳逻辑。
- “孩子不能解决问题，只会让问题更重。”  
  关键：AU 卡瑞洛判断。
- “在芷瞳还不真的心甘情愿之前，他不会主动加一个孩子进来。”  
  关键：主线排除依据。
- “惊惧成立，后果不成立。”  
  关键：冷战中孩子变量的使用上限。
- “两个人的关系不是靠家庭、血缘、下一代来稳定，而是靠两个主体在自由条件下互相选择。”  
  关键：无子 HE 正当性。
- “主线 HE 不应该靠公开关系、婚姻登记、孩子、卡瑞洛高调保护或‘夫人’身份完成。”  
  关键：终局规则。

### C9. 主动追求 IF / 无外部危机线

**1. 分叉点**  
三年分离后，没有懂中文仆人反噬、没有旧系统残余绑架、没有外部事件把芷瞳重新拖回卡瑞洛世界。

**2. 设定概述**  
这条 IF 问：没有命运帮忙制造入口，卡瑞洛是否会主动追求芷瞳？答案是会想，但极难。卡瑞洛不是普通男人，他每一个主动动作都会带来物理后果：本人出现会带来安保、路线、敌人、警方和旧世界追踪；派人联系像监控复活；送资源像收买；安排地点天然偏向控制结构。因此这条线的核心不是“怎么低头追她”，而是“怎样创造一个她可以安全拒绝他的物理条件”。它分为清场、给信息而不是要回应、请求而不是召回。真正难的是让他主动，但不能把主动变成优势。

**3. 测试的关系命题**
- 没有外部事件，男主如何靠近而不夺取？
- 请求是否能替代召回？
- 信息能否无条件归还，而不是变成钩子？
- 女主是否可以安全拒绝？

**4. 男主变量**
- 放大：不使用优势、请求、等待、安全条件创造。
- 压缩：命令、安排、保护性隔离、资源交换。
- 难点：主动本身天然带压迫性。

**5. 女主变量**
- 放大：安全拒绝、外部生活、选择权。
- 关键：她不是只能在危险和卡瑞洛之间选择，也可以选择正常对象或不选择亲密。

**6. 关系变量**
- 重逢入口不靠危机，而靠可拒绝的请求。
- 信息归还不能附带回应义务。
- 追求本身必须去优势化。

**7. 它为什么存在**  
它测试主线外部危机的必要性。外部危机并不是狗血方便，而是能在不让卡瑞洛主动侵入芷瞳生活的前提下，把两人放回同一场域。

**8. 为什么没有成为当前主线**  
节奏太慢，戏剧推进低温。主线需要旧系统反咬来检验卡瑞洛是否能救她而不重新收编她。

**9. 关键设定句与论述摘录**
- “卡瑞洛怎样创造一个她可以安全拒绝他的物理条件。”  
  关键：主动追求 IF 核心。
- “对卡瑞洛来说，真正有资格靠近之前，第一步反而是把自己的世界从她身边拆远一点。”  
  关键：反本能靠近。
- “我把你有权知道的东西还给你。你不需要因此回应我。”  
  关键：信息归还原则。
- “请求，而不是召回。”  
  关键：行动方式转变。
- “他主动，但不能把主动变成优势。”  
  关键：全线难点。

## D. IF 线分类：按结构功能，而不是按剧情

### D1. 失败条件测试型

- **包含 IF 线**：不分离火葬场、黑暗自毁占有稳态、孩子绑定、惩罚巧芙 IF、怀孕真实后果线。
- **共同功能**：说明什么条件下关系不能成立，或者只能形成低温稳定/现实锁链。
- **共同测试问题**：人在身边、身体反应、孩子、补偿、把柄、日常共处能不能替代自由选择？
- **对主线反证作用**：主线必须处理自由、解释权、外部身份和边界，不能停在“他对她好一点”。

### D2. 黑暗放大型

- **包含 IF 线**：自毁式占有稳态、孩子绑定/代际反噬、Marcello 私名污染。
- **共同功能**：放大控制、家庭、孩子、私名、长期日常如何把柔软物变成不自由结构。
- **共同测试问题**：真实父爱、家庭温情、私名亲密能否抵消起点不正当？
- **对主线反证作用**：主线必须避免孩子、家庭、夫人位置、私名提前污染。

### D3. 修复条件测试型

- **包含 IF 线**：不分离火葬场重逢 IF、重生柔和 HE、主动追求 IF、无子低调 HE。
- **共同功能**：测试关系成立需要哪些现实边界和心理能力。
- **共同测试问题**：放手后如何接住？重生后如何等待？主动靠近如何不使用优势？无子无婚如何持续选择？
- **对主线反证作用**：主线修复不能靠道歉、甜期或名分，而要落到自由、边界、责任和接口上。

### D4. 主体性失败/压缩型

- **包含 IF 线**：柔和 HE 黑暗共同体线、黑暗孩子绑定线、不分离火葬场线。
- **共同功能**：测试芷瞳若不经过主线分离式外部重建，会在哪些位置获得主体性、又会在哪些位置受限。
- **共同测试问题**：系统内部成长是否足够？孩子责任是否会压缩自由？不分离是否让能力线不足？
- **对主线反证作用**：主线选择外部独立后回归，是为了使主体性证明更硬。

### D5. 男主放手失败/迟到型

- **包含 IF 线**：不分离火葬场、早死/被抓 IF、黑暗占有稳态。
- **共同功能**：测试卡瑞洛不能及时变量分离时会怎样。
- **共同测试问题**：他是把欲望切断、押进孩子，还是痛到主动放手？
- **对主线反证作用**：主线的卡瑞洛不能过早正确，也不能完全不变；他必须处在“欲望保留但开始承担”的中间态。

### D6. 孩子/家庭收编型

- **包含 IF 线**：原作孩子家庭化分支、AU 孩子主体性危机、黑暗孩子绑定、女儿代际反噬。
- **共同功能**：测试孩子从“家”的可能转为“主体性危机”的机制。
- **共同测试问题**：孩子到底是家、锁链、责任、下一代审判者，还是不可逆风险？
- **对主线反证作用**：无子 HE 不是缺失，而是主题保护。

### D7. 无子稳态型

- **包含 IF 线/版本**：无子低调 HE、结局正当身份、安全边界、重逢后台公开风险。
- **共同功能**：测试关系不靠生殖、婚姻、公开身份、夫人位置如何成立。
- **共同测试问题**：低可见度、强边界、弱标记是否比公开归属更安全、更尊重？
- **对主线反证作用**：卡瑞洛最终成长不是高调标记她，而是减少标记。

### D8. 正常人生参照型

- **包含线索**：主线分离正常参照物、主动追求 IF 中普通优秀追求者可能、无子低调 HE。
- **共同功能**：测试正常、安全、温柔是否足以替代卡瑞洛。
- **共同测试问题**：如果芷瞳可以选择正常生活，她为什么仍需要处理卡瑞洛这个变量？

## G. 当前主线为什么需要这样走

### G1. 为什么必须有分离

IF 线反复证明，不分离并不会自动修复关系。不分离火葬场里，补偿、放宽、身体确认都会耗尽，因为自由仍然由卡瑞洛分配。芷瞳需要从卡瑞洛系统外部建立语言、行动、社会身份、学术路径和判断权；卡瑞洛也需要面对“她在没有我的地方变得完整”。因此主线分离不是拖延，而是让两个人都从原先耦合中拆出来。

### G2. 为什么不能靠甜期自然修复

无巧芙报告柔和 HE 证明甜期确实可能延长真实靠近，但它也显示隐患：芷瞳仍在系统内部爱上卡瑞洛，她的自由证明较弱。如果甜期不经过冷战或分离，很多变量会没被拆开：被买下起点、巧芙债、系统内部自由、身体反应和真心选择。甜期可以保留真实，但不能洗白结构。

### G3. 为什么不能靠孩子完成 HE

原作孩子可以象征家，但 AU 孩子首先触发主体性危机。孩子会把身体、身份、未来、下一代安全和危险世界延续全部推上桌。黑暗孩子线进一步说明，孩子最容易成为内部结构和现实锁链，甚至造成代际反噬。主线若用孩子完成 HE，会把“自由条件下互相选择”替换成“不可逆后果下维持关系”。

### G4. 为什么不能靠卡瑞洛温柔化解决

多个 IF 都强调：卡瑞洛不能突然变成安全好人或赎罪圣人。重生柔和 IF 的温柔来自上一世代价；主线重逢的卡瑞洛“知道对的事，但还做不到”；柔和 HE 也不是不痛，而是静默酷刑。主线必须保留欲望、危险和旧系统责任，否则男主会失去原作电流，也失去变量分离的意义。

### G5. 为什么不能靠芷瞳不爱了获得自由

分离篇和无子 HE 的核心不是“不爱”，而是爱不能拥有行动指令权。不分离重逢 IF 也显示：芷瞳可以仍然爱他，仍然觉得当年“被不要”痛，但这不等于关系自动成立。主线需要她承认爱过，同时仍能离开、拒绝、判断、发出自己的版本。

### G6. 为什么不能靠正常亲密参照物替代

正常参照物能证明安全、温柔、边界珍贵，但不能处理卡瑞洛打开的高规格看见、危险结构和未完成命题。主动追求 IF 中也承认芷瞳可以选择正常优秀对象，但这不自动解决她和卡瑞洛之间未完成的解释权、伤害责任和真实选择问题。

### G7. 为什么不能靠公开身份、婚姻、夫人位置完成

低调 HE 文件明确：公开会把芷瞳从旧禁区变成公共定价对象；婚姻会成为可追踪锁链；夫人位置会把她重新写进卡瑞洛权力名下。主线终局更适合低可见度、强边界、弱标记，让她仍主要是连芷瞳，而不是卡瑞洛的某个身份。

### G8. 为什么重逢必须先处理旧系统责任和通信/边界接口

卢卡献礼、懂中文仆人反噬、包/手机/线路/内容，都说明问题不是两个人互相爱不爱，而是旧系统仍会按旧逻辑把芷瞳当软肋、礼物、筹码、可递交的信息。重逢修复必须先处理“为什么他会以为你会满意”“内容我写”“不是自由，是边界”等接口，否则关系会被旧系统再次吞回去。

### G9. 为什么最终需要低可见度、强边界、弱标记的稳态

卡瑞洛这种世界里的高调标记会增加攻击价值。芷瞳既不是系统内部共同体成员，也不是可被隔离的家庭主妇；她有学术、会议、父母、外部身份和社会接口。主线 HE 的难点正是：保护她，但不把她收进来；爱她，但不标记她；和她在一起，但不把她变成所有人都能定价的软肋。
