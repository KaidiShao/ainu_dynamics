# 讨论归档｜价值对齐与证据去污染：数学原理 v1

## 0. 文档目的

本文档把 `价值对齐与证据去污染机制` 写成一个更接近数学/计算模型的版本。

核心问题是：

```text
在强制关系中，爱的证据已经被控制污染。
那么，什么条件可以让这些被污染的证据重新具有诊断价值？
```

回答是：

```text
不是爱的证据本身直接变干净，
而是强迫者先发出高层规范信号，
使被强迫者更新其对强迫者高层生成模型的判断。

价值对齐先发生，
证据去污染才可能发生。
```

因此本文要形式化的不是：

```text
他对她好 -> 她被奖励 -> 她原谅
```

而是：

```text
他承认她的规范判断 -> 她更新他的高层模型 -> 过去/现在的爱证据获得新的解释条件 -> 宽恕成为可能
```

## 1. 基本变量

设两个 agent：

```text
K = 卡瑞洛
Z = 芷瞳
```

### 1.1 卡瑞洛侧 hidden states

```text
L_K ∈ {0,1}
L_K = 1 表示卡瑞洛真实爱芷瞳。

V_K ∈ {0,1}
V_K = 1 表示卡瑞洛承认芷瞳的高层规范：
      愿意不能被占有替代；
      后来的好不能抵消来路；
      爱不能夺取定义权。

C_K ∈ [0,1]
卡瑞洛的控制强度。

G_K ∈ [0,1]
卡瑞洛的罪感/自我审判强度。

S_K ∈ [0,1]
卡瑞洛的 self-cohesion，自体凝聚程度。
```

### 1.2 芷瞳侧 hidden states

```text
W_Z ∈ {0,1}
芷瞳是否自由愿意。

F_Z ∈ {0,1}
芷瞳是否真实宽恕 / 表达慈悲。

A_Z ∈ [0,1]
芷瞳的 agency / 行动主体性。

B_Z ∈ [0,1]
芷瞳的边界完整性。

T_ZK ∈ [0,1]
芷瞳对卡瑞洛不再使用控制 policy 的信任。
```

### 1.3 关系层条件

```text
Freedom ∈ [0,1]
拒绝、离开、不回来、不复合是否真实可用。

NR ∈ [0,1]
non-reconciliation availability，不复合可用性。

Context
历史伤害、强制结构、孩子绑定、家庭系统、夫人位置等背景。
```

### 1.4 可观测信号

```text
O_love
爱的观测：照顾、等待、克制、补偿、温和、长期承担、身体关系中的收敛等。

O_norm
规范信号：对不起、不追、无条件补偿、承认她走是正当的、承认后来对她好不能抵消来路。

O_return
自由回应信号：回来、命名爱、宽恕、主动靠近、主动选择关系。
```

## 2. 证据污染：为什么爱不能直接成为修复证据

在清白关系中，`O_love` 可能对 `L_K` 有较高诊断价值：

```text
P(O_love | L_K = 1) >> P(O_love | L_K = 0)
```

因此：

```text
O_love 支持 “他爱她”。
```

但在强制关系中，`O_love` 的生成原因变多。

同一个观测可以由多种 latent cause 生成：

```text
cause ∈ {
  love,
  guilt,
  compensation,
  softening strategy,
  refined possession,
  fear of loss,
  maintaining family stability
}
```

所以：

```text
P(O_love | love) 高
P(O_love | compensation/control/softening) 也高
```

这会降低 `O_love` 对 `L_K` 的诊断价值。

可以写成：

```text
D_love = I(L_K ; O_love | Context)
```

在强制结构下：

```text
D_love 低
```

因为 `O_love` 不再能有效区分：

```text
他爱我
```

和：

```text
他想补偿我
他想软化我
他仍在高级占有
他害怕我彻底离开
他需要这个家成立
```

因此：

```text
爱仍然存在，
但爱不能直接被接收为修复证据。
```

## 3. 价值对齐：Z 真正在推断什么

芷瞳后期真正想推断的，不只是：

```text
L_K：卡瑞洛是否爱我？
```

而是更高层的：

```text
V_K：卡瑞洛是否承认我的底层规范？
```

即：

```text
在他的世界模型里，
我的愿意是否比他的占有更重要？
他是否承认我走是正当的？
他是否承认后来的好不能抵消来路？
他是否不再用爱夺取定义权？
```

这不是 reward，也不是普通好感，而是高层生成模型中的 normative prior / preferred state。

因此，价值对齐可以定义为：

```text
V_K = 1
```

当且仅当：

```text
K 的高层模型承认：
W_Z 不能由 C_K 替代；
O_love 不能抵消历史强制；
Z 的审判权与选择权仍然有效；
K 的爱不能成为索取回应的理由。
```

## 4. 规范信号：为什么 “对不起 + 不追 + 补偿” 很关键

`O_norm` 是高层规范信号。

它不是普通情绪表达，也不是普通现实安排。

它的结构是：

```text
O_norm = apology + no pursuit + unconditional compensation + no claim
```

也就是：

```text
对不起；
我不追；
我补偿你失去的现实人生；
但我不把补偿当成让你回来的理由。
```

这个信号对 `V_K` 有较高诊断价值：

```text
P(O_norm | V_K = 1, Freedom = 1) 高
P(O_norm | V_K = 0, Freedom = 1) 低
```

因为如果卡瑞洛不承认芷瞳的高层规范，他更可能发出的是：

```text
我爱你；
我等了你很多年；
我为你付出了这么多；
你为什么还不回来；
这个家已经这样了；
你也知道我有多痛。
```

这些都可能继续索取回应。

而真正的 `O_norm` 不索取，它先确认芷瞳的判断：

```text
你走是正当的。
我没有资格追。
我后来对你好不能抵消我当初做错。
```

所以芷瞳的更新是：

```text
q_Z(V_K = 1 | O_norm, Freedom)
  ∝ P(O_norm | V_K = 1, Freedom) q_Z(V_K = 1)
```

如果 `O_norm` 可靠，则：

```text
q_Z(V_K = 1) ↑
```

## 5. 证据去污染：价值对齐如何改变爱的解释条件

一旦 `q_Z(V_K = 1)` 上升，芷瞳就可以重新解释过去和现在的 `O_love`。

此前：

```text
P(cause = control/compensation/softening | O_love) 高
P(cause = love-with-respect | O_love) 低或不稳定
```

在 `O_norm` 出现后：

```text
P(cause = love-with-guilt-and-respect | O_love, O_norm) ↑
P(cause = refined-possession | O_love, O_norm) ↓
```

更形式化地：

```text
P(cause | O_love, O_norm)
  ∝ P(O_love | cause) P(cause | O_norm)
```

`O_norm` 改变的不是 `O_love` 的表面事实，而是改变了各个 cause 的先验权重。

因此：

```text
D_love_after
  = I(L_K ; O_love | V_K = 1, Freedom, Context)
```

并且通常有：

```text
D_love_after > D_love_before
```

其中：

```text
D_love_before = I(L_K ; O_love | Context)
```

这就是证据去污染：

```text
不是过去的伤害被取消；
不是后来的好抵消来路；
而是芷瞳终于能把一部分证据重新归类为“爱”，
同时保留“有罪”的判断。
```

## 6. 为什么这不是 reward learning

错误模型是：

```text
Σ reward_K_to_Z ↑
=> Z 原谅 K
```

也就是：

```text
卡瑞洛给了很多好处；
芷瞳被照顾、被保护、拥有稳定生活；
所以她逐渐更新为他值得爱。
```

这个模型不成立。

因为芷瞳恰恰会抵抗这种解释：

```text
如果我因为好处而承认爱，
那是不是后来的好替来路洗白？
```

真正发生的是：

```text
q_Z(V_K = 1) ↑
=> 对 O_love 的解释模型改变
=> 一部分 O_love 的 precision 上升
=> 宽恕/慈悲成为可用行动
```

也就是说：

```text
不是 reward accumulation，
而是 high-level model revision。
```

## 7. 与 active inference 的关系

在 active inference 中，agent 不只是被动更新 belief，也会选择 policy 来改变未来 observation。

卡瑞洛早期的错误 policy 是：

```text
π_control:
  maximize O_stay
  maximize proximity
  minimize immediate loss uncertainty
```

但这个 policy 的代价是：

```text
Diag_W ↓
Diag_love ↓
Freedom ↓
```

成熟后的 policy 是：

```text
π_align:
  allow exit
  do not pursue
  apologize
  compensate without claim
  preserve Z's right not to return
```

这个 policy 短期不会最大化 preferred outcome：

```text
Z may not return.
Z may not forgive.
Z may not receive love.
```

但它提高未来信号的诊断价值：

```text
Diag_W ↑
Diag_F ↑
D_love_after ↑
```

因此成熟 policy 可以写成：

```text
π_mature = preserve freedom + send normative signal + wait
```

它的功能不是立刻获得回应，而是恢复回应的可辨识性。

## 8. 分离期作为 counterfactual test

分离期可以视为一次 counterfactual test：

```text
如果 Z 真的离开，
K 会不会继续控制？
```

观测结果：

```text
O_no_pursuit = 1
```

这使自由本身变成可观测事件：

```text
Freedom_observed ↑
```

但 `O_no_pursuit` 本身仍然歧义：

```text
他尊重我；
他放弃了；
他疲惫了；
他服判了；
他不爱了；
他终于不追了。
```

所以 `O_no_pursuit` 需要 `O_norm` 解释。

组合信号是：

```text
O_no_pursuit + O_norm
```

它共同支持：

```text
V_K = 1
```

也就是：

```text
他不是不要我；
也不是用疲惫结案；
而是承认我走是正当的，
并且不再用爱索取我的回来。
```

## 9. 宽恕如何启动

宽恕不是情感覆盖 prediction error。

也不是：

```text
他太惨了 -> 我心软 -> 我原谅
```

而是：

```text
O_norm 使 q_Z(V_K = 1) 上升；
q_Z(V_K = 1) 使 O_love 的部分解释去污染；
O_love 被重新解释为 love-with-guilt-and-respect；
Z 可以同时保持：
  K 有罪；
  K 爱我；
  K 承认我的标准；
  我可以自由选择宽恕。
```

所以：

```text
F_Z = 1
```

不是 surrender，而是主体行动。

这也可以写作：

```text
P(F_Z = 1 | Freedom, B_Z, q_Z(V_K = 1), D_love_after)
```

当以下条件同时成立时，宽恕更可能成为真实行动：

```text
Freedom 高；
B_Z 高；
q_Z(V_K = 1) 高；
D_love_after 足够高；
NR 高。
```

其中 `NR` 是：

```text
non-reconciliation availability
```

即：

```text
她仍然可以不复合。
```

因此：

```text
她能不复合，宽恕才不等于复合。
```

## 10. 最小 simulation 草案

可以先做一个非常小的二值模型。

### 10.1 Hidden states

```text
L_K ∈ {0,1}
V_K ∈ {0,1}
F_Z ∈ {0,1}
```

### 10.2 Observations

```text
O_love ∈ {0,1}
O_norm ∈ {0,1}
O_return ∈ {0,1}
```

### 10.3 Context variables

```text
Freedom ∈ {0,1}
NR ∈ {0,1}
```

### 10.4 Example likelihoods

强制结构中：

```text
P(O_love = 1 | L_K = 1, V_K = 1) = 0.9
P(O_love = 1 | L_K = 1, V_K = 0) = 0.9
P(O_love = 1 | L_K = 0, V_K = 0) = 0.6
```

因为即使不承认她的规范，卡瑞洛也可能为了补偿、占有、维持家庭而持续给出好。

所以 `O_love` 对 `L_K` 有一定信息，但对修复关系不够。

规范信号：

```text
P(O_norm = 1 | V_K = 1, Freedom = 1) = 0.85
P(O_norm = 1 | V_K = 0, Freedom = 1) = 0.10
```

这使 `O_norm` 对 `V_K` 有较高诊断性。

宽恕/回来：

```text
P(O_return = 1 | F_Z = 1, Freedom = 1, NR = 1) 高
P(O_return = 1 | F_Z = 0, Freedom = 1, NR = 1) 低
P(O_return = 1 | F_Z = 0, Freedom = 0) 也可能高
```

因此：

```text
O_return 只有在 Freedom = 1 且 NR = 1 时，
才对 F_Z / W_Z 有高诊断价值。
```

## 11. 与自由回应可辨识性模型的关系

自由回应可辨识性模型说：

```text
正向亲密信号只有在其反向行动真实可用时，
才具有高诊断价值。
```

本文档进一步说明：

```text
即使反向行动已经恢复可用，
过去被污染的爱证据也不会自动变干净。
```

还需要：

```text
价值对齐信号
```

也就是：

```text
K 承认 Z 的规范判断；
K 不再用爱索取回应；
K 不把补偿转化为新的关系债务。
```

只有这样：

```text
O_love 才能从控制/补偿/软化的解释场中部分去污染。
```

所以二者关系是：

```text
自由回应可辨识性模型：
解决 “什么条件下回应有意义？”

价值对齐与证据去污染模型：
解决 “什么条件下被污染过的爱证据可以重新被解释？”
```

## 12. 一句话总纲

> 在强制关系中，爱不能直接成为修复证据，因为爱的观测已经被控制污染；修复需要强迫者先发出高层规范信号，使被强迫者确认双方共享“愿意不能被占有替代、后来不能抵消来路”的价值结构，随后爱的证据才可能被部分去污染，并重新获得诊断价值。

更短地说：

> 价值对齐不是奖励累积，而是让被污染的爱重新变得可解释。
