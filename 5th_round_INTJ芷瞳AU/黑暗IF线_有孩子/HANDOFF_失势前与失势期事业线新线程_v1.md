# HANDOFF：黑暗 IF 有孩子线——失势前与失势期事业线新线程

## 0. 给新线程的使用方式

这个 handoff 用于新开线程后，集中推进“卡瑞洛失势前、暗夜倒台前兆、东方倾城绑架计划、瓦雷斯失控、失势期间家庭与事业线交织”的正文。

不建议一上来把所有文档都读一遍。当前目录文档数量已经非常大，孕期、产后、母女线、Alba 第二部、和好后补丁、台湾追去 IF 都混在一起。新线程如果全量通读，很容易被旧阶段拖偏，反而写不准当前事业线。更好的方式是分层读取。

但“前史、孕期、母女线”不是可有可无的背景。它们是失势前事业线的情感地基：卡瑞洛为什么会有低配幸福，芷瞳为什么会在失势期仍然站在家这边，Alba 为什么已经让这个家变得真实，都要从这些阶段里来。因此新线程可以读这三组，但暂时不需要读后期分离、和好后、台湾追去 IF、第二部 Alba 发现真相等分支。

1. 先读“必读口径”和“当前事业线必读”。
2. 再读“当前承接试写稿”。
3. 补读前史、孕期、母女线，建立情感地基。
4. 写到具体失势重建阶段时，再查对应归档。
5. 后续分离、和好、第二部和其他 IF 分支暂不读，除非用户明确要求。

核心原则：新线程不是从头研究黑暗 IF，而是接住已经写到 Alba 两岁左右、幻影家庭稳定、暗夜倒台前兆开始压近的阶段。

## 4. 角色状态速记

### 4.1 卡瑞洛

当前卡瑞洛不是完全自罚状态。他仍然有一种抽象希望：也许有一天芷瞳会愿意。但他不太敢想具体场景，因为一想具体就会发现说不通。芷瞳没有真正被放到可以离开的路面前，她的温和不能证明她选择了他。

他已经进入“低配幸福”状态：

- 芷瞳在家。
- Alba 会叫爸爸妈妈。
- 芷瞳会管孩子。
- 晚饭有时还会留。
- 家里灯亮着。
- 东翼安静。

这些让他活，也让他羞耻。芷瞳对他好一点，他反而更容易良心发现。芷瞳冷，他可以把痛放进“我应得”；芷瞳温和，他会开始怀疑自己是不是正在利用她的善良、责任和秩序感。

失势不会击碎他的事业自我。他不是因为权力没了就崩。他的工作能力、家族责任感、Te、防御力都很强。真正被击中的，是他不能再用“我能保护她、给她稳定生活”替代“她有没有选择”。

### 4.2 芷瞳

芷瞳当前已经很能当妈妈了，但不是传统温柔母性。她是 Ni-Te 式的照护：看书、观察、校正、判断、管作息、怕养坏、怕自己做错。Alba 的随机性让她焦虑，也一点点治她的强迫性控制。

她对卡瑞洛没那么怕了，但距离“温和主动”和“承认爱”还远。她会在具体事务上和他交流，会被他“我怕很多事，但不怕你管她”这类真话转移注意力，会开始意识到卡瑞洛也会怕。这个线索后面会通向她推断卡瑞洛强迫她怀孕的动机。

她平时不追问卡瑞洛工作，因为抽象不道德可以搁置；具体受害者、台湾、绑架、东方倾城这样的词一旦靠近，她就不能再把它当作远处的 Te 系统。

### 4.3 Alba

Alba 是这个阶段最重要的“家庭真实性”证明。

她不是修复工具，但她让父母不得不真实互动。她会可爱、会傻、会找爸爸妈妈，会把低信息量重复变成对卡瑞洛有意义的东西。卡瑞洛不是天生喜欢重复、低效、无聊的大人；Alba 是例外。她每一次“看”，都在确认他是爸爸，也确认这个家还在。

Alba 越可爱，越让这个偷来的家显得真实。也越让后续事业线压进来时刺痛。

### 4.4 雷厉风

雷厉风不是道德校准器。他的道德底线不比卡瑞洛高。他是高情商、高执行、高危险、高操作性的人。

在暗夜会议里，他不应该替芷瞳说话，也不应该像好兄弟心理咨询师。他更可能看懂卡瑞洛被家庭牵住，也看懂暗夜这局不稳。他可以笑，可以调侃，可以用一句话点出卡瑞洛不愿承认的东西，但他的基本立场仍然是操作、局势、生存，不是伦理。

东方倾城对雷厉风是裂缝，因为她不是陪他待在黑暗里的人，而是让他看见自己在黑暗里的人。奥菲丽雅则是陪他腐烂的人。这条线在绑架后会变得重要。

## 5. 暗夜会议写作口径

下一稿如果写瓦雷斯会议，建议主轴如下：

1. 卡瑞洛在瓦雷斯，意识流视角。
2. 会议空间不是现代董事会，而是中世纪古堡里的高压犯罪秩序。
3. 牧师作为暗夜领导者压场，雷厉风在场，葛瑞或类似粗粝高层在场，另设一至两名分别代表资金/合法外壳与安保/撤离线的高层。蔡不是常驻高层，只在会议推进到诱饵执行细节时按议程被召入，接受询问并确认自己的真实动机；不要让他与牧师、卡瑞洛等人平级参与战略决策，也不要塞太多人。
4. 争论核心不是“要不要做坏事”，而是“现在不出重手，东方家继续切暗夜生意；出了重手，后续成本可能更大”。
5. 卡瑞洛把账摊出来：收益、暴露点、后续成本、东方旭拿到公开开战理由、官方力量可能介入、谈判主动权流失。
6. 其他人刺他：你有意大利根基、有姓氏、有账户、有能回去的房子、有女人、有孩子、有干净餐桌、有以后，所以你当然能等。
7. 卡瑞洛不辩解私事。他只继续讲风险。
8. 他越冷，别人越恨，因为他的冷静本身来自一种他们没有的退路。
9. 雷厉风可以笑，但不要写成道德站队。可以让他看出卡瑞洛被刺，也知道卡瑞洛的反对不是胆小，而是账确实难看。

注意：会议正文不要让作者解释“结构体面”。让别人一句脏话、一个讥讽、卡瑞洛没有抬眼、雷厉风笑了一下，去露出这个结构。

## 6. 东方倾城绑架计划的待定设计

这部分还需要新线程继续设计，不要直接照原作。

原作要点：

- 原作里芷瞳在台湾，卡瑞洛可以作为诱饵去钓东方倾城。
- 雷厉风黄雀在后绑架东方倾城。
- 现场还有几个暗夜高层。

有孩子 IF 的变化：

- 芷瞳在意大利私宅。
- 卡瑞洛不适合亲自做诱饵，也不一定去现场。
- 卡瑞洛更像战略家/风控者，不是现场行动者。
- 雷厉风仍然最适合执行。

建议方案：

- 蔡姓男子曾是台湾政商体系中的重量级人物，因金融弊案、巨额债务与东方旭揭发而垮台，后在警方追捕下假死；他当前没有独立势力，是暗夜庇护的高级逃犯/历史资产，不是暗夜高层。
- 蔡平时不常驻瓦雷斯，只因本次行动被临时召来。他答应返台并不只是服从命令，也是真的想见过去一直较包容他的姐姐。
- 蔡以“把一只装有个人旧物与零散旧纸张的盒子交给姐姐保管”为由，在围城安排见面。盒子不是足以解决一切的关键证据，只负责使私人赴约理由经得起初步调查；真正的诱饵是活着的蔡本人。
- 姐姐可能不来、报警或派代理人。即使姐姐不到场，蔡的复活也可能引来东方家核实；但东方倾城未必亲自出现，也可能派西门如月、东方倾国、灭明或“鬼”。
- 雷厉风只在出现具有足够谈判价值的东方家核心目标时执行绑架；不能为了不空手而临时抓一个外围人员。计划必须预设等待期限、警力阈值、暴露阈值与撤离窗口。
- 卡瑞洛总体不喜欢这个方案。他不反对利用人情，而是认为蔡的真愿望、姐姐的选择、东方家的派员层级以及东方旭是否妥协属于不同控制链，不能把数个“可能”直接相乘成“必然”。
- 行动后蔡由暗夜立即撤出台湾并暂时安置、看管于瓦雷斯附近，既防止他被警方捕获，也防止他因见过姐姐后产生新的个人行动；这可与原作中东方倾城在瓦雷斯认出他的场景衔接。
- 计划执行后，因为东方倾城身上的隐藏定位器，瓦雷斯被外部力量穿透。

这个方案需要正文前再打磨逻辑，不要随手写。

## 8. 禁忌和易错点

- 不要把卡瑞洛写成突然圣人。
- 不要把雷厉风写成道德审判员。
- 不要把暗夜其他高层写成蠢反派。
- 不要让瓦雷斯会议像公司董事会。
- 不要让芷瞳过早知道东方倾城计划细节。
- 不要让卡瑞洛向芷瞳解释工作压力。
- 不要让卡瑞洛主动卖惨。
- 不要让芷瞳突然变成侦探或政治行动者。
- 不要用太多“台湾是芷瞳的家”这种明说。让电话、父母、旧照片、语言、新闻词汇来承担。
- 不要把卡瑞洛控制欲写成翻芷瞳私人物品。他的控制是结构控制，不是低级窥私。
- 不要让卡瑞洛在会议里用芷瞳和 Alba 为自己辩解。他不会。
- 不要让暗夜高层知道太具体的米兰私宅生活。他们可以知道“意大利那边”“女人孩子”“家里”，但不要像读者一样全知。
- 不要把“失势”写成纯事业失败。真正刺的是亲密资格。

## 9. 一句话总纲

失势前的卡瑞洛不是还没有得到家，而是已经得到一个低配但真实的家；事业线的残酷之处在于，暗夜倒台不是简单把他的权力打碎，而是把他一直挡在书房外的黑暗推到东翼门口，让他再也不能用“我能保护她们”回避“她有没有选择”。
