# 文风规范｜前期正文非线性意识流 v1

## 适用范围

这份规范主要用于黑暗 IF 有孩子线的前期正文，尤其是从“强迫执行临界”到“怀孕确认”前后这一段。

这一阶段的核心不是剧情事件本身，而是事件之后留下的心理悬置、身体后果、权力边界和无法明说的恐惧。因此正文不应该写成动作戏、流程戏或心理分析稿，而应该写成一种贴近人物意识的非线性叙事：动作可见，物件反复回来，心理压力在段落里慢慢流动。

## 核心原则

### 1. 动作嵌在意识里，不单独摆动作

动作必须清楚，但不能像分镜表一样一下一下列出来。

不理想：

```text
卡瑞洛走过去。

他坐下。

他拿走书。

她僵住。

他让她躺下。
```

更合适：

```text
卡瑞洛走过去时，每一步都放得很慢。芷瞳的手指还压在书页上，那点阻力轻得不像要拦，只像她已经忘了怎么松开。他等了一会儿，才把书从她膝上拿走。纸页合上的声音很轻，房间里却像因此空了一下。
```

动作仍然发生，但动作本身携带心理压力。

### 2. 用物件承载心理，不直接解释心理

这一阶段最重要的叙事工具不是概念，而是物件。

可反复使用的压力载体包括：

- 水杯
- 托盘
- 门外脚步
- 外间的灯
- 书页
- 日期
- 薄毯
-窗边
- 血样
- 医生手里的纸

这些物件不能只是道具，而要在不同场景里改变意义。

例如水杯：

- 第一层：卡瑞洛的照料。
- 第二层：芷瞳知道他仍然在监看她的状态。
- 第三层：她喝水这个动作会回到卡瑞洛那里。
- 第四层：照顾和控制在她那里无法完全分开。

物件反复回来时，不需要每次解释完整意义。只要让它在新的场景里再次出现，读者会感到压力累积。

### 3. 长段意识流为主，短句只用于落点

前期正文不适合大量短句堆叠。短句太多会像提纲、动作清单或 AI 式分解，容易把情绪打散。

更合适的节奏是：一段里有动作，有心理，有物件，有回声，让压力在一个段落中慢慢变形。

短句可以用，但只用于真正需要断裂、刺痛、落地的地方。

适合短句的位置：

```text
他不是放手。

只是退到了门外。
```

```text
他们谁都没有问。

可那个没有声音的结果，已经在房间里坐下来了。
```

不适合短句的位置：

```text
她坐着。

他看着。

她没有动。

他也没有动。

房间很静。
```

这类写法会让场景变散，像在制造空白，而不是制造压力。

### 4. 不写“说明腔”，把分析压回场景

正文里不要频繁直接写：

```text
这说明他很愧疚。
她觉得这是一种高级占有。
他此刻陷入自我厌恶。
她的防御系统启动了。
```

这些可以放在修订口径或讨论归档里，不应该直接进入正文。

正文更适合这样写：

```text
他看见她只喝了两口水，没有再劝。现在每一句劝都太小，也太像一种补偿。
```

这里没有直接说“他愧疚”，但愧疚在动作里。

### 5. 视角必须守住身体位置

意识流不是万能镜头。人物看不见的东西不能写。

如果芷瞳背对卡瑞洛，卡瑞洛不能看见她的眼神。

可写：

```text
卡瑞洛看不见她的眼睛，只能感觉到她呼吸很浅。她的肩背一直没有真正松开。
```

不可写：

```text
她背对着他，眼神空茫。
```

如果芷瞳正面躺着，卡瑞洛坐在旁边就不能自然地拍背。要拍背，必须让她侧躺，或者让卡瑞洛躺在她身后。

身体调度一旦不成立，情绪也会塌。

### 6. 克制不是抽离

卡瑞洛的克制不能总写成“收回手”“退开”“不再碰她”。在某些场景里，抽离反而会惊扰芷瞳，也会削弱安抚功能。

更准确的克制是：

- 不加码。
- 不索取。
- 不把靠近变成新的权利。
- 不要求芷瞳回应。
- 不把她的疲惫误读成愿意。

例如医生前夜：

```text
他仍然隔着薄毯抱着她，没有再靠近，也没有退开。不知过了多久，也闭上了眼。
```

这里的克制不是离开，而是维持一个不会继续侵入的姿势。

### 7. 卡瑞洛的痛要在功能性动作里流出来

卡瑞洛不是崩溃到不能工作的人。他会继续签字、问细节、处理撤回线路。越是系统继续运行，越能显出他私下那块空洞。

可写：

```text
消息进来，命令出去，瓦雷斯没有因为她房里的灯亮到天明而停下，卡瑞洛也没有出错。只是每一次有人推门进书房，他都会先抬一下眼。不是她。也不会是她。她不会来找他。
```

这种写法比“他很痛苦、很想见她”更有效。

### 8. 芷瞳的冻结不要写成冷静

芷瞳此时不是理性地分析局势，也不是冷淡地等待结果。她是被现实压到冻结，反应变慢，身体先于语言暴露恐惧。

可写：

```text
她没有哭，也没有问他为什么。她只是坐在那里，像整个人忽然从房间里退了出去。
```

不可写成：

```text
她冷静地接受了这个结果。
```

她不是接受，是暂时没有反应能力。

## 句子类型

### 推荐句型

使用中长句承载多层压力：

```text
她看得出来。也正因为看得出来，才更不想碰。那些东西不是伤害，甚至都是照顾，可它们每一样都说明卡瑞洛仍然在这里，仍然在通过这个房间的每一个角落碰到她。
```

动作、判断、反感、矛盾在同一段里流动。

### 谨慎使用短句

短句适合做刀口：

```text
他要这个结果。

他不能接受含糊。

可是那个结果如果真的回来，就是她最怕的事情落地。
```

但不能整篇都这样，否则会显得散、硬、像提纲。

### 避免 AI 式对照句

尽量少用：

```text
不是……不是……而是……
```

可以偶尔使用，但不能成为主要句法。

更自然的替代方式是把判断融进动作：

```text
她没有推开他。肩膀却缩得更紧，像连没有推开这件事都让她觉得难堪。
```

## 场景组织方式

### 每一场只抓一个核心压力

不要同时写太多机制。

例如：

- 执行停止后空白：核心是“他退开了，但没有真的放开；她暂时安全，却仍在他的世界里”。
- 月事推迟：核心是“外部推进停止，身体结果开始逼近”。
- 医生前夜：核心是“她被悬置磨到睡不着，他不得不用靠近来让她睡”。
- 抽血确认：核心是“确定性从她身体里被取出，又以结果的形式返回”。

每一场都可以有多个动作，但只能有一个主压力。

### 物件回声要跨场延续

同一个物件可以在不同篇里承担不同层次。

例如“书”：

- 执行停止后空白：她拿着书但没有看，表示身体还在房间里，意识不在阅读中。
- 月事推迟：同一页反复停住，表示时间卡住。
- 医生前夜：卡瑞洛拿走书，表示她连假装阅读的支撑都被放下。

这样物件会形成连续性，而不是每篇重新开始。

## 禁忌写法

### 1. 不要把正文写成心理总结

不写：

```text
卡瑞洛意识到自己既期待又羞耻。
```

改成：

```text
每一次走廊里响起脚步声，他都会先抬眼。不是医生的时候，他会继续低头。下一次脚步声响起，他还是会抬眼。身体比他诚实。它在等。
```

### 2. 不要把医生戏写成流程戏

医生问诊和抽血只保留必要切口。

重点不是医学过程，而是：

- “七天”被说出口。
- 血样从她身体里被取走。
- 结果以纸的形式回来。
- 卡瑞洛要确定性，也厌恶自己要确定性。

### 3. 不要为了痛而机械加码

例如“天快亮时才睡着”不能滥用。前一夜已经几乎没睡，下一夜如果继续熬到天亮，会让场景像作者在折磨人物，而不是人物处境自然发展。

痛感要来自结构，不要来自无止境耗损。

### 4. 不要让卡瑞洛过度冷静

他可以工作不出错，但内里不能像稳定危机管理。他的动作越平稳，越要有某个细节泄露他已经被打穿。

例如：

- 文件翻过去又翻回来。
- 每次有人推门都先抬眼。
- 问“脸色呢”后不再问。
- 吩咐水和食物时意识到这些都太小。

### 5. 不要让芷瞳过度理智

她可以不说话，可以不哭，可以坐得很直，但这不是理智冷静，而是冻结。

她的防御要通过身体写：

- 手指攥住书页。
- 肩膀轻轻僵住。
- 把薄毯拉住。
- 看着自己的手，像那双手和她没有关系。
- 不拿书，不碰食物，只喝两口水。

## 示例：同一信息的两种写法

### 太散的版本

```text
医生来了。

芷瞳很害怕。

卡瑞洛也很痛苦。

医生要抽血。

芷瞳把手伸出去。

卡瑞洛看着她。

他很自责。
```

### 本线推荐版本

```text
后来医生说需要取血。

芷瞳没有立刻动。比起前面那些问题，这句话反而让她安静得更厉害。问话还可以少答，可以摇头，可以含糊过去；血不行。血被取走，就会带着她身体里的东西离开她，变成一份纸上的结果，再被送回这个房间。

她把手伸出去。

这个动作很轻，却让卡瑞洛胸口发紧。他站在不远处，没有替她说话，也没有走近。她的袖口被卷起来，露出的手臂白得刺眼。针刺进去时，她肩膀缩了一下，他几乎往前动，最后仍然停住。
```

## 总结

这一阶段的正文要像意识流小说，而不是剧情梗概、动作戏或心理分析稿。

最重要的不是“发生了什么”，而是“发生过的事情如何通过水、门、书、日期、薄毯、血样这些具体物继续留在房间里”。

动作要准确，视角要守住，句子要让压力流动。短句只在刺点处落下。人物不能把话说清楚，所以正文也不能替他们说得太清楚。
