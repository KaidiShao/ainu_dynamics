# 游戏设计归档｜多 IF 叙事与证据污染机制 v1

归档日期：2026-06-12

## 0. 设计起点

本归档整理一个基于《爱奴》INTJ 版芷瞳 AU 的互动叙事游戏构想。

最初的想法是把当前已经发展出的多条 IF 线做成游戏：主线、黑暗 IF 有孩子线、重生柔和 HE 线、原作式恶魔线、Alba 视角调查线等，都可以作为可进入、可拼接、可回看、可互相照亮的叙事分支。

进一步讨论后，形成一个更有趣的双层设计：

> 表层是档案式多 IF 叙事游戏。  
> 底层是隐藏的双主体动力学系统。  
> 玩家以为自己在选择剧情路线，实际上每次选择都在改变“愿意是否还能被证明”。

这个游戏不适合做成普通恋爱游戏，也不适合只做“好感度 +5 / 黑化值 +10”的数值游戏。它的核心不是追求某个角色留下，而是追求“她留下”这件事是否仍然具有解释力。

最核心的一句话是：

> 你可以得到她在场。  
> 但你可能失去证明她愿意的条件。

## 1. 游戏类型：档案式多 IF 叙事 + 隐藏动力学

游戏表层可以采用视觉小说、互动小说或档案调查游戏的形式。

玩家不会从头到尾线性扮演一个角色，而是在不同时间线、不同视角、不同档案片段之间移动。玩家通过阅读片段、选择进入某个分叉点、解锁另一视角、回看旧事件，逐步理解不同 IF 的形成机制。

适合的外观结构：

- 多周目视觉小说；
- 档案调查界面；
- 时间线碎片拼图；
- 多视角心理悬疑；
- 文学化互动叙事；
- 隐藏变量驱动的关系动力学模拟。

但底层不需要向玩家明说“这是 active inference”或“双主体模型”。这些理论应当像小说里的地基一样隐藏在机制里。

玩家看到的是：

- 某句台词在不同路线里变了；
- 同一个动作在不同结构里意义不同；
- 同样是“她留下”，有时是愿意，有时是污染；
- 同样是“他退开”，有时是尊重，有时是自罚；
- 同样是“她没有拒绝”，有时是亲近，有时是误判；
- 同样是“孩子存在”，有时是家庭，有时是结构绑定，有时是代际反噬。

游戏真正让玩家体验到的是：

> 关系里的证据会被控制污染。  
> 结果到手，不等于意义成立。  
> 越想证明愿意，越可能破坏愿意可被证明的条件。

## 2. 核心机制：证据污染

本游戏最核心的机制可以命名为“证据污染”。

普通恋爱游戏里，玩家的目标通常是提升好感度、解锁亲密、达成结局。但在这个 AU 游戏里，最重要的不是“芷瞳是否留下”，而是：

> 她留下这件事，还能不能被解释成愿意？

如果玩家通过控制、威胁、现实绑定、剥夺出口来让她留下，那么结果短期看似成功，但这个结果本身的证据价值会下降。

也就是说：

- 她留下了，但不一定说明她愿意；
- 她没有拒绝，但不一定说明她接受；
- 她照顾孩子，但不一定说明她认可这段关系；
- 她回到家里，但要看她是否仍然可以不回来；
- 她说“我原谅你”，必须在她可以不原谅时才有意义；
- 她说“我爱你”，必须在她可以离开时才有诊断性。

因此，游戏不应只追踪“结果”，还要追踪“结果的可解释性”。

可以设定隐藏变量：

- `自由度`：芷瞳现实上是否还有离开、拒绝、不回应的可能。
- `恐惧`：卡瑞洛对失去芷瞳的恐惧水平。
- `控制冲动`：卡瑞洛使用现实权力解决情感不确定性的倾向。
- `愿意可判别性`：芷瞳的行为还能多大程度证明她的自由愿意。
- `证据污染`：控制越强，留下、沉默、照顾、回头等行为越失去解释力。
- `羞耻`：卡瑞洛被看穿欲望结构后的防御强度。
- `自我审判`：卡瑞洛对自己行为的罪感和后续克制。
- `芷瞳防御`：芷瞳将爱藏进公正、温和、母职和沉默里的程度。
- `宽恕可发生性`：芷瞳是否已经拥有足够自由，因此宽恕不再等同于妥协。
- `代际反噬`：Alba 作为自由主体反过来拆解父母结构的可能性。

这些变量不一定公开显示。更适合让它们体现在文本变化里。

例如：

- 同一句“她没有离开”，在低污染路线里写得柔软，在高污染路线里写得沉重。
- 同一个“卡瑞洛把水留下”，在主线里像照顾，在黑暗 IF 里像补偿。
- 同样是“芷瞳看了他一眼”，在甜期里是动心，在稳态里可能是公正，在和好后才重新变成爱。

## 3. 核心体验：不是赢得她，而是保留愿意的可证明性

这个游戏不应奖励玩家“把芷瞳留住”。

它应该奖励玩家保留芷瞳自由回应的条件。

这意味着很多看似有效的选择都是陷阱：

- 派人看紧她：短期降低离开风险，长期提高证据污染。
- 用孩子绑定她：强行生成长期结构，但大幅破坏愿意可判别性。
- 戳穿她的自保策略：短期赢得高位，长期让她撤回心。
- 提前替她解决所有困难：提高生活质量，但降低她主动求助的可能。
- 用痛苦要求回应：可能触发心软，但污染回应。

反过来，很多看似危险的选择才是通向 HE 的条件：

- 允许她拒绝；
- 不戳穿她的防御；
- 在她可以离开时仍然让她离开；
- 让她知道你看见了，但不羞辱她；
- 在你有能力控制时选择不控制；
- 在她回来时不把回来当作胜利。

因此，这个游戏的真正主题不是“怎样得到爱”，而是：

> 怎样让爱仍然有资格被称为爱。

## 4. 表层结构：多 IF 档案宇宙

游戏可以从一个档案界面开始。

玩家面对的不是一条线性剧情，而是一组破碎档案：

- 主线分离篇；
- 黑暗 IF 有孩子线；
- 重生柔和 HE 线；
- 原作式恶魔线；
- Alba 视角调查线；
- 芷瞳研究笔记；
- 卡瑞洛自我审判片段；
- 家族会议记录；
- 旧情人访谈；
- 巧芙证词；
- 台湾家中对话；
- 管家 / 仆人 / 司机视角的边缘记录。

玩家可以进入片段，也可以在关键节点做选择。某些选择不会立刻改变当前片段，但会改变后续档案能否解锁，以及同一事件在另一视角中的文本。

这非常适合当前 AU 的非线性意识流气质。

玩家不是按时间顺序读完所有事，而是在不同线之间慢慢发现：

- 为什么主线能够甜；
- 为什么黑暗 IF 能长期稳定；
- 为什么重生柔和 HE 能避免最黑分叉；
- 为什么 Alba 不是修复工具，而是自由主体；
- 为什么芷瞳的宽恕不是妥协；
- 为什么卡瑞洛的放手不是失败，而是愿意重新变得可证明的条件。

## 5. 可游玩路线草案

### 5.1 主线 HE：自由之后的愿意

主线的核心是：

> 卡瑞洛学会放手，芷瞳在自由中确认自己愿意。

这条线的关键不是让芷瞳一直留在身边，而是让她拥有足够真实的离开可能。只有在她可以不回来时，她回来才有意义。

主线可游玩关键点：

- 冷战爆发后如何处理芷瞳的防御；
- 日本救援后是否追；
- 分离期如何承受失去；
- 是否把手下报告当成控制工具；
- 回归第一场是否把她回来当作胜利；
- 是否允许她对过去重新命名。

主线的胜利不是“她没有走”，而是“她走过以后仍然回来”。

### 5.2 黑暗 IF 有孩子线：恐惧压过愿意

黑暗 IF 的核心是：

> 卡瑞洛无法承受芷瞳没有理由留下，于是用孩子制造不可撤回结构。

这条线不是没有爱，而是爱被不自由污染。

可游玩关键点：

- 日本后伤口暂代关系；
- 卡瑞洛是否承认自己无法承受她撤回心；
- 是否把孩子作为现实绑定；
- 芷瞳怀孕确认后的处理；
- Alba 出生后是否形成幻影家庭；
- Alba 长大后如何发现真相；
- Alba 是否带走芷瞳；
- 卡瑞洛是否追。

这条线里玩家可能短期获得高度稳定的家庭结构，但代价是愿意可判别性被严重污染。最后由 Alba 作为自由主体反噬结构。

### 5.3 重生柔和 HE：被看穿后仍被保护

这条线的分叉点在冷战爆发处。

正常线里，卡瑞洛发现芷瞳利用他的欲望结构后，被羞耻刺中，于是戳穿她、压回高位、说狠话。这会让芷瞳觉得：原来我自保的靠近在你这里会被审判。

重生柔和 HE 线里，卡瑞洛知道她在利用他，却不戳穿。

他接住她。

他不说破，不让她难堪，不把她的自保命名成欺骗，也不立刻要求她承认靠近。他只是持续对她好，甚至更温柔、更稳。

后来芷瞳发现他早就知道，会被深深震动：

> 原来不是你没看懂。  
> 是你看懂了，却没有用它伤害我。

这条线的甜在于：卡瑞洛提前学会了黑暗 IF 后期才明白的东西。

> 我想要你愿意，所以我不能把你的防御逼成认罪。

### 5.4 原作式恶魔线：外放的威胁与牺牲

原作式路线更外放、更戏剧化。

这里卡瑞洛会用“恶魔面具”夺回芷瞳。他可以威胁家人，可以说很狠的话，可以用最黑的方式遮住“我离不开你”。

这条线的关键不是现实绑定的冷结构，而是高强度戏剧冲突：

- 三年失去；
- 台湾夺回；
- 威胁家人；
- 牧师、瓦雷斯、火场；
- 牺牲自己保护芷瞳；
- 最终还自由。

这条线可以和黑暗 IF 对照：

- 原作式线是“我可以毁掉你在乎的人，所以你回来”；
- 黑暗 IF 是“我没有理由让你同意，所以我不要求你同意，但我还是做”。

两条线都黑，但黑法不同。

### 5.5 Alba 视角调查线：孩子成为自由主体

Alba 线是后期最适合做成档案调查玩法的部分。

玩家从女儿视角进入，最开始看到的是一个看似体面的家：

- 父亲强大、克制、爱母亲；
- 母亲聪明、温和、负责；
- 管家称呼“夫人”；
- 家族场合里所有人都默认这个结构；
- 父母之间没有明显争吵。

但细节逐渐不对：

- 父母没有婚礼；
- 母亲从未真正回过自己家；
- 中文名字“知遥”像隐秘线索；
- 父亲谈起母亲时有时只说“她”；
- 旧人提到拍卖场；
- 巧芙的存在浮出水面；
- 母亲对“怕不怕父亲”的回答让她听出不平等。

Alba 线的核心不是“揭露父亲是坏人”，而是她学会识别：

> 爱是真的。  
> 但不自由也是真的。  
> 如果母亲不能选择离开，那我算什么？

最终她带走芷瞳，不只是质问父亲，也动之以情和诱惑父亲：如果你不给她一次选择机会，你怎么知道她怎么想？

## 6. 关键节点设计

### 6.1 冷战爆发点

这是多条线的核心分叉点。

玩家可能选择：

- 戳穿芷瞳；
- 装作不知道；
- 退回高位；
- 继续对她好；
- 用身体确认；
- 给她更多空间；
- 要她看自己；
- 不要求她承认。

这里不是简单“温柔 = 好结局”。如果只是压抑自己但内心继续算账，后续仍然可能爆。真正关键是：卡瑞洛是否能理解芷瞳也有苦衷，是否能不把她的自保当成对自己的否定。

### 6.2 日本救援后

这是主线和黑暗 IF 的核心分叉点。

玩家面对的不是“追 / 不追”这么简单，而是：

- 是否能承受她可能不回来；
- 是否把伤口当作正当靠近理由；
- 是否试图制造不会愈合的理由；
- 是否能区分失去她和失去她的愿意；
- 是否把恐惧变成控制。

这里如果选择孩子绑定，会进入黑暗 IF。

### 6.3 执行临界

这是黑暗 IF 中最黑的节点。

玩家不能把它写成情色选择或一次失控。它是恐惧、原始愿望、现实绑定和自毁的合流。

核心台词：

> “你、你想干什么？”  
> “我要你怀我的孩子。”  
> “你不能这样。”  
> “我能。”

这个节点的变量变化应当极大：

- `证据污染`大幅上升；
- `芷瞳防御`从低落切为应激；
- `卡瑞洛自我审判`上升；
- `愿意可判别性`急剧下降；
- `未来修复难度`大幅增加。

### 6.4 Alba 带走母亲

这是黑暗 IF 的反噬节点。

Alba 不是系统外来的正义使者，而是错误结构内部长出的自由主体。她继承了父亲的判断力，也继承了母亲教她识别恐惧包装成判断的能力。

她带走芷瞳时，卡瑞洛面对的不是外敌，而是自己的孩子。

这会让追与不追不再是简单权力选择，而是他是否终于承认：

> 恐惧不是事实。  
> “我承受不了”不是理由。  
> 如果她不能选择离开，留下就仍然不能证明愿意。

## 7. UI 与叙事表现方式

适合的 UI 不应太像恋爱养成。

可以考虑：

- 档案柜；
- 多时间线地图；
- 碎片化回忆房间；
- 人物视角切换；
- 事件节点图；
- “证据”而不是“好感度”；
- 文本颜色或边缘注释暗示污染程度；
- 同一句话在不同路线中出现不同解释。

隐藏变量不要用数值条直接显示。

更适合用文本反馈：

- “她没有离开。”  
  低污染版本：她在门口停了一会儿，最后回头看他。  
  高污染版本：她没有离开。门口的人也没有动。

- “他退开。”  
  主线版本：他把选择留给她。  
  黑暗 IF 稳态版本：他退得太快，像连自己的需要也不敢让她看见。

- “她没有拒绝。”  
  甜期版本：她没有拒绝，甚至闭了一下眼。  
  黑暗 IF 版本：她没有拒绝，因为她已经知道拒绝没有用。

同一事件的意义应由结构决定，而不是由动作本身决定。

## 8. 结局设计

结局不应简单分为 HE / BE。

更适合按“愿意是否恢复可证明性”来分类。

可能的结局：

### 自由回归结局

芷瞳拥有真实离开可能，最终选择回来。

关键不是回归，而是她可以不回来。

### 幻影家庭稳态结局

家存在，孩子成长，日常温暖，但愿意可判别性长期被污染。

这不是纯 BE，而是“真实被污染的稳定态”。

### Alba 反噬结局

孩子长大后拆解父母结构，带走母亲，迫使父亲面对恐惧。

这是黑暗 IF 的核心开放修复路线。

### 柔和 HE 结局

卡瑞洛在冷战爆发点接住芷瞳，没有戳穿她。芷瞳后来发现他早就知道，意识到自己被看穿却没有被羞辱。

这条线甜，但甜里有痛，因为玩家知道其他线他没有做到。

### 证据坏死结局

卡瑞洛持续使用控制换取结果，最终芷瞳仍在场，但所有行为都失去诊断性。她留下、照顾、沉默、甚至温和，都不能再证明愿意。

这不是死亡结局，但非常黑。

## 9. 现有素材如何转化为游戏内容

当前已有大量归档和试写稿，可以转化为游戏模块。

适合直接做成档案节点的内容：

- “夫人”称呼；
- 芷瞳生日；
- Alba 中文名“知遥”；
- 亲戚婚礼未婚线索；
- Alba 发现拍卖场；
- 旧情人 Elena；
- 卡瑞洛母亲“不像话”判断；
- 芷瞳回家见父母；
- 巧芙对照；
- 分离期父女相依为命；
- 芷瞳研究笔记；
- 卡瑞洛看不懂却意识到毁掉她人生可能性；
- 身体越界后的误读重解；
- 回归第一场“我原谅你”；
- 和好后重新解释“夫人”。

适合做成关键选择节点的内容：

- 冷战爆发点；
- 日本后是否制造现实绑定；
- 第一次执行临界；
- 怀孕确认后如何处理；
- 是否让芷瞳回台湾；
- Alba 质问父亲时是否追；
- 芷瞳回来后卡瑞洛是否把忏悔说清。

适合做成隐藏变量反馈的内容：

- 水杯是否被碰；
- 她是否看他；
- 他是否退开；
- 她是否主动问他吃饭；
- Alba 是否用“妈妈”还是“她”听见父亲提起芷瞳；
- 管家是否先看卡瑞洛方向；
- 芷瞳是否主动解释；
- 卡瑞洛是否把帮助写成规则。

## 10. 总结

这个游戏最有趣的地方，不是分支多，而是每条分支都在测试同一个核心问题：

> 爱要在什么条件下，才仍然能被证明是愿意？

主线回答：要有自由，要有离开可能，要有卡瑞洛真正放手。

黑暗 IF 回答：如果用现实绑定解决恐惧，爱仍然可能存在，但证据会被污染，孩子会成为结构和反噬。

重生柔和 HE 回答：如果卡瑞洛在羞耻点接住芷瞳，不把她的防御逼成认罪，就不必走向现实绑定。

Alba 线回答：错误结构内部也会长出自由主体，而这个主体最终会要求父母重新面对选择。

因此，这个游戏不是“选择正确选项得到好结局”。

它更像一个关系动力学迷宫。

玩家必须慢慢学会：控制可以得到结果，但会破坏结果的意义。真正难的不是让她留下，而是让她留下这件事仍然有资格说明她愿意。
