# 试写存档｜和好后：以为你不要我了 v3

芷瞳回来后的第三天，卡瑞洛把几份文件放到她面前。

台湾那边的账户、房产、信托，还有后来陆续补上的几项安排。纸页很薄，摊在桌上，却像把那几个月重新铺开了。

芷瞳看了一会儿，没有伸手。

卡瑞洛说：“这些还是你的。”

她抬头看他。

“你不用因为回来，就把它们退回去。”

他说得很平静。

芷瞳却忽然想起自己第一次看见那些安排的时候。那时她在台湾，父母在楼下说话，窗外有很潮湿的风。她看着那些签名和数字，终于明白那句“对不起”不是一时情绪。

他是真的在算。

在还。

也在退。

“我那时候以为你不要我了。”

她说得很轻。

卡瑞洛看着她，像没有立刻听懂。

芷瞳垂下眼。

“你发了对不起，又把这些都安排好。”她看着桌上的纸，“我以为你已经……算清楚了。”

房间里安静下来。

卡瑞洛终于明白她在说什么。

原来他的退开，也曾经让她这样想。

他绕过桌子，走到她身边。

芷瞳没有退。

“我怎么会不要你。”

他说得很快。

快到几乎不像他。

芷瞳抬眼看他。

卡瑞洛在她面前停下，声音低下来。

“你走以后，我每天都在想你。”

她的手指在桌沿轻轻收紧。

卡瑞洛看见了，却没有停。

“但我知道，我不能要求你回来。”

芷瞳很久没有说话。

那句话把她在台湾时反复猜过的东西，终于放到了一个确定的位置上。

他不是不要她。

他只是不能再要她。

“我知道。”

她停了停。

“我后来知道。”

卡瑞洛低头看她。

芷瞳声音更轻。

“你那时候也很难。”

这句话仍然让他沉默。

他习惯把那几个月放进罪有应得里。芷瞳这样说，像把他从那里面看见了。

她又说：“我也没有办法不想你。”

卡瑞洛的呼吸停了一瞬。

芷瞳说完，脸上有一点很淡的窘迫，像这句话比桌上所有文件都更难签字。

卡瑞洛伸手。

她没有躲。

下一刻，他把她抱住。

不是很轻。

也不是失控。

只是终于不用再隔着那些文件、那些账户、那些体面的安排和她说话。

芷瞳起初没有动。

过了一会儿，她抬手，抓住他背后的衬衫。

卡瑞洛抱得更紧了一点。

她的脸贴在他胸口，声音闷在那里。

“我以为你真的要把我还回去了。”

卡瑞洛闭了一下眼。

“我还不起。”

芷瞳安静下来。

桌上的文件被风吹动一角，很轻地响了一声。

卡瑞洛低头，吻了吻她的发。

“那些是你的。”

他停了停。

“我也是。”

芷瞳没有立刻说话。

只是抱住他的手慢慢收紧了。
