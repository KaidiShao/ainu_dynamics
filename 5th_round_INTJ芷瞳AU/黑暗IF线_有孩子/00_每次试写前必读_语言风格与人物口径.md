# 每次试写前必读：语言风格与人物口径

## 使用规则

本文件是黑暗 IF 线试写前的中心规范。以后凡是写“黑暗 IF 线（有孩子）”的新片段、续写、改写、重写，关于语言风格、人物口径、叙述方式，只读本文件即可，不需要再临时翻散落在旧试写稿开头的点评。

如果是在改某一篇既有试写稿，可以额外读取那篇试写稿本身，以确认承接内容；但风格校准、人物声线和禁忌项，以本文件为准。

用户在当前对话中给出的最新指令优先级高于本文件。本文件用于防止输出自动滑回说明腔、理论腔、翻译腔、过度对话、人物动机错位。

## 触发词规则

凡用户提出“试写 / 重写 / 改写 / 续写 / 写一稿 / 写写看”等请求，默认必须先读取本文件，再进行正文输出。

用户只说“试写”，或在请求中出现“试写一下”“写一个版本”“重写一稿”等近似表达，也视为触发本规则。

本规则用于主窗口和新线程：只要任务属于黑暗 IF 线（有孩子）的正文试写、片段改写、意识流重写或场景续写，就应先读本文件，再开始写。

## 示例使用原则

本文件里的具体事件、物件、台词、线索都只是当前已经讨论出的可用例子和素材池，不是封闭清单，也不是剧情上限。

试写时可以使用这些例子，也可以发展新的生活事件、外部事件、家族事件、育儿细节、身体细节和研究细节。唯一要求是：新增内容必须符合阶段、人物声线和关系结构，不能为了服务理论点而临时发明一个不自然的装置。

因此，看到“例如”“可以”“优先使用”时，都应理解为：这是已验证方向，不是所有可能方向。

## 一句话总纲

黑暗 IF 线不是“没有爱”，而是爱被不自由结构污染；正文不能解释这个结构，而要让它从日常安排、身体停顿、空间距离、称呼、孩子的目光和沉默里露出来。

理论在地下，诗在地上。结构在骨头里，不要直接长在皮肤外面。

## 硬口径

- 女儿名字固定为 `Alba`，不得另起名。
- Alba 的中文名字为“知遥”。这个名字可以成为后期她理解母亲处境时的隐性线索之一，但不是唯一线索。
- 这条线的孩子不是圆满符号，而是内部结构、现实绑定和代际反噬的核心。
- 芷瞳不是因为不爱才不能回应，而是不能让爱替当年的错误押注签字。
- 卡瑞洛不是不爱，也不是单纯施害者。他有罪、有魅力、有长期付出，也有持续自我审判。
- 黑暗 IF 的核心问题不是“卡瑞洛对芷瞳不好”，而是“即使他后来对她很好，不自由仍然污染一切”。
- Alba 不是修复父母的工具，而是父母错误关系内部长出的自由主体。
- 第一部主要是卡瑞洛视角，第二部再转 Alba 视角。芷瞳侧片段可以写，但要清楚它在结构中的位置。
- 芷瞳被 Alba 带走以后，不是马上回来。她会有半年到一年左右的自由期，确认自己可以不回去，也确认自己想回去不是因为孩子、怜悯、愧疚或担心卡瑞洛撑不住。
- 芷瞳主动回来不是结尾，而是重新相处、重新命名旧日温柔和迟到甜的开始。
- 卡瑞洛没有见过芷瞳父母。不是客观不能安排，而是芷瞳没想带，他也没脸主动进入那个位置。
- 卡瑞洛听得懂日常中文对话，但中文空间不自动向他开放。Alba 会说中文，母女之间有稳定中文交流。
- 卡瑞洛通常不会在 Alba 面前直接叫“芷瞳”，更多说“你妈妈”。但在失控或被刺中时，他会只说“她”，因为“她”已经是不需说明的唯一对象。
- 芷瞳通常不叫“卡瑞洛”。因为这是姓，不是亲昵称呼；她更多说“你”，或者直接说事情。
- 瓦雷斯阶段不写“管家”，也不写“女仆”。按照原作语感，这里是仆人、手下、医生、守在外间的人，带有临时据点、执行命令和黑暗组织的冷硬感。
- “管家 / 夫人 / 家宅秩序”属于后期独立住宅和幻影家庭阶段。那里可以写管家、下人、司机、安保、医生等长期运转的家族基础设施，但也尽量不用“女仆”，需要时写仆人或下人。

## 正文语言禁忌

### 不要说明腔

正文不要直接替读者解释：

- 这不是家，而是笼子。
- 她终于意识到安稳不是自由。
- 他爱她，但他没有资格要求她。
- 这说明他们都看见了部分真相。

这些是分析文档语言，不是正文语言。正文可以写成类似下面的具体承载物；这些只是例子，不是全部可用线索：

- 水杯的位置。
- 门口停住的脚步。
- 管家一句“夫人”。
- Alba 抬头问一个很普通的问题。
- 卡瑞洛把话咽回去。
- 芷瞳看见他瘦了，却一时不知道该怎么开口。

结论可以存在，但要从物件、动作、身体反应和空间关系里渗出来。

### 不要高密度短句堆结论

短句只能用于真正断裂、惊醒、失控、判决落下的瞬间。不能整段都写成：

他知道。
她也知道。
可他们都没有说。
这就是问题。

这种写法会变成 AI 味、心理惊悚诗、分析提纲。正常段落需要有呼吸，有具体场景，有句长变化。

### 不要“这不是 X，而是 Y”泛滥

“这不是 X，而是 Y”适合归档论述，不适合正文反复使用。正文中如果必须用，也只能在极少数关键处出现。

多数时候应改成具体描写。例如不要写“这不是照顾，而是补偿”，而是写卡瑞洛怎样把药、水、医生、房间、安静都安排好，又怎样在她醒来时站得太远。

### 不要把理论词放到人物嘴里

人物不能说后台术语：

- 冷战机制
- 高级占有
- 稳态
- 自我审判
- 半生押注
- 幻影家庭
- 结构性不自由

这些可以是归档词，不是人物台词。芷瞳可以说“在瓦雷斯的时候也是”，不能说“你又回到冷战机制里了”。

### 不要写成辩论

卡瑞洛和芷瞳的关键对话不是论文答辩。尤其和好后，他们应该更亲近，话更短，更准，更带身体温度。

如果一段对话里每个人都在完整解释自己的动机，通常就是错的。应删掉解释，让一句话、一个停顿、一个动作承担更多。

### 不要结尾画蛇添足

很多片段前面已经成立，结尾不要再补一句主题澄清。尤其避免：

- “我说的是家。”
- “她终于知道这意味着什么。”
- “这一次，他没有再逃。”
- “原来他们一直都在等这句话。”

如果动作已经说清楚，正文应该停在动作、安静、光线、房间、手、视线或未说出口的话上。

## 叙述方法

### 意识流优先

黑暗 IF 线试写原则上以意识流和自由间接叙述为主。除非场景本身必须依赖外部行动推进，不要写成简单动作戏。

动作只保留必要骨架：谁进来、谁停住、谁看见什么、谁说了哪一句。真正的正文重心应落在动作触发出的心理涌动、旧伤回声、误读、身体反应、空间压力和没有说出口的判断上。

但意识流不是把剧情摘要切碎，也不是把分析文档换成短句。它必须由当前现场牵出：

- 当前物件触发旧记忆。
- 当前称呼牵出旧羞辱或旧亲密。
- 当前身体反应暴露本人还没承认的感情。
- 当前空间距离让过去的关系位置短暂复现。
- 当前一句很普通的话让人物突然意识到自己已经变了。

如果一段只是“他走过去、她转身、两个人说话、然后离开”，而没有意识流层面的压力和回声，通常不适合这条线，除非它只是大段正文之间的极短过渡。

### 先有场景，再有意义

每一段试写先确认一个具体场景：

- 谁在场。
- 谁的视角。
- 当时是什么阶段。
- 他们刚经历过什么。
- 这个场景表面上在做什么。
- 真正刺中的是什么。

不能先拿一个理论点，然后随便编一个事件承载它。事件本身必须有生活逻辑。

### 非线性不是乱跳

黑暗 IF 可以写非线性意识流，但不能把剧情摘要切碎以后叫意识流。

可用方式示例：

- 当前动作触发记忆。
- 当前物件牵出旧场景。
- 当前称呼让旧伤短暂浮上来。
- 当前身体反应让她或他误认成过去某一刻。

错误方式：

- 先讲一段理论。
- 再插一段过去。
- 再解释这段过去意味着什么。
- 最后总结人物变化。

### 一个片段只推进半步

不要每一场都完成一个大结论。很多黑暗 IF 的美感来自“差一点”：

- 差一点问出口。
- 差一点承认。
- 差一点心软。
- 差一点回头。
- 差一点把旧事说清楚。

一场推进半步，长期积累才有十几年的重量。

### 让物件承担意义

优先使用具体物件和空间。下面是当前已经验证有效的素材池，不是限制：

- 水杯、药、医生记录、伞架、文件、蛋糕、生日蜡烛、没有署名的卡片。
- 门口、走廊、餐桌、书房外间、孩子房间、车后座、台湾家里的客厅。
- 管家称呼、司机装作没听见、亲戚在婚礼上闪烁其词。

这些比直接写“他们很痛苦”有效。

## 人物声线

## 卡瑞洛

### 基本口径

卡瑞洛不是低级控制狂，也不是机械施害者。他清楚自己犯了错，但前期仍有傲慢：他相信孩子、家、长期照顾、体面和自己的吸引力，终有一天能让芷瞳愿意。

后期他越来越知道这套押注可能只能生产出“妥协”，不是“愿意”。这就是他持续自我审判和越来越克制的来源。

### 表层

- 话少。
- 精准。
- 不轻易解释。
- 不卖惨。
- 不长篇忏悔，除非已经进入和好后的关键修复期。
- 不用很多“我怕你……”式台词。
- 不主动把自己放到受害者位置。

### 内层

卡瑞洛内心可以非常剧烈，但不是理性总结式剧烈。他的痛苦应该锋利、羞耻、自罚：

- 他想要她，但不能把想要变成要求。
- 他想被需要，却提前替她清掉所有可能需要他的痛点。
- 他想让她主动走向他，又不愿意让她因为无助才走向他。
- 他希望她温和是因为爱，又会把温和降级成公正、责任、心软。
- 他越敬重芷瞳的公正，越不敢相信她爱他。

### 行动方式

卡瑞洛的爱常表现为安排，而不是表白。下面是可用表现，不是所有表现：

- 药和水。
- 安全路线。
- 医生。
- 研究材料。
- 家庭聚会的尺度。
- 给 Alba 的解释。
- 让家里人尊重芷瞳。
- 退开。
- 不追。

但这些安排也会污染关系，因为芷瞳会觉得自由是他发放的。

### 台词规则

卡瑞洛可以：

- 沉默。
- 短命令。
- 冷幽默。
- 精准提问。
- 很短的自嘲。
- 在关键时刻说一句很狠的自我判决。

卡瑞洛不能：

- 长篇解释心理动机。
- 像治疗师一样复盘关系。
- 像辩手一样证明自己。
- 用可怜姿态逼芷瞳心软。
- 在明显知道自己不该继续时还继续言语试探。

## 芷瞳

### 基本口径

芷瞳不是冷漠分析机器。她敏锐、善良、执着公正，但她也会赌气、别扭、不愿宽恕。她的心魔不是“不坚持正义”，而是把宽恕误认为妥协。

需要区分阶段：和好前，芷瞳对卡瑞洛主要是温和但略有疏离，不是撒娇式孩子气。她可以被触动、可以心软、可以看见他的好，但仍然不愿主动给出明确回应。和好后，她对卡瑞洛才更明显地出现短促、直接、带一点孩子气的亲近表达。

对 Alba 则不同。芷瞳和女儿之间更亲近、更自然、更流动。她教孩子时可以犀利，也可以温柔引导；她不是在女儿面前保持对卡瑞洛那种疏离。

她后期要超越的不是判断力，而是防御。宽恕对她来说不是变世故，而是一种更高层的力量和行动。

### 叙述方式

芷瞳侧应是第三人称 + 芷瞳分析型自由间接叙述。不要告诉读者“她在分析”，而要让读者进入她的分析。

她的分析要从具体东西长出来：

- 旧房间。
- 语言。
- 身体余震。
- 没有写完的笔记。
- 药味。
- 卡瑞洛站得太远。
- 他又说“没事”。
- 他把水杯主动留下。

### 情感口径

芷瞳能感到卡瑞洛爱她，也能感到他对她好，但她很难确定这到底是爱，还是高级占有策略、孩子母亲位置、夫人位置、长期软化策略。

她不是完全看不见卡瑞洛的痛。很多时候她能感觉到，但她不想照顾这个痛，因为自己并不自由。

她不是每天痛苦。稳态时期有真实安稳、真实舒适、真实被照顾，也有很多被卡瑞洛吸引的瞬间。正因为生活有时候真的像家，才更酸涩。

### 台词规则

和好后，芷瞳对卡瑞洛可以直接、短、带一点孩子气：

- “哼。”
- “你又这样。”
- “在瓦雷斯的时候也是。”
- “我是有点心软。”
- “如果不是爱你，我也不会那么心软。”

和好前，尤其稳态期和分离前，她对卡瑞洛不应这样说话。那时更适合写：

- 温和但有距离。
- 体面地回应。
- 很短地说事。
- 被触动后没有立刻给出更多。
- 明明看见他的期待，却只给到“谢谢”“嗯”“你也去睡”这一类有限回应。

芷瞳不能总是：

- 逼问到底。
- 用理论词拆解卡瑞洛。
- 长篇说服卡瑞洛。
- 像审判者一样把所有话说清楚。

和好后她会更主动、更亲近，不需要写得像两个人还严格限制身体接触。

## Alba

### 基本口径

Alba 不是侦探工具，也不是剧情装置。她是从这个家内部长出来的人。

她小时候可能觉得父母感情很好，因为这个家运行得太稳定、太体面、太像幸福。她不是先发现“不幸福”，而是后来发现：稳定并不能回答妈妈能不能离开。

### 发现真相的路径

她的怀疑应从日常裂缝开始。下面只是当前可以使用的线索类型，不是全部线索：

- 为什么从没回过妈妈的家。
- 为什么亲戚问婚礼时闪烁其词。
- 为什么“夫人”这个称呼很自然，却没有真正名分。
- 为什么妈妈拥有很多家内权力，却不拥有离开的自由。
- 为什么父亲对妈妈的称呼在失控时只剩“她”。

不要让 Alba 一上来像查案。她先被刺到，然后开始问更好的问题。

### 和卡瑞洛对峙

Alba 至少 16 岁，她可以说很成熟的话。但成熟不等于上位。她质问父亲时同时有正义、伤心、歉意和对父亲的理解。

她不是单纯为了让卡瑞洛痛苦而质问。她要同时做到三层：

- 伦理上戳破他的自我辩护。
- 情感上让他看见自己把女儿也变成了维系关系的工具。
- 诱惑他：如果不给芷瞳一次选择机会，他怎么知道芷瞳真正怎么想。

卡瑞洛能看出她的劝说很准，也会为她骄傲，但这不需要明写成“她像谁”。可以让他在沉默里认。

## 身体关系口径

稳态期两人多半分房睡，身体关系频率不高。

原因不是芷瞳完全不愿意，而是卡瑞洛越来越害怕自己在强迫她。他不能接受芷瞳只是妥协，也不能接受自己用需求逼她心软。

关键场景可以写成以下方向；这些是已讨论出的核心机制，不是要求每一场都照单全写：

- 卡瑞洛从长期克制中露出裂缝。
- 芷瞳没有拒绝，而且并非痛苦地不拒绝。
- 卡瑞洛过程中可能越来越接近“求”。
- 芷瞳会被触动。
- 卡瑞洛第二天更克制，因为他以为她是心软、善良、不忍心。
- 芷瞳会误读成他暴露了策略失败的狼狈，又退回体面和高位。

不要写成卡瑞洛明知芷瞳抗拒还继续。如果芷瞳明确抗拒，他会停。

不要把身体关系写成纯伤害，也不要写成普通甜蜜。它的张力来自两个人都看见了部分真相，又都错过了最关键的一层。

## 幻影家庭口径

幻影家庭不是喜剧，也不是每日酷刑。它是酸涩、安稳、苦、偶尔有一点结构性荒谬。

卡瑞洛确实把芷瞳和 Alba 养得很好：

- 生活稳定。
- 尊重芷瞳在家里的判断。
- 给她研究空间。
- 尊重她教育 Alba 的方式。
- 让管家和家里人称她“夫人”。
- 尽量不让她为现实事务受苦。

但问题在于，这些自由和尊重多数是卡瑞洛给的。芷瞳接受它们时会有被道德绑架的感觉：如果她不承认这是好，好像就不公正；如果她承认，又像是在替不自由签字。

芷瞳做母亲、管家务、教育 Alba，不是顺从卡瑞洛，而是对孩子负责。但这客观上满足了卡瑞洛对“孩子母亲 / 家里女主人”的期待，也让她自己心里复杂。

卡瑞洛在幻影家庭中常有父亲被排除感：母女日常、教育、家务判断、孩子成长都形成芷瞳主导的自然秩序。他会孤独，但芷瞳不一定想补偿他。她能感觉到一点，却不想替他处理这个情绪缺口。

## “夫人”称呼口径

“夫人”是尊重，也是羞辱。

对外和对孩子来说，这个称呼维持体面。卡瑞洛也确实想让芷瞳做他的夫人。

但芷瞳没有真正选择这段关系，也没有自由和名分，因此“夫人”会提醒她：她被放进了一个卡瑞洛设好的位置。

早期她不会问，因为问了像是要名分。不问，则可以把它解释成“为了孩子和体面”。

卡瑞洛其实宁愿她问。反对至少说明她愿意在这个称呼上和他发生关系；不问说明她把这当成他体系里的又一条安排。

和好后可以重新聊起。卡瑞洛可以直接承认：“我确实想让你做我的夫人。”关键不是理性解释，而是他终于把“是我想”说出来。

## 分离期口径

Alba 带走芷瞳以后，芷瞳是在自己家 / 父母家，不是神秘藏匿地点。

这会更刺痛卡瑞洛：她只是回家，他更没有立场追。

卡瑞洛没有追，不是因为不痛，而是第一次发现“我承受不了”不是事实，只是恐惧。他以前不是不能承受失去芷瞳，而是不愿承受，所以才让她承受。

分离期卡瑞洛的痛不是激烈外放，而是弥漫性、日常性、服判式：

- 他不追。
- 不问。
- 不借 Alba。
- 不把痛苦变成命令。
- 听见 Alba 和芷瞳通话，不走近。
- 从 Alba 那里知道芷瞳继续研究，会意识到自己毁掉过她的其他可能性。

Alba 后期会更关心父亲。她帮助母亲离开，也等于让自己失去日常意义上的母亲。她对父亲有歉意，不影响她坚持正义。

## 回归后口径

芷瞳回来前，卡瑞洛默认她不会回来了。

芷瞳回来不是因为卡瑞洛撑不住，也不是因为 Alba，也不是因为怜悯。她在自由中确认自己爱他，也确认宽恕不是妥协。

第一次见面时，重点不是复述所有逻辑，而是：

- 卡瑞洛震惊到不敢动。
- 他叫“芷瞳”。
- 芷瞳被他的消瘦和这个名字触动。
- 她先关心他，才让他能说出自我判决。
- 卡瑞洛必须先承认自己的罪，芷瞳才更容易进一步说“我原谅你”。

回归后的甜不是轻松甜，而是迟到、旧伤重新命名、身体终于可以靠近的甜。

和好后两个人已经心意相通，不要写得像还在严格限制身体接触。芷瞳可以主动亲近，卡瑞洛也可以主动问、主动忏悔、主动倾吐。

## 常见错误清单

- 把芷瞳写成纯受害、纯冷漠、纯理性。
- 把卡瑞洛写成纯被动、纯惨、纯高尚或纯控制狂。
- 把 Alba 写成侦探、工具人、道德高位发言机。
- 为了承接理论，临时发明不清楚的课程、旧识、训练项目。
- 让人物说后台术语。
- 让对话承担太多解释功能。
- 让结尾加一句多余主题总结。
- 把稳定生活写成每天痛苦。
- 把身体越界写成单向侵犯或普通恋爱。
- 把卡瑞洛的自我审判写成冷静论文。
- 把芷瞳的宽恕写成妥协。
- 把“家”直接解释掉，而不是让它在日常里既成立又失效。

## 每次试写前检查

开写前先回答这几项，不一定写进正文。括号里的事件和刺点只是当前素材示例，不是封闭清单：

1. 这是哪个阶段：前期控制收紧、中期幻影家庭形成、稳态后期、Alba 发现真相、分离期、回归后等。
2. 当前视角是谁：卡瑞洛、芷瞳、Alba，还是外部家庭成员。
3. 表面事件是什么：生日、病中照顾、亲戚婚礼、车上对话、门口停顿、研究材料、孩子教育，或其他自然长出的事件。
4. 真正刺中的是什么：自由、名分、求、被排除、不能追、不能问、不能要求回复，或该场景中新长出的关系裂缝。
5. 这个场景只推进哪半步。
6. 哪个物件或动作承担意义。
7. 哪些话不能说出口。
8. 结尾是否已经成立，是否需要删掉最后一句解释。

## 试写稿建议格式

新试写稿可以采用：

```md
# 试写存档_阶段_视角_场景名_v1

## 本稿口径

- 视角：
- 阶段：
- 表面事件：
- 真正刺点：
- 本稿避免：

## 正文

正文从这里开始。
```

如果是改稿，可以在开头增加：

```md
## 修订方向

- 保留：
- 删除：
- 加强：
- 避免：
```

“本稿口径”和“修订方向”是给写作者看的，正文从“## 正文”以后开始。正文内部不要再出现后台解释。

## 最终校验

写完后检查：

- 是否有一眼能删的最后一句解释。
- 是否有三句以上连续短句在讲结论。
- 是否有“这不是 X，而是 Y”的分析句。
- 是否有角色说了他们不会说的后台词。
- 是否有动作、空间、物件承担情绪。
- 是否让卡瑞洛少说但更准。
- 是否让芷瞳不是冷机器，而是敏锐、别扭、会被触动。
- 是否让 Alba 从孩子的位置说话，而不是替作者说话。
- 是否保留了“安稳是真的，不自由也是真的”的双重性。
