## V3 写法说明

V3 保留 V1/V2 已确认的设定，但不再以“核心结论—职责列表—场景清单—写作禁区”的方式组织。每篇围绕一个核心矛盾连续展开，让世界观、人物心理、阶段变化和正文场景处于同一条因果链中。

建议按以下顺序阅读：先理解家族历史与产业如何生产 Marcello，再进入他与雷厉风、芷瞳的关系，最后讨论继承与下一代转型。

## 7 篇核心综合论述

1. **Carillo 四代发展史：南方根基、北意企业化与暗夜欧洲化**  
   说明地方人身权力如何变成北意基础设施、制度身份与欧洲网络，以及四代历史如何最终把 Marcello 固定为无法退出的功能性家主。

2. **Carillo 产业结构：热那亚入口、伦巴第物流与毒品黑线演化**  
   解释 Carillo 实际控制的是物流接口而非港口领土，合法与非法业务怎样相互支撑，以及产业治理逻辑如何迁移为 Marcello 的亲密关系控制。

3. **Marcello 接班至失势：年轻家主、实权争夺、暗夜扩张与家族反噬**  
   从 Enrico 去世、Roberto 暂时代管、暗夜危机、公司化战争，一直写到婚姻继承压力与暗夜倒台，追踪 Marcello 如何被一次次成功训练成绝对承担者。

4. **Marcello 与雷厉风：十年生死联盟、失眼事件与日本撤离镜像**  
   写两人从二十二岁/十九岁的初遇，到雷厉风失眼、日本撤离冲突和后来“死亡”的完整关系史，区分忠诚式不放弃与控制式不放手。

5. **芷瞳的女主人位置：内宅主权、亲属互惠与家族权力观察**  
   讨论她如何在一个既照顾又限制她的私宅中建立生活边界，怎样通过 Alba、工作人员、亲属往来与家族活动成为真正女主人，却不被 Carillo 完全吸收。

6. **失势重建中的芷瞳：家庭稳态、有限介入、Andrea 合作与受伤亲近**  
   写暗夜倒台后她为何未离开、如何保护家庭与合法资产、为何能无偏判断 Andrea，以及 Marcello 中段受伤后“不索取—主动靠近”的感情机制。

7. **Carillo 继承正当性：儿子压力、Lorenzo 方案与停止复制 Marcello**  
   将 Eleonora 的继承焦虑、Claudia 的母亲反抗、Lorenzo 的轻盈现代化、Alba 的伦理位置与芷瞳对系统正当性的拒绝放进同一论述。

## 2 篇侧边综合补丁

8. **Rinaldi 母系、教育路径与蓝眼睛谱系**  
   说明 Rinaldi 联姻的真实交换、Claudia 与 Marcello 的教育塑形，以及 Eleonora—Marcello—Alba 蓝眼睛谱系如何推动感情线。

9. **日本撤离 IF 分岔校准**  
   固定日本袭击、Marcello 重伤、雷厉风阻拦与派属下接人的事件顺序，并分别分析芷瞳被带回、被警方先救走、明确拒绝三条 IF 的后续意义。

## 统一时间线与关键校准

- Enrico 在 Marcello **21 岁**时因旧伤恶化去世。
- Marcello **22 岁**、雷厉风 **19 岁**时因暗夜失货危机初识。
- 雷厉风在二十岁出头的中段袭击中失去一只眼睛。
- 主线开始时 Marcello 已与雷厉风相识约十年；Marcello 遇见芷瞳约半年后发生日本袭击。
- 日本事件中，Marcello 重伤后要回**住处**带走芷瞳，不是追击警方。
- 芷瞳若被警方发现，只会被视为犯罪组织控制的人质，本身没有安全风险；Marcello返回的核心动机是不愿失去她。
- 暗夜在瓦雷斯倒台时 Marcello 不在现场，**没有受伤**；失势首先是系统性与权力性失势。
- 五年重建中段可发生一次针对 Marcello 的袭击与受伤，推动 Andrea 合作及芷瞳更私人地靠近。
- 芷瞳对 Marcello 的家族异化已有理解，但直到 Alba 带她离开、她在自由中主动回家，理解才可能转化为重新选择。
