# 试写存档｜和好后：以为你不要我了 v1

芷瞳后来很少再提台湾那几个月。

不是因为不能提。

只是那段时间像一间灯很亮的房间，她一个人待过太久，回头看时，反而不知道先说哪一处。

有一天夜里，卡瑞洛从浴室出来，看见她还醒着。

她靠在床头，手里拿着一本书，书页却很久没有翻。灯光落在她侧脸上，睫毛垂着，像在想很远的事。

卡瑞洛没有立刻过去。

芷瞳听见他的脚步停下，抬头看了他一眼。

“怎么了？”

他问得很轻。

她看着他，忽然有一点不好意思。

那种不好意思来得太迟，迟到不像她。她已经回来，已经说过原谅，也已经在很多夜里靠进他怀里。可有些话仍然像藏在旧抽屉里，打开时还是会碰到手指。

“我那时候以为你不要我了。”

话说出口，她自己先安静下来。

卡瑞洛看着她。

很久。

久到芷瞳几乎后悔。

她低下眼，像想把那句话收回去。

“你发了对不起，又把什么都安排好。”她说，“我以为你已经……算清楚了。”

卡瑞洛走到床边。

他没有坐下，只是站在那里看她。那一瞬间，他才明白，原来他的退开也曾经伤到她。

“我怎么会不要你。”

他说得很快。

像这句话根本不需要经过思考。

芷瞳抬眼看他。

过了一会儿，卡瑞洛才低声说：“你走以后，我每天都想你。”

她的手指在书页边缘轻轻收紧。

卡瑞洛看见了，却没有停。

“但我知道，我不能要求你回来。”

房间里安静下来。

芷瞳忽然觉得台湾那些夜晚里反复猜过的事，都在这一句里落了地。

他不是不要她。

他只是不能再要她。

她低头看着手里的书，纸页被她捏出一点弯折。过了很久，她才说：“我知道。”

停了一下。

“我后来知道。”

她把书合上，声音放得更轻。

“你那时候也很难。”

卡瑞洛没有说话。

这句话仍然让他不知该怎样接。他早就习惯把那几个月放进罪有应得里，芷瞳这样说，像把他从那里面看见了。

芷瞳抬眼看他。

“我也没有办法不想你。”

卡瑞洛的呼吸很轻地停了一下。

她说完，像终于把自己也交出来一点。不是道歉，不是解释，也不是为了让那几个月变得轻。只是承认：她回了家，得到了自由，也还是想他。

卡瑞洛坐到床边。

这一次，他没有问可以不可以。

只是伸手，把她手里的书拿走，放到一旁。

芷瞳看了他一眼，没有拦。

他的手覆上来，握住她的手指。

很久以后，他低声说：“我一直在等你。”

芷瞳靠过去，额头抵在他肩上。

“我知道。”

她闭上眼。

“这次我知道。”
