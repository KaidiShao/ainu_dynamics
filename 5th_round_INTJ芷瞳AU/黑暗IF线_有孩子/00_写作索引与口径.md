# 黑暗 IF 线（有孩子）写作索引与口径

## 文件夹用途

本文件夹用于存放《爱奴》INTJ 版芷瞳 AU 的“有孩子黑暗 IF 线”相关试写稿、片段池、阶段大纲和后续修订记录。

本线不是主线正文，也不是无子低调 HE 的替代版本，而是从冷战后更黑暗的分叉点继续推演：卡瑞洛用孩子、家庭、长期付出和半生押注把芷瞳留在身边，最终由女儿 Alba 打破幻影家庭，使芷瞳获得真正自由条件，再引出迟到回归与重新相处。

每次试写、改写、续写前，语言风格与人物口径先读 `00_每次试写前必读_语言风格与人物口径.md`。该文件覆盖散落在旧试写稿开头点评中的通用规范；具体场景承接再读对应试写稿本身。

## 版本阅读口径：V2/V3 通常不是对 V1 的简单覆盖

本文件夹中的版本号主要用于记录讨论、试写和综合论述的生长过程，不能一律理解成软件式的“新版取代旧版”。很多 V1、V2 乃至后续版本都各自保留了很有价值、也很有趣的内容：

- V1 往往保存最初发现机制时最鲜活的直觉、情绪入口、场景火花和人物措辞；
- V2 往往负责校准口径、补足因果、展开机制或换一个分析重心，但不必然包含 V1 的全部灵气和细节；
- V3 及以后有时是综合重写，有时只是阶段性扩展，也不当然宣布前版失效；
- 同一题目的不同版本可能不是优劣关系，而是不同意识流入口、不同叙事距离或不同侧重点的并列方案。

因此，阅读时按目的区分：

1. 若只需确认当前硬口径，优先读取最新 handoff、最高优先级口径补丁及明确标为“校准/修订”的新版本；
2. 若要继续写正文、寻找文风、人物感觉、场景细节或高情绪浓度，应把相关 V1/V2 并读，不要只凭版本号跳过旧稿；
3. 若要研究某项机制，先看综合论述的新版本建立全貌，再回读 V1 保存的发现过程、例证和未被综合稿收走的锋利表达；
4. 只有文件明确写明“旧版作废”“由本版覆盖”或与最高优先级口径冲突时，旧版才不再作为有效参考。

换言之：版本号记录的是思考继续长出来了，不等于旧版本失去阅读价值。尤其本线的大量 V1 与 V2，应视为互相照亮的档案，而不是只保留最新版的淘汰序列。

## 硬口径

- 女儿名字已经确定为 `Alba`，不得另起名。
- 这条线的孩子不是传统圆满符号，而是内部结构、现实绑定和代际反噬的核心。
- 黑暗 IF 的问题不是“没有爱”，而是爱被不自由的结构污染。
- 芷瞳不主动命名爱，不是报复，而是不能让爱替当年的错误押注签字。
- Alba 不是修复父母的工具，而是父母错误关系内部长出的自由主体。
- Alba 带走芷瞳后，会主动回去当面面对卡瑞洛，并以女儿身份阻止他追。
- 芷瞳被带走后仍有很长一段自由期心理活动：确认自己可以不回去，确认想回去不是因为孩子、怜悯、愧疚或担心卡瑞洛撑不住。
- 芷瞳主动回来不是结尾，而是重新相处、重新命名旧日温柔和迟到甜的开始。
- 第一部暂以卡瑞洛视角为主，第二部再转 Alba 视角。
- 卡瑞洛没有见过芷瞳父母。不是客观上完全不能安排，而是芷瞳没想带他见，他也没脸主动进入芷瞳父母面前的位置。
- 卡瑞洛听得懂日常中文对话，但中文空间仍然不是自动向他开放的空间；Alba 会说中文，母女之间有稳定的中文交流。
- 巧芙在日本事件中已经被救走。日本以后她不再处于卡瑞洛控制下，也不能继续作为现实中的代罚筹码；她只作为既往创伤、旧规则记忆和卡瑞洛早期结构化控制的历史样本存在。巧芙这一控制支架的消失，也是卡瑞洛在日本回来后转向孩子策略的重要前提。
- 日本事件以前，只要巧芙仍在卡瑞洛控制下，AU 芷瞳不会像原作南美段落那样独自冲动逃跑。她能够预判自己行动的成本会被转嫁给巧芙；只有出现可以带巧芙共同撤离的可靠窗口，或巧芙已经脱离控制，她才会重新评估离开。此口径不是“芷瞳不想走”，而是她不会让朋友替自己的单独逃亡承受代罚。
- 原作芷瞳在南美向陌生人泄露卡瑞洛身份、依赖临时外援逃亡的行为，仅可作为原作人物与后果机制的参照，不移植给 AU INTJ 芷瞳。AU 芷瞳的主体性主要通过信息克制、风险建模、情绪撤退与等待结构性窗口表现。
