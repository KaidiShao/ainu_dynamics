# 色彩、面料、轮廓与配饰词典

> 用途：为后续定妆、服装概念图、面料细节板与场景插画提供统一视觉语言。本文是**设计词典**，不是小说正文事实清单。  
> 人脸占位：`[ZHITONG_FACE_REF_PENDING]`、`[MARCELLO_FACE_REF_PENDING]`；身高常量：芷瞳168 cm、卡瑞洛185 cm、相差17 cm；双人体量余项占位：`[PAIR_SCALE_REF_PENDING]`。  
> 本文件不生成图片，不设计五官、发际线、妆容或精确肤色适配，也不把任何品牌或现成成衣当作设计答案。

## 0. 使用规则

### 0.1 证据代码

| 代码 | 本词典中的含义 | 使用方式 |
|---|---|---|
| `E1` | 原文件明确写出的衣物、颜色类别、材质类别、状态、穿着感受或选择行为 | 可以写“原文/设定明确”，但仍须注明它是正文、设定还是讨论层 |
| `E2` | 多份互不依赖文件形成的稳定交集 | 可作为跨文件视觉底盘；不能越过分支边界 |
| `D1` | 从人物、身体、空间和衣橱机制推出的高可信视觉转译 | 可供概念设计，但必须允许版型、色温和工艺微调 |
| `D2` | 两种以上都不违背原文的可替换候选 | 只用于并列测试，不直接锁正式图 |
| `Q` | 作者、年份、季节、地点、身份、身体阶段或参考图尚未决定 | 不得填成正史；正式图前必须复核 |

本文件中的所有 HEX 值均标作 `D1-VIS`：**只用于后续视觉沟通和颜色取样，不是小说正典色号，也不是贴脸最终色。** 实际色温、明度和贴脸范围须在导入 `[ZHITONG_FACE_REF_PENDING]` / `[MARCELLO_FACE_REF_PENDING]` 后复校。

### 0.2 分支门

- `COMMON`：芷瞳大学期尚在形成的自主审美、受伤恢复和卡瑞洛早期衣橱系统；可由 `MAIN` 与 `CHILD_IF` 继承的是判断与机制，不是大学期或成年期的整套视觉强度。
- `MAIN`：分离后主体重建与自由期；不得借用怀孕、Alba、`夫人`或家族首饰权限。
- `CHILD_IF`：早孕、迁居、孕产、家宅稳定、台湾旧衣和自由回归；不得把其身体状态或家宅身份倒灌 `MAIN`。
- `PROVISIONAL`：迁居、生产、产后连续链、精确季节和远期衣橱存在正文缺口时使用。

### 0.3 色彩不能单独承担的意义

1. 深色不自动等于危险，浅色不自动等于无辜。
2. 柔软不自动等于尊重，昂贵不自动等于拥有选择权。
3. 鲜艳不自动等于自由，低饱和不自动等于压抑。
4. 两人穿相近颜色不自动等于关系和谐；先检查谁选、谁付钱、谁能拒绝。
5. 任何色盘必须与轮廓、触感、闭合方式、维护状态和身体动作一起使用。

## 1. 统一色彩词典

### 1.1 芷瞳大学期自主审美色盘｜`COMMON` 被带走前

**证据底盘：** `A1 + E2`。作者直接锁定她是物理系学生，大学审美仍在形成：略先锋、有结构感、喜欢有趣设计，但不高度实验。原SOURCE中的艺术、小众、先锋中古、历史感、反叛与颓废只提供长期兴趣坐标，不能在22岁造型中同时满配。具体色名与比例均为 `D1`。

| 统一色名 | 视觉参考 HEX（非正典） | 位置与作用 | 禁止误读 |
|---|---:|---|---|
| 炭墨灰 | `#303236` | 外套、裤装、针织底色；适合课堂与图书馆日常 | 不是全黑极简或战术黑 |
| 纸灰米白 | `#D2CABB` | 衬衫、针织内层、里布 | 不等于卡瑞洛衣橱的柔化象牙色 |
| 深墨蓝 | `#30445C` | 常穿外套、裤装或书包 | 不做制服化理科优等生模板 |
| 低饱和森林绿 | `#526557` | 一件针织、围巾或小面积内衬 | 一套只用一次，不做成套森系 |
| 干酒红 | `#74404A` | 袜类、针织、包袋或一枚扣位附近的私人色 | 不做甜美浆果色 |
| 克制钴蓝 | `#456587` | 单件上衣或很小的设计重心 | 不与其他信号色同时抢画面 |
| 钝芥末色 | `#9A7A3B` | 极少量袜口、里布或旧图案 | 不是固定学院配色，只是她偶尔觉得有趣 |

**组合语法 `D1`：** 一套大学造型使用“日常中性底 + 一个私人颜色”；若已有特殊领口/口袋/扣位，就不再增加明显面料拼接。重点是普通学生衣橱里出现一件她觉得设计有趣的衣服，不是造型师堆满先锋标签。

**视觉关键词：** `物理系大学日常`、`可穿的轻先锋`、`清楚结构`、`一个有趣设计点`、`中性底加一个私人颜色`、`审美仍在形成`。

### 1.2 卡瑞洛配置衣橱色盘｜`COMMON` 衣裙系统

**证据底盘：** `E1（设定明示，非逐件正文）`。原文件列出旧象牙、雾蓝、深酒红、暗金、灰绿、柔软材质的黑色；`E2`支持其共同语言是昂贵、柔软、古典、繁复而“去刺”。

| 原设定色名 | 视觉参考 HEX（非正典） | 设计用法 | 控制机制 |
|---|---:|---|---|
| 旧象牙 | `#D9CEB9` | 主裙、内层、细褶；避免婚纱白 | 让轮廓显得安静、被照料、易被观看 |
| 雾蓝 | `#91A7AE` | 柔垂裙装、上衣或同色系层叠 | 降低对比与攻击性，不制造清爽少女感 |
| 深酒红 | `#683441` | 冷季裙装、内衬、窄范围腰部或袖口 | 贵重但压低亮度，不写成诱惑色 |
| 暗金 | `#8A744A` | 暗纹、包边、纽扣背面、极细金属线 | 只提供沉入织物的旧光，不用亮片或金色礼服 |
| 灰绿色 | `#6C786B` | 日常衣裙、针织或薄外层 | 柔化冷意，仍保持宅邸内部的低声量 |
| 柔软黑 | `#29292A` | 绉感丝、细羊毛或柔垂外层 | 黑色也被做软；不能恢复她成年自主衣橱更清楚的锋利判断 |

**组合语法 `D1`：** 同色系层次优先，明度差小，光泽受控；一件衣服可以复杂，但复杂被隐藏在暗扣、细褶、衬里和近距离才看得见的织纹中。不要用强撞色、裸露结构或可见修补。

**关键差别：** 这套色盘不是“芷瞳不喜欢的颜色”。她可能欣赏颜色本身；问题在于整排衣服都把她翻译成更安静、更柔软、更适合被安放的形象。

### 1.3 `CHILD_IF` 家宅稳定期色盘

**证据底盘：** `E1（讨论层 SOURCE 明示）`列出灰、黑、象牙、深蓝、墨绿、酒红；`E2`支持“艺术、优质、克制、封闭、安静，像被保存得很好的人”。这不是连续正文逐件锁色。

|---|---:|---:|---|
| 石板灰 | `#5C6062` | 大 | 直线、衬衫、裤装与外壳感增加，不再以柔美裙装为唯一主体 |
| 深炭黑 | `#252627` | 大/中 | 低光泽、稳定、封闭；不是 MAIN 的攻击性黑 |
| 旧象牙灰 | `#CEC5B5` | 中 | 降低暖甜感，像书页、石膏和旧馆藏 |
| 深墨蓝 | `#26384A` | 大/中 | 比卡瑞洛的墨蓝略轻一个层级，避免两人制服化同色 |
| 墨绿 | `#334A40` | 中 | 作为长外套、针织或长裙，不做田园感 |
| 静酒红 | `#613943` | 小/中 | 只在她主动选择时保留一点私人温度 |

**组合语法 `D1`：** 低饱和、低光泽、较少同时出现的颜色；允许一处只有移动时才显出的深色褶底或内衬，作为她未消失的智性与私人审美。不要把整套画成米白“贵妇老钱风”，也不要把“被保存”画成没有使用痕迹的瓷娃娃。

### 1.7 两人并置的色彩关系

| 节点 | 允许关系 | 禁止关系 |
|---|---|---|
| `COMMON` 控制型并置 | 他为深色稳定块；她为旧象牙/雾蓝/灰绿等柔化低对比；可共享一个低亮度深色，但材质与轮廓必须不同 | 同款情侣装、婚纱式黑白配、用同色证明归属 |

## 2. 面料词典：重量、光泽、垂坠、触感与季节

### 2.1 重量与表面统一标尺

| 词项 | 视觉定义 | 动作反应 | 使用警告 |
|---|---|---|---|
| `轻` | 可透气、层次薄，边缘会随呼吸和小动作变化 | 抬手时形成细密褶，落下后缓慢复位 | 不自动等于透明或暴露 |
| `轻中` | 能形成完整衣片，又不会压身体 | 坐下有柔和折线，行走产生连续小摆动 | 芷瞳日常/孕期最常用的设计重量 |
| `中` | 能维持结构、回弹和清楚下坠 | 转身后轮廓很快收回 | 适合工作西装、直筒裤、稳定外壳 |
| `中重` | 有明显重量和边界 | 下摆只产生一次沉稳摆动 | 适合冷季外套，不适合早孕室内重压 |
| `重` | 强结构、抗风、体量大 | 动作少，落点明确 | 仅在确定寒冷/户外场景使用；精确季节为 `Q` |
| `哑光` | 正面几乎不反射，只显织纹 | 光线移动时轮廓不跳 | 卡瑞洛和 CHILD_IF稳态默认 |
| `低光泽` | 只有转身、褶底或斜光时出现微光 | 可让复杂工艺近看成立 | 卡瑞洛配置衣橱可用；禁止镜面缎光 |
| `受控冷光` | 密织纤维在夜间斜光下有窄范围反射 | 轮廓边缘更清楚 | 仅正式/夜间 D1，不做闪耀舞台服 |
| `干爽手感` | 表面不黏、不蓬松，有轻微纤维感 | 褶线清楚，接触皮肤有存在感 | 自主旧衣可用；伤口/孕期贴肤层禁粗糙 |
| `柔滑手感` | 内缝平、贴肤阻力小 | 衣片随身体移动，不抓皮肤 | 不得把舒适自动解释成同意 |

### 6.3 图像中可见的动作反应词

- `柔垂但不贴体`：移动时衣片跟随，停下后回成竖向褶，不勾出身体全部曲线。

- `中量回弹`：坐下形成折线，起身后大部分恢复，仍留一两道真实坐褶。
- `沉摆一次`：适合马尔切洛长外套或冷季外层；下摆不连续翻飞。

- `袖口留下关系痕迹`：皱、湿、血、抓握只在场景发生后出现，并保持连续。
- `孕期留量从结构展开`：侧褶/移扣随坐姿张开，不把腹部做成视觉装饰中心。
