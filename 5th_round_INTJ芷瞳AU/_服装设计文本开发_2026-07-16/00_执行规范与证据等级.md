# 服装设计文本开发：执行规范与证据等级

> 项目阶段：第一阶段，只做文本；不生成图片。  
> 工作边界：只在 `_服装设计文本开发_2026-07-16` 内创建或修改文件；原小说、讨论归档与 `_深度通读档案_2026-07-16` 一律只读。  
> 编码：UTF-8 Markdown。

## 1. 分支标签

| 标签 | 含义 | 可继承范围 | 禁止倒灌 |
|---|---|---|---|
| `COMMON` | 正式分岔前共同基础 | 人物底层审美、早期相处与共同经历 | 不含任何分岔后的婚姻、怀孕、家族权限或自由期结果 |
| `MAIN` | 主线 | 仅继承 `COMMON`，再沿主线连续链发展 | 不得吸收 `CHILD_IF` 的怀孕、Alba、夫人位置或家族首饰权限 |
| `CHILD_IF` | 黑暗 IF 线·有孩子 | 仅继承 `COMMON` 与该分支明确允许的前置节点 | 不得把其稳定家宅衣橱、孕产身体和称谓倒灌回 `MAIN` |
| `OTHER_IF` | 其他事件变体 | 只用于确有比较价值的局部变量 | 不得作为 `MAIN` 或 `CHILD_IF` 的缺口填充物 |
| `ALT` | 替代设计、未采用稿或被放弃版本 | 可作为对照或候选来源 | 不得写成已发生事实 |
| `PROVISIONAL` | 因年份、季节、地点、身份或连续正文缺口而暂定 | 可供概念开发和测试图使用 | 必须列出可撤销部分，不得称为正史 |

> 本套文档中的“`MAIN自由期`”只指日本分离后在台湾三年的自主生活/重建阶段；不表示MAIN第五幕M4以后已经写出还自由、主动回归或修复。M4最远正文仍在瓦雷斯、自由未归还。

## 2. 原文件版本等级

| 等级 | 本项目中的处理 |
|---|---|
| `CURRENT` | 在其所属层级与版本族中当前采用；仍需判断它是结构层、讨论层还是正文层，不能自动等同“场景已发生”。 |
| `SOURCE` | 原始素材、母稿或可追溯来源；只证明来源，不自动证明采用。 |
| `ALT` | 可比较替代；只进入候选、禁用说明或差异分析。 |
| `SUPERSEDED` | 已被后续明确替代；不用于正式设计，除非为解释为何禁用。 |
| `UNRESOLVED` | 深度审计未能裁决，或原文件之间仍有实质矛盾；设计必须标记 `PROVISIONAL` 或暂停进入正式图像生成。 |

### 2.1 双轴状态写法

每条证据同时记录“文件状态”和“叙事落实状态”，例如：

- `CURRENT / 正文已发生`
- `CURRENT / 讨论已采用但正文未连续落地`
- `CURRENT / 远期样本`
- `SOURCE / 仅提供历史或人物底色`
- `ALT / 可替换设计候选`

禁止只写一个 `CURRENT` 便省略它属于结构、讨论、设定还是正文。

## 3. 设计推导等级

| 代码 | 等级 | 判定标准 | 写作口径 | 可否进入正式图片生成 |
|---|---|---|---|---|
| `A1` | 作者直接裁决 | 作者在本项目对话中明确确认，且未被后续裁决撤回 | “作者于日期直接确认……” | 可作为最高优先级人物/路线约束；具体单品仍须标E1/E2或D1/D2 |
| `E1` | 原文明确事实 | 原文件直接写出衣物、颜色、材质、首饰、状态、穿着感受或选择行为 | “原文明确……” | 可以；仍受脸部/比例占位符约束 |
| `E2` | 多文件稳定交集 | 至少两份互不依赖的采用文件相互支持，且无更高层冲突 | “多文件稳定显示……” | 通常可以 |
| `D1` | 高可信设计推导 | 从人物审美、身体、空间、季节与衣橱机制合并推出，可逐步复核 | “设计上可高可信转译为……” | 可以作为可修改设计层；须与 E1/E2 分栏 |
| `D2` | 可替换设计候选 | 存在两种以上都不违背原文的视觉方案 | “候选 A/B……” | 只适合测试或方案比较 |
| `Q` | 作者尚未决定 | 会改变正史性、身份、年份、季节、地点、身体阶段或权限的待决项 | “作者待决……” | 不可以；或仅做明确标注的预研图 |

## 4. 定位与引用规则

1. 每份实际用于设计判断的原文件必须完整读取至 EOF，写入 `00A_服装相关原文件回读台账.md`。
2. 证据定位优先写“相对项目根目录路径 + Markdown 标题/段落名 + 行号范围”；行号是本次快照定位，不替代标题。
3. 索引、审计报告只负责导航与版本裁决；具体衣物判断必须回到原文件。
4. 原文没有写出的结构、色号或工艺，不得伪造为引文；只能进入 `D1`/`D2`。
5. 若审计与原文矛盾，记录两侧路径、段落、冲突影响和暂行处理，不静默选边。

## 5. 命名规则

### 5.1 造型编号

`{BRANCH}-{CHARACTER}-{NN}`

- `COMMON-ZT-01`：共同基础，连芷瞳，第 01 套。
- `MAIN-ZT-01`：主线，连芷瞳。
- `CHILDIF-ZT-01`：有孩子 IF，连芷瞳。
- `COMMON-MC-01` / `MAIN-MC-01` / `CHILDIF-MC-01`：马尔切洛·卡瑞洛。

同一编号不得因小改版重复指向两个不同阶段；替代方案追加 `-A`、`-B`，但仍属同一叙事节点。

### 5.2 人脸与比例占位符

- 连芷瞳：`[ZHITONG_FACE_REF_PENDING]`
- 马尔切洛·卡瑞洛：`[MARCELLO_FACE_REF_PENDING]`
- 作者已锁身高：连芷瞳 `168 cm`；马尔切洛·卡瑞洛 `185 cm`；固定身高差 `17 cm`（`AUTHOR-02`）。
- 双人体量其余字段：`[PAIR_SCALE_REF_PENDING]`，仅继续占位肩宽差、头身比、基础体态、年龄视觉差、臂长与并排重心。

参考图导入前，不锁定贴脸精确色、脸型修饰领口、耳饰尺度、发际线、发型发饰、妆容、精确肩宽、头身比或永久标准体型。已锁的168/185/17厘米不得被临时人台、鞋跟、姿势或透视改写。

## 6. 禁止混用规则

1. `MAIN` 自由期审美不得移植到 `CHILD_IF` 稳定家宅期。
2. `CHILD_IF` 的怀孕/产后体型、Alba、夫人称谓、家族首饰权限不得倒灌 `COMMON` 或 `MAIN`。
3. 台湾旧衣不是“恢复青春”的快捷符号；必须保留能穿但不舒服、气味/面料/腰线与身体记忆错位。
4. 远期 `CURRENT` 样本不填补中间未写链条；缺口统一标 `PROVISIONAL`。
5. 未决年份、季节、迁居住所、婚姻法律状态、Alba 年龄与称谓不可由服装设计替作者决定。
6. “贵、优雅、古典、艺术感”不能单独作为设计结论；必须落到轮廓、重量、光泽、垂坠、闭合、活动反应和穿着痕迹。
7. 品牌和设计师只能作为作者侧审美坐标，不能替代设计描述，也不能直接复制成衣。
8. 控制关系不得被漂亮衣服美化成单纯宠爱；每套芷瞳造型必须写明选择者、购买/提供/管理者、拒绝权和身体舒适度。

## 7. 正式图像生成准入门槛

一套造型只有同时满足以下条件，才在证据矩阵中标记“可进入正式图片生成”：

- 分支、阶段、地点、身体状态没有相互冲突；
- 至少有 E1/E2 支撑核心叙事功能，或明确为可撤销的 D1 测试设计；
- 文件状态与叙事落实状态完整；
- 未把 `Q` 层信息写死；
- 已列出脸部/比例参考到位后需要复校的内容；
- 有完整的禁止画出元素；
- 通过 `08_服装连续性检查与禁用清单.md` 的交叉核验。

## 8. 原文件保护与完工核验

- 开工时记录项目中输出目录以外原文件的清单、大小与修改时间快照；完工时复核差异。
- 本阶段不移动、不重命名、不删除、不写回任何原文件。
- 所有生成文件只存在于新输出目录。
- 最终核验覆盖：分支、版本、身体阶段、空间、季节、称谓、首饰权限、占位符完整性及 12 组造型编号唯一性。
