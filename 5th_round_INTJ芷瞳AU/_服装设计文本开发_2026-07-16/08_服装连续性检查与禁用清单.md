# 服装连续性检查与禁用清单

> 用途：本文件是第一阶段全部衣橱结论、12组造型卡与第二阶段图像接口的**硬性放行闸门**。它不负责把候选变成正史，只负责发现串线、越级采用、身体／空间／季节错误，以及用视觉美化权力问题的风险。  
> 工作边界：只核验文本成果；不生成图片，不补写脸部参考，不修改任何小说原文件、讨论档案或深度通读档案。  
> 结果术语：`PASS`＝可按当前证据使用；`CONDITIONAL`＝可作明确可撤销的测试设计；`HOLD`＝缺作者决定或缺正文，不进入正式图像生成；`REJECT`＝与现行分支／版本／身体／权限冲突，必须退回修改。

## 0. 使用顺序与证据边界

每套造型必须按以下顺序检查，前一关未通过，不得用后面的视觉细化掩盖：

1. 分支与阶段；
2. 版本状态与叙事落实状态；
3. 身体阶段；
4. 空间与季节；
5. 称谓、法律身份与首饰权限；
6. 选择权、舒适度与叙事作用；
7. 轮廓、面料、色彩、配饰与动作反应；
8. 人脸／比例占位符；
9. 原文件回读台账与原文件保护。

### 0.1 本轮采用的裁决层

- 分支父链、连续缺口与远期样本：`11_主线与IF继承关系及完整分支图谱.md`、`14_正文阶段路线图_当前入口_待写顺序.md`。

## 2. 版本、远期样本与证据闸门

### 2.1 双轴状态不得省略

每张卡必须同时写：

- **文件／版本状态**：`CURRENT`、`ALT`、`SOURCE`、`SUPERSEDED`、`UNRESOLVED`；
- **叙事落实状态**：正文已发生、结构父链、讨论族口径、孤立CURRENT岛、远期样本、连续缺口、设计推导。

以下写法一律不合格：`状态：CURRENT`。  
合格示例：`CURRENT（版本族）/ 孤立远期样本；中间普通生活未写；服装结构D1`。

### 2.2 常见越级错误

| 误判 | 正确处理 |
|---|---|
| 结构层CURRENT＝场景已经发生 | 结构只锁节点作用；具体衣物仍回原稿核验 |
| 讨论稿CURRENT＝正文正史 | 标“讨论族CURRENT”；所有“可能／可设定／待写”仍为候选 |
| 版本号最高＝采用 | 服从正文连续性、明确修订与总纲硬口径 |
| 日期最新＝采用 | 日期只用于追溯，不具有自动裁决权 |
| `FULL`＝采用 | `FULL`只表示读至EOF |
| SOURCE中有好物件＝整场可继承 | 只回收局部，并重新通过目标分支的空间、权限与伦理检查 |
| SUPERSEDED仍可默认续接 | 仅用于反例或明确标出的SOURCE局部，不得作为默认链 |
| 离散远期样本＝中间生活已经连续发生 | 标出缺口，不替作者生成过渡事实 |

### 2.3 当前必须显式标出的离散岛与缺口

| 节点 | 可用内容 | 不能声称 |
|---|---|---|
| CHILD K2→K3 | 早孕制度已形成；迁居功能可做D1 | 迁居决定、路线、季节、住所落地已经写完 |
| CHILD K3b `第一封信_v3` | 孕中后期阶段与少量动作锚 | 它是K2之后无缝下一场；称谓、衣橱、首饰已连续建立 |
| CHILD K3→K4 | 生产与产后可建立可撤销功能候选 | 生产、产后恢复、`夫人`制度形成已有连续正文 |
| CHILD K5→K6 | 真相与谈判链、台湾自由骨架 | 询问母亲—同意—准备衣物药物—实际撤离已经发生 |
| CHILD K7 | 她主动回归后的局部动作、无行李／外套等E1锚；自由与资产是前提 | K4至K7普通生活链已补齐；`夫人_v4`已采用 |
| MAIN M4之后 | 当前可从书房外间继续 | 自由已归还、双方已和解或她已主动选择留下 |

### 2.4 图像准入对应文本结论

- `E1/E2 + 正文已发生 + 参数不冲突`：可在脸参／比例参到位后进入正式图像生成。
- `E1局部 + D1 + 季节或场景缺口`：仅可做无脸结构测试，标`CONDITIONAL`。
- `SOURCE强母题 / ALT场景 / 离散CURRENT岛`：只做比较板或可撤销测试，不能标“正史造型”。
- `Q`影响分支、法律身份、身体阶段、住所或首饰所有权：`HOLD`。
- 任何`SUPERSEDED`被当现行、任何串线：`REJECT`。

| 阶段 | 身体锚点 | 服装必须回应 | 禁止 |

| COMMON C0 | 健康、年轻、物理系大学生，审美尚在形成 | 整体适合上课、写字、步行；她只为一个有趣领口、扣位、口袋、结构缝或私人颜色承担轻微不实用 | 把她先验设计成无色功能主义者；或反向画成艺术学院秀场学生/成熟先锋设计师 |

### 3.2 每套必须通过的动作测试

除纯平铺工艺板外，人物造型必须说明以下动作中至少四项，且不得互相矛盾：

- 站立与转身；
- 坐下与起身；
- 抬手／伸手；
- 行走、楼梯与门槛；
- 乘车与长时间坐姿；
- 伤口换药／医疗检查；
- 孕期弯腰、扶桌、重心转换；
- 抱孩子或短时护理（仅有对应阶段证据时）；
- 穿脱鞋、外套与首饰。

若服装只能在静止正面成立，动态即露出伤口压迫、勒腹、绊脚、无法自行穿脱或需要他人强行调整，则该造型`REJECT`。

## 9. 控制、照护与浪漫化风险

### 9.1 每件衣物必须回答的八问

1. 谁提出需要？
2. 谁决定结果？
3. 谁付款／提供资源？
4. 谁送入、保存、修改和催促更换？
5. 芷瞳有哪些真实选项？
6. 她拒绝、退还或穿自己的衣服，代价是什么？
7. 这件衣服是否舒服；舒服是否来自她认可的选择？
8. 场合结束后，衣服／首饰／尺寸数据归谁控制？

缺少第5—8问的造型，即使视觉漂亮，也不得放行。

### 9.2 不得互相替代的概念

| A | 不等于B |
|---|---|
| 最好的面料与裁缝 | 她有选择权 |
| 衣服舒服 | 她同意关系或怀孕 |
| 她觉得衣服好看 | 她授权卡瑞洛定义她 |
| 她没有公开拒绝 | 她愿意 |
| 门没锁／衣柜可选 | 她能离开系统 |
| 孕期照护精确 | 关系已经修复 |
| `夫人`待遇 | 法律婚姻、继承或退出能力 |
| 家内实权 | 全族主母／黑线共治 |
| 资产名义归她 | 可支配且可退出 |
| 他不亲自选每件衣服 | 控制框架不存在 |
| 她主动回归 | 早期控制因此正确 |

### 9.3 控制减弱必须有可见证据

可用的微小退让包括：两个以上真正不同的选项；裁缝不保存为永久标准；她可自行联系；场合结束即归还暂借首饰；卡瑞洛只说明温度／正式度而不评价她“应该怎样美”；她的行李、鞋、外套和新购衣物由本人管理。  
“他语气温柔”“他买得更贵”“他觉得都好看”均不是退让证据。
