## 1. 本交接包的使用边界

1. 造型事实与状态以 `07_核心场景造型卡_第一批12组.md` 为直接入口；证据等级以 `00_执行规范与证据等级.md` 为准。
2. 提示词框架中的 `E1/E2` 内容可以保留为硬约束；`D1` 内容可在不改变叙事功能的前提下微调；`D2` 必须作为并列候选；`Q` 不得被图像模型擅自补齐。
3. `PROVISIONAL` 造型只能制作概念预研或结构测试，文件名、图注与元数据均须保留 `PROVISIONAL`，不得混入“正史定妆”。
4. 不从面孔反推国籍模板、肤色模板或“东方/南欧”刻板造型；不以品牌、演员、模特或设计师姓名代替服装结构。
5. 不固定芷瞳的永久体重、孕前/孕中/产后标准体型；每张图都应重新读取该卡的身体阶段。
6. 在三个占位符全部或部分未解除前，可以做衣物平铺、无脸人台、局部工艺板与低信息轮廓测试；不可制作可被误认作人物最终定妆的肖像。

### 2.1 解除占位符的最小条件

- 面孔接口：至少一张正面中性光、一张左右三分之四、一张侧面；照片应来自相近时间，且能区分镜头畸变与真实轮廓。
- 体量接口：身高不再等待照片；其余字段至少需要一张两人可比较的全身参照，或分别提供带可信尺度物的正/侧全身。若没有同框照片，不得宣称肩宽、头身比、体态、臂长与并排重心已锁。
- 色彩接口：只有在白平衡可信、无重滤镜的照片到位后，才校准贴脸色、金属冷暖与领口邻近色。

```text

[身体状态与社会位置] + [选择权与叙事作用] +
[内层至外层单品] + [轮廓/剪裁/闭合/口袋/内衬] +
[面料重量/光泽/垂坠/穿着痕迹] + [主色/辅色/金属色] +
[动作时面料反应] + [视图/镜头/光线/背景] +
[证据状态图注] + [禁止元素]
```

## 6. 参考图导入清单

### 6.1 必需参考

1. 芷瞳：正面中性光、左右三分之四、纯侧面、自然站立全身、自然坐姿；尽量同一时期、无美颜和强滤镜。
2. 卡瑞洛：正面中性光、左右三分之四、纯侧面、自然站立全身、穿普通衬衫或针织时的肩背参照；避免厚外套遮蔽真实结构。
3. 双人：同框同地面全身为优先；若无同框，分别提供可信尺度物、镜头距离相近的全身参照。
4. 色彩：包含中性灰卡或可信白色物体、白平衡稳定的照片；否则只做相对冷暖，不做精确贴脸配色。
5. 身体阶段：如作者有明确文字或非真人示意，分别给出伤势恢复、早孕、孕中后期、产后与长期训练后的**范围**，不要指定一个永久模板。

### 6.2 有帮助但不构成正典的参考

- 用户认可的面料小样、旧衣实物照片、纽扣/闭合/手工褶细节、生活中真实磨损与修补；
- 项目空间平面、门窗/桌椅尺寸和季节光线；
- 作者侧审美参照仅用于讨论“结构或气质坐标”，不得复制品牌成衣或秀场整体造型。

### 6.3 参考图验收记录字段

每张参考图记录：`REF_ID / 提供日期 / 人物 / 拍摄时间是否一致 / 镜头或滤镜风险 / 可用于面孔/比例/肤色/肩背中的哪些字段 / 禁止外推项`。原图不得只用聊天缩略图替代归档版本。
