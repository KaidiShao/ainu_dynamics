| 字段 | 内容 |
|---|---|

| 核心概念 | **年轻、可穿的轻先锋：普通大学衣橱里只有一个有趣结构点** |
| 叙事作用 | 建立后来“去刺衣橱”的早期参照：她已有自己的判断，但审美尚未成熟；关系控制拿走的是选择权，不是一套现成的激进先锋制服 |

### 完整单品（D1候选）

1. 内层：普通棉质短袖或薄针织，领口精确形状待脸参；
2. 主层：炭灰/深墨蓝衬衫或细针织上衣，只在特别领口、错位一枚扣、斜向省缝三者中选一个设计点；
3. 下装：不束腹的直筒/轻阔腿长裤，或简洁中长裙二选一；保持可辨认的大学日常轮廓；
4. 外层：自然肩短羊毛外套或旧夹克，实用口袋清楚；若主层已有设计点，外套保持普通；
5. 鞋袜：可长距离步行的系带鞋/短靴，哑光皮，深色袜；不承担先锋造型任务；
6. 包：能放书、笔记与普通随身物的旧皮/密织帆布肩包，只在包带、口袋或里布留一个小趣点；
7. 配件：本卡不放首饰；包袋的普通功能五金不承担身份或赠礼含义。

### 结构、材质与色彩

- 轮廓：上身清楚、下装留行动量；总体对称可穿，只有一个近看可见的结构偏移或特别比例。
- 剪裁：口袋真实可用；袖口允许写字/背包；特别领口、扣位、口袋或省缝四选一，不叠加。
- 面料：普通羊毛、棉、细针织、密织帆布、哑光皮；以日常触感为主，只允许一处细小反差。
- 视觉参考色（非正典色号）：炭墨灰`#303236`、深墨蓝`#30445C`、纸灰米白`#D2CABB`，辅以森林绿`#526557`或干酒红`#74404A`二选一。
- 金属：氧化银灰；不锁耳饰/贴脸金属。
- 闭合：普通门襟中只错位一枚扣，或完全常规闭合；裤/裙用普通前门襟/侧拉链；包用低亮功能扣。
- 内衬：若外层保持普通，可在里布留一处低饱和私人色；主层已有设计点时，内衬不再抢画面。
- **配色三项：** 主色炭墨灰/深墨蓝；辅色纸灰米白＋森林绿或干酒红二选一；金属色低亮银灰。全部为D1-VIS，非正典色号。
- **工艺六项：** 闭合=常规门襟或单一错位扣候选；纽扣=普通低亮扣；系带=服装无、包带仅功能；褶裥=裤前普通单褶或裙身一道结构省；口袋=真实可用且可作为唯一趣点；内衬=可选一处低饱和色、不与其他设计点叠加。
- **动态三态：** 移动时外套侧衩/裤腿自然打开；坐下时裤褶或裙身结构释放；抬手时肩背与袖口不受限，设计点不扭曲。

### 合身、痕迹与动作

- 合身程度：肩与腰有结构，腿部/髋部留真实步幅。
- 状态：袖口、鞋面、包角有普通学生日常的轻微磨损；不以可见修补或重度做旧制造先锋感。
- 移动：快走时外套侧衩与裤腿自然打开；坐下时裤褶/裙身释放，不需要小心维持端庄。
- 抬手：袖口不勒前臂；口袋可直接放手、票据或小笔记。

- 与Marcello并排：本卡不与他同框；避免事后把她的独立时期也纳入他的色盘。
- 原文证据：`intj版芷瞳_au_人物总纲_v_2.md` 108–122、1555–1563；`衣裙线设定补丁_v1.md` 120–210；`AUTHOR-01`限制大学期视觉强度。

- 状态：`A1作者裁决 / CURRENT人物约束 / D1 PROVISIONAL`。

## 2. COMMON-ZT-02｜鞭伤恢复期房内实用衣物

| 字段 | 内容 |
|---|---|
| 人物 | 连芷瞳；`[ZHITONG_FACE_REF_PENDING]` |
| 分支与阶段 | COMMON第一幕，拍卖后伤势恢复 |
| 场景 | 房内换药前后、短距离到餐桌；衣物服务身体，不制造亲密 |
| 地点与季节 | 前期私人住所；国别/季节未锁，采用室内温度可调的双层结构 |
| 身体状态 | 背部鞭伤、发炎/发热风险、应激、体力差 |
| 社会位置 | 被安置和管理的人；不是客人、病房患者或被承认伴侣 |
| 核心概念 | **体面、可自行合上、便于换药；保护与管理同在** |
| 叙事作用 | 让“身体被照料”与“没有退出权”同时成立，避免漂亮病弱滤镜 |
| 衣服由谁选择 | 宅邸系统给定；她可在穿脱和是否需要帮助上争取最小自主 |

### 完整单品（D1功能设计）

1. 内层：前开合软棉背心/短衫，背部无硬扣和厚缝；
2. 主层：直身长睡衫或软衬衫式家居上衣，前排小扣，侧缝有换药开口候选；
3. 下装：柔软直筒长裤，宽软腰头，不压腹/背；
4. 外层：轻量无硬腰带长袍/短外罩，前片交叠但可由她自己系合；
5. 鞋袜：防滑软底室内鞋；薄棉袜，发热时可不穿；
6. 配件：无首饰；药、纱布、温水属于场景物件，不是服装装饰。

### 结构、材质与色彩

- 轮廓：直、松、不会贴出伤口；肩部不掉落，避免“脆弱露肩”。
- 剪裁：前/侧开合；背片尽量少接缝；下摆不拖地。
- 面料：长绒棉、细亚麻或低摩擦针织为D1；需经过多次水洗、无强香整理剂。
- 色彩：纸白、淡石灰、低饱和灰绿仅作视觉参考；不因“纯洁”强制全白。
- 闭合：扁平贝壳/布包扣候选；无背后拉链、紧束系带、金属钩碰伤口。
- 口袋：一侧浅袋可装手帕/药单，但不让她携带物被工作人员自动清空。
- 内衬：原则上无厚衬；关键位置可双层隔离药膏。
- **配色三项：** 主色淡石灰/纸灰；辅色低饱和灰绿或未漂白棉；金属色无（避免金属钩碰伤口）。均为D1-VIS。
- **工艺六项：** 闭合=前/侧开；纽扣=扁平贝壳扣或布包扣；系带=仅外罩前方一根可自系软带；褶裥=无装饰褶；口袋=一只可用浅袋；内衬=无厚衬、药物接触区可双层。
- **动态三态：** 移动时下摆不拖地；坐下时软腰不起硬折；抬手时前片拉力不传到伤背。

### 合身、痕迹与动作

- 合身：肩颈稳定，背部有余量；不以过大衣服吞没她。
- 状态：刚换药时背片可能有极轻药膏/湿气造成的深色阴影，但不展示伤口。
- 坐下：软腰头不起硬折；长袍在椅面自然堆叠，不勒背。
- 抬手：前片拉力不传到后背；她能自己扣上大部分纽扣。
- 气味：洗净棉布、药和温水；不使用香氛化“豪宅气味”。

### 视觉关系、证据与限制

- 与Marcello并排：若他入画，他保持深色完整，站在不触碰换药区的位置；两者质地差异体现系统与伤员，不做情侣配色。

- 推导：前开合、软腰、侧开口、具体面料为D1；原文未锁款式。
- 状态：`CURRENT机制 / D1 PROVISIONAL`。
- 禁止画出：色情化露背、透明睡衣、蕾丝病弱装、束腰、满身绷带展示、卡瑞洛亲手替她穿衣的浪漫化画面。
