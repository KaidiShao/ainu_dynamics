# 当前试写稿取舍清单 v1

> 说明：这份清单对应本线程里的试写片段，而不是项目内既有正文文件。目的不是给试写稿打分，而是明确哪些精神可以保留、哪些段落需要重写、哪些方向索性不要继续沿用。

## 1. 可保留的部分

### 1.1 拍卖场后包厢与回程两段

这两段是当前最值得保留的试写成果。

- 芷瞳在极端恐惧里仍然先分析，这一点非常对。
- 她从卡瑞洛的眼神变化里意识到“心甘情愿”碰到了他的真实需求，这个判断非常有电。
- 她在回程中迅速意识到“这不是一夜的掳走，而是长期收容”，人物发动机是稳的。
- 她下决心要学意大利语、要把解释权一点点抢回来，这条线可以保留。

结论：
这两段可以作为后续正式写作时的核心模板。

### 1.2 芷瞳的外在声线

- 外在说话轻、软、克制，大多数时候不直接硬顶，这个方向对。
- 她很少数时候被逼急了会冒出一点带刺的话，这个也对，而且很有趣。

结论：
这个声线要继续保留，不要把她写成时时刻刻都在外显算计的女主。

### 1.3 “她喜欢他听得懂她的话”这一层

- 卡瑞洛能听懂她说话里的分量，而她日常生活里的很多人其实听不懂，这一点很值钱。
- 这条线可以作为后续吸引力的重要来源之一。

结论：
保留，但要写得轻，不要太早写成情感确认。

## 2. 需要重写后再用的部分

### 2.1 第一晚与早餐后试探

可保留的精神：

- 她很快读出这栋房子是“长期秩序”
- 她开始尝试用模糊信号换信息
- 卡瑞洛会观察她、判断她、觉得她在记在算很有意思

必须改的地方：

- 不能让巧芙太早被放，也不能太早给出“几天后就放人”这类过硬信息
- 卡瑞洛前期给的信息要更少、更吝啬
- 他可以有一点被她只在乎巧芙刺中的不悦，但不该太快显得像已经高度失控

结论：
结构可留，具体剧情必须重写。

### 2.2 门口送词典与意大利语线

可保留的精神：

- 芷瞳已经开始从日常对话里抓词
- 语言对她来说不是兴趣，而是夺回解释权的工具
- 她被卡瑞洛叫名字、被他看着、被他的眼睛留下感官印象，这些都可以保留

必须改的地方：

- 不要太早写成卡瑞洛已经看穿她在偷学
- 不要太早写成他主动“教学”或配合她学
- 语言线前期应更多是她自己在暗地里长出来，而不是他递工具帮她成长
- 除意大利语线外，默认他们大部分直接交流场景用英语即可；正文里不要频繁点破语言切换，不然很容易出戏。
- 语言能力边界按 `A1-` 处理：她懂一点拼读和极少量高频词，能抓音形、称呼和重复模式，但不能实时听懂完整对话。后续不能写成完全零基础，也不能写成即时翻译开挂。

结论：
意图与气质可保留，具体桥段要重写。

### 2.3 处理鞭伤

可保留的精神：

- 她真的够不着伤口
- 她强撑过头，身体先翻账
- 让卡瑞洛处理这道伤，会天然带来羞耻、屈辱和“身体状态被接管”的难受

必须改的地方：

- 不能写得太暧昧
- 不能写成她仅仅因为擦药就进入很强的身体混乱
- 这场的重点应当是疼、狼狈、屈辱、被管理，而不是过早的情欲认知危机

结论：
这场能用，但要降掉暧昧度，重写为“疼痛/屈辱场”。

## 3. 当前不该继续沿用的部分

### 3.1 巧芙太早获得释放或可验证安全

- 太早放巧芙，会直接削弱芷瞳后续“不逃”的内在约束
- 太早让芷瞳验证巧芙状态，会削弱卡瑞洛对解释权和不确定性的控制

结论：
这类设定索性不要。

### 3.2 把卡瑞洛写得太“整合”、太“好”

- 如果他太会照顾、太肯给信息、太早替她着想，就会失去原作那种症状性
- 当前更对的卡瑞洛是：对外高功能，对她这里有病，而且这个病要慢慢发作出来

结论：
凡是把他写成过早温柔管理者的版本，都不宜直接沿用。

### 3.3 过早的身体混乱与说明文式复盘

- 仅仅擦药、换药，不足以支撑她进入真正的“解释落后于身体”的大混乱
- 那种“我到底是在怕、在疼、还是在回应”的片段，要放到更后面的明确性推进之后
- 另外，试写里凡是把她的复盘写得太像概念说明文的部分，也不要直接保留

结论：
只保留痛点结论，不保留原段落表达。

## 4. 当前最稳的继续方向

如果按校准后的版本继续写，最稳的顺序应当是：

1. 芷瞳要求见巧芙，被拒
2. 她正式下定：在巧芙真正脱身前，我不逃
3. 卡瑞洛更明确地被她“只为朋友和承诺而留”刺中
4. 他开始从高功能观察/诱导，往更明显的症状性强势推进
5. 真正的身体混乱与事后复盘，放到后面再写

结论：
后续试写应优先服务主线约束，不再为了局部片段的“带感”而提前透支节奏。

## 5. v2 修订总入口

最新一轮校准后，所有精神较对片段的逐段修订意见已经整理到：

`精神较对片段_v2修订清单.md`

v2 的核心不是推翻前文，而是把以下四条新原则回灌进每个片段：

- 芷瞳拿到信息时，情绪重点不是“赢了”，而是“未知减少，所以安全了一点”。
- INTJ 芷瞳不是不脆弱，而是把脆弱管理成分析、计划、记录和输出控制。
- 卡瑞洛想要的不是表面服从，而是她未经处理的真心反应。
- `心甘情愿` 不是单纯策略台词，而是被胁迫污染、却又确实产生救人结果的道德债。
