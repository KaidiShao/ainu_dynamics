# 剧情设计：无孩子 IF 停手、放她走与雷厉风送别 v1

## 1. 场景功能

这一组场景是无孩子 IF 的起点。

它的功能不是写卡瑞洛如何变好，而是写他如何失败。他强行执行几天，最终被芷瞳的崩溃击穿，无法继续把这件事命名为“留住她”。没有怀孕结果作为现实支架，他进入认输式放手，决定让芷瞳回家。

这一组场景要完成三件事：

第一，证明卡瑞洛曾经真的越过了芷瞳的拒绝，所以伤害成立。

第二，证明他不是能在芷瞳哭到失控以后继续的人，所以无孩子 IF 分叉成立。

第三，证明放手不是成熟胜利，而是狼狈认输后的伦理退让。

## 2. 前置状态

前置状态应该是：

芷瞳经历过几天抵抗。

她不是完全冷静谈判，也不是歇斯底里撕打。她受制于卡瑞洛的现实系统，不敢把他逼到更可怕的地方。她会躲、会挡、会说不要、会说放开我、会说我不想生你的孩子，也可能说“你这样只会让我更恨你”。

卡瑞洛在执行中越来越狼狈。他不是冷静享受强迫，而是每一次都被她的抗拒刺中，却又因为恐惧失去她而继续。

这几天里，他已经开始在其他方面低姿态：照顾她，给她空间，动作变轻，但核心事情上仍不松手。

因此到“别让我恨你”这一晚，双方都已经到了极限。

## 3. 当晚关键对话与动作

当晚可以这样设计：

芷瞳一开始仍然抗拒，但她的反抗已经不是第一晚那种惊惶，而是更深的疲惫和羞愤。她知道说不一定没有用，却还是说。

卡瑞洛靠近时，她躲开。

他抓住她的手腕。

她说：

“不要。”

他没有松。

她又说：

“你放开我。”

他仍然没有松。

这里不能写卡瑞洛手松。因为他已经知道她会抗拒，也已经在这条路上走了几天。如果一抗拒就松，后面就不成立。

他们在床边或床上拉扯一会儿。芷瞳不会踢他、抓伤他或尖叫式撕打，因为她害怕卡瑞洛，也不知道他的底线在哪里。她主要靠推、挡、躲、说不愿意，期待他自己停。

当她发现又无效时，可能说：

“你这样，我只会更恨你。”

卡瑞洛不能回答。因为回答就会牵扯到他希望她对自己有感情，而他此前又用过“不需要你愿意”的防御。他无论怎么回都不对。

更核心的台词是：

“别让我恨你。”

这句比“我恨你”更刺。

“我恨你”是定罪。

“别让我恨你”里还有最后一点：你不要真的变成这样。

卡瑞洛听懂了。他会痛，但仍继续。这里必须保留他没有听的残酷性，否则无孩子 IF 的罪会被削弱。

## 4. 芷瞳哭出来的时刻

芷瞳不能在说完“别让我恨你”后立刻哭，然后卡瑞洛马上停。那会让执行失败来得太容易。

更合适的顺序是：

她说“别让我恨你”。

卡瑞洛痛苦，但还是继续。

事情已经完成或接近完成后，芷瞳才终于控制不住哭出来。

她不是掉几滴眼泪，而是哭到停不下来。她可能一开始还想忍，后来忍不住，声音哑，呼吸乱，听不见卡瑞洛说话。

卡瑞洛叫她：

“芷瞳。”

她没有反应，只是在发抖。

他又说：

“别哭。”

“别这样。”

这些话很笨，也很无用。不能写成漂亮承诺。卡瑞洛这时说不出“我会补偿你一辈子”这种话，因为那听起来像情感勒索，也因为他自己都觉得荒唐。他只能说最短、最无力的话。

## 5. 他为什么做不下去

这里的核心思想不是“我受不了你哭”，而是：

我如果继续下去，就不是留住你。

我只会毁掉你。

当下场景里不必让他说出来。可以留到多年后亲密复盘再由他回忆。此处只写他状态崩塌：

他想把她抱住，但她哭得听不见。

他想安抚，却没有一句话能成立。

他终于意识到，自己不能再把这件事叫成“留下她”。

这时候可以写他停下来，或者已经无法继续下一次。他处理水、被子、灯，让芷瞳睡下。

他不应该继续留在屋里睡。因为他面对不了自己，也面对不了她。

## 6. 逃走与门边回头

卡瑞洛最后会逃到书房。

动作可以这样：

他把水放在她够得到的地方。

把灯调暗。

确认她呼吸慢下来。

走到门边。

回头看了一眼。

这一眼很重要，有道别意味。

不是他要离开芷瞳，而是他知道从今晚以后，旧的靠近方式已经结束了。他不能再把身体关系当成确认她还在的方式，也不能再用现实权力把她压进自己的未来里。

他关门，去书房。

这晚不应该继续写很多天。到他逃走就够了。后面很多天需要另开文档或下一场。

## 7. 后续几天：工作逃避与认输

后续几天卡瑞洛可能躲在工作里。

他工作不会出大错。卡瑞洛的理性防御很强，他可以签字、处理撤回线路、问细节。但每隔一会儿，他会看向某个芷瞳本来可能在的位置，然后继续工作。

他不是崩溃到系统停摆的人。越能运行，越显得空位痛。

他也不敢再叫芷瞳到身边，不敢要求她陪自己工作，不敢碰她。

这时候他会开始想：

如果没有怀孕，就放她走。

这个念头不是高尚，而是认输。

她不会再愿意。

我也不能再这样。

没有孩子，我已经没有理由继续把她留在这里。

## 8. 告诉芷瞳可以回家

这里需要一场短而重的对话。

卡瑞洛应该先告诉芷瞳她可以回家，然后他才受伤或病倒。这样他不是用伤势逼她留下，也不是雷厉风利用他的脆弱诱导芷瞳。

对话可以很短：

卡瑞洛站在离她一段距离的地方。

芷瞳很警惕，不知道他又要说什么。

他说：

“你可以回台湾。”

芷瞳抬头看他，像没有听懂。

他继续：

“我会安排。”

停一下。

“雷厉风送你走。”

芷瞳可能很久说不出话。

她问：

“为什么？”

卡瑞洛没有立刻回答。

最后他说：

“因为我没有资格留你。”

这句可以是这里的核心，也可以稍后在病中说出。根据正文节奏决定。

## 9. 卡瑞洛受伤/病倒

卡瑞洛放手以后，可以因为自毁、失误、过度工作、旧伤牵连或外部冲突受伤/病倒。

这个伤不能设计成苦肉计。他自己没有想用它留芷瞳。他甚至可能不想让她知道。

这里要注意顺序。

雷厉风可以让芷瞳知道卡瑞洛情况不好，也可以给她一次去看他的机会，但“他的伤很重？”、“死不了，不过也不轻”、“他让你走，不是为了让你回头”这组对话，不应该放在她见卡瑞洛之前。

这组对话更适合发生在芷瞳已经看过卡瑞洛以后。

因为她见过他，听过他的道歉和“我想要你愿意”，也看见他真的很狼狈。她显然还会被他牵动。这个时候雷厉风送她走，才需要说那句边界很清楚的话。

不是在看之前劝她去看。

而是在看之后保护她继续走。

雷厉风不是把卡瑞洛的伤变成筹码，不是说“他都这样了你不能走”。他更像是给她一次见面的机会，然后在她已经被触动以后，替卡瑞洛守住放手的边界。

如果正文需要让雷厉风在看之前开口，可以非常轻：

“你要走了。”

停一下。

“他情况不太好。”

或者：

“见不见，你自己决定。”

这样就够了。不要在看之前把“去看一眼”写成一个带压力的任务。

## 10. 病中见面与迟来表白

芷瞳去看他。卡瑞洛本来已经准备当作诀别，看到她还愿意来，会完全绷不住。

但他不是想留她。他已经决定放手。

他可能说：

“对不起。”

芷瞳没有说话。

他声音很低：

“我以为我能承受你恨我。”

停很久。

“我不能。”

这里可以保留当年崩溃版台词，因为这是分离前第一次说出。

他还可以说：

“我想要你愿意。”

这句是这条线的核心。它把他此前所有“不需要你愿意”的防御撤掉。

芷瞳不会问“你是不是爱我”这种话。她更可能说：

“你为什么现在才说。”

这句很痛，因为它不是在求解释，而是在指出迟到。

卡瑞洛不会辩解。

他只说：

“对不起。”

这个“对不起”和有孩子 IF 正线里芷瞳回家后他发信息说“对不起”同构。它不是解释，也不是索取原谅，而是伦理位置的改变。

## 11. 雷厉风送别：她被牵动，但仍然会走

这场看望不会让芷瞳立刻留下。

她会被触动，会心痛，甚至会想哭。但她还是会走。因为这时候她需要回到自己的生活里，需要确认自由是真的，也需要从卡瑞洛的世界中出来。

雷厉风送她离开时，这个场景才适合放那组对话。

芷瞳可能一路都很安静。

她看过卡瑞洛以后，不可能没有反应。她不会突然变得冷硬，也不会像完全不在意。她会被他牵动，会担心他的伤，会反复想起他说“我想要你愿意”和“对不起”的样子。

但她也知道自己还是要走。

在这种沉默里，她可能终于问：

“他的伤很重？”

雷厉风可以说：

“死不了。”

停一下。

“不过也不轻。”

这个回答很雷厉风：不卖惨，也不粉饰。

芷瞳可能又沉默很久。她没有说要回去，也没有说不走，但雷厉风看得出来，她被卡瑞洛牵动得很深。

这时雷厉风可以说那句正经话：

“他让你走，不是为了让你回头。”

这句保护了卡瑞洛的放手，也保护了芷瞳的自由。

它不是说“你不能回头”，也不是说“你不该心疼他”。它是在告诉芷瞳：你被他牵动是真的，但你不用把这份牵动立刻翻译成留下。你去看他、心疼他、被他的话打动，都不等于你欠他一个回头。

这句也保护了卡瑞洛。

因为卡瑞洛这次放手，如果马上被他的伤、他的道歉、他的狼狈重新变成把芷瞳拉回去的理由，那这个放手就又被污染了。雷厉风难得认真，是在帮兄弟守住这个最后的体面。

卡瑞洛会更痛，但比黑暗 IF 正线更能承受。因为她是听见真话以后走的。她没有原谅，也没有留下，但她不是完全带着误解离开。

他已经道歉。

他说出了“我想要你愿意”。

这让他即使以为是诀别，也能比正线更快重新站起来。

## 12. 写法校正

不能写成：

芷瞳一哭，卡瑞洛立刻停止，显得伤害不严重。

卡瑞洛病倒是为了让芷瞳心软。

雷厉风替卡瑞洛卖惨。

芷瞳因为听到表白就留下。

应该写成：

卡瑞洛已经做错并继续了一段时间。

芷瞳哭到失控后，他终于无法继续。

他认输式放手，先告诉她可以回家。

受伤或病倒发生在放手之后，不是筹码。

雷厉风不是在看之前用卡瑞洛的状态推她回去，而是在看之后、送别时，承认她会被牵动，同时保护她继续离开的自由。

芷瞳听见道歉与表白，但仍然回台湾。

这使无孩子 IF 的分离既痛，又比有孩子 IF 干净。
