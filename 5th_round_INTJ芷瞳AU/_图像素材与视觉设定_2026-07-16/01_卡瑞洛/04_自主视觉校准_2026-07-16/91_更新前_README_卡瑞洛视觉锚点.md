# 卡瑞洛视觉锚点

## 当前结论

`MC_FACE_REF_001`被选为卡瑞洛的主脸候选，同时也是一个高度匹配的阶段性情绪锚点。

它最适合表达：

- 冷战后期，外部姿态尚未崩塌，眼神里已经有求；
- 怀孕以后，他不知道怎样靠近才不会继续伤害芷瞳，只能克制地等待一个很小的实际回应；
- 在芷瞳面前受挫后，过早形成的掌权者人格短暂后退，露出那个实际上不知道该怎么办的男人。

它不适合直接代表：

- 对外家族事务中的完整权力场；
- 标准工作状态下完全端正、精确、无裂缝的卡瑞洛；
- 卡瑞洛的永久发型、精确身高与肩背；
- 任意阶段都可复用的通用表情。

## 当前视觉接口

```text
MC_FACE_CORE_001
用途：核心脸部骨相候选。

MC_STATE_COLDWAR_LATE_001
用途：冷战后期，克制地请求回应。
匹配度：高。

MC_STATE_PREGNANCY_CARE_001
用途：怀孕后低压力照顾期，等待她允许自己做一点实际的事。
匹配度：较高。
限制：请求对象不是感情保证，不把自己的痛苦压给她。
```

## 已完成的派生结果

| 素材 | 目标 | 作者反馈 | 最终定位 |
|---|---|---|---|
| `MC_FACE_DERIVED_001` | 外部权力场基准第一次尝试 | “似笑非笑，表情有点瘆人” | `REJECTED_EXPRESSION_DRIFT`；仅作负面样本 |
| `MC_FACE_DERIVED_002` | 更保守的身份保持与侧向观察 | “好一点，但是有点微妙的可爱” | `SELECTED_STATE_CANDIDATE`；孕后私下等待回应 |

第一张证明：完全摆正、正对镜头、收紧嘴唇和对称化面孔，会把卡瑞洛从“无需表演的权力”推向“礼貌地威胁”。

第二张证明：保留歪头、把视线移向房间里的具体对象，能够恢复人物关系感，但侧移视线、松眉、圆眼和蓬松额发会使他显得意外地年轻、无措和可爱。这种可爱适用于芷瞳才能看见的私下状态，不适合外部权力场。


## 下一步建议

暂时停止继续磨“外部权力场表情”。下一张优先生成：

```text
MC_BODY_REF_001_普通衬衫肩背体量_PROVISIONAL
```

目的不是做成品服装图，而是让作者选择卡瑞洛的肩宽、胸背容量、腰线、颈肩关系与站姿。建议使用无厚外套、无低机位、无动作英雄化的普通深色衬衫或薄针织，生成正面与三分之四半身／全身候选。脸部只能使用 `MC_FACE_REF_001`作身份参考；身体结果必须标 `PROVISIONAL`，由作者选择后才可进入 `COMMON-MC-01`精确剪裁测试。

不得从现有三张近景图直接锁定侧脸、后脑、肩宽、胸腰比或精确身高。
