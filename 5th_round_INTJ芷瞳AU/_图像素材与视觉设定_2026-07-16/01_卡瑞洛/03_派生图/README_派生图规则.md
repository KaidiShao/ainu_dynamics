## 4. 实际执行结果

### `MC_FACE_DERIVED_001`

- 目标：外部权力场基准。
- 结果：状态转换明显，但身份保持不足；嘴角、正面凝视和面孔对称化形成似笑非笑的隐含威胁。
- 作者裁决：否决。
- 保留用途：负面提示词和连续性检查样本。

### `MC_FACE_DERIVED_002`

- 目标：从原图重新进行更保守的状态编辑。
- 结果：身份保持优于第一张；取消瘆人的微笑，但侧向观察、松眉、较圆眼型与蓬松额发带来微妙可爱。
- 作者裁决：保留为状态候选。
- 使用接口：`MC_STATE_PREGNANCY_CARE_002`。
- 限制：不能作为外部权力场或第二张身份锚点。

## 5. 当前推进条件

外部权力场基准尚未生成成功，但已经不必为了服装生产继续反复修改表情。当前可并行进入：

1. 普通衬衫或薄针织状态的肩背体量候选；
2. 作者选择肩宽、胸背、腰线和站姿范围；
3. `COMMON-MC-01`深色精确剪裁结构测试；
4. 芷瞳脸部与身体参考导入；
5. 两人比例均获确认后，再做双人同框。

下一项推荐编号：

```text
MC_BODY_REF_001_普通衬衫肩背体量_PROVISIONAL
```

任何新角度或身体生成造成的鼻尖、下颌、眼距、耳位、头骨、肩宽和胸腰比例变化都属于模型推测，必须由作者重新确认，不能自动继承。

## 6. `MC_FACE_DERIVED_002`左眼微调复核｜2026-07-18

作者认为`MC_FACE_DERIVED_002`本身比后续部分校准图更自然，只希望将画面左侧、人物自己的右眼极轻微睁大，以加强侧视协调。

执行时锁定原图身份锚点与`MC_FACE_DERIVED_002`编辑底图，所有轮次均从两张固定输入重新开始：

- R01：请求上眼睑增加2%—3%，结果开合过量，双眼同时圆亮、脸部圆方化，身份29/40；
- R02：请求上眼睑增加1%—1.5%，开合较R01收回，但仍全图重生，身份30/40；
- R03：没有生成。R01与R02均不是有效单参数结果，不具备中间插值条件。

最终继续采用未经修改的`MC_FACE_DERIVED_002`作为：

