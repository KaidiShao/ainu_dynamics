# `MC_FACE_STATE_003`｜私下专注凝视

## 1. 作者裁决

作者确认采用这张图作为一个新的独立关系状态。

它不是对`MC_FACE_DERIVED_002`左眼的成功修复，也不替代原状态图。它表达的是：卡瑞洛专注地看着芷瞳，安静、不催促，却让她无法忽略他的全部注意力已经落在自己身上。

核心句：

```text
他没有要求她回应，
但他的全部注意力已经构成回应条件。
```

## 2. 状态含义

在这个状态里：

- 卡瑞洛没有主动逼近、追问或索取承诺；
- 他的目光不是散漫等待，而是持续接收芷瞳的停顿、呼吸和微小反应；
- 芷瞳会意识到自己正在被认真读取，因此他的专注会改变她接下来怎样回应；
- 影响来自注意力的完整和持续，不来自恐吓、怒意或公开权力。

这是一种安静但具有关系重量的凝视。它允许卡瑞洛保持智性、克制与高注意力，同时避免把他画成审讯者、黑帮人物或哀求回应的人。

## 3. 与既有状态的区别

| 素材 | 核心状态 | 关系动力 |

## 4. 正向使用范围

当前可用于`CHILD_IF`亲密私下场景，例如：

- 芷瞳刚说出一句暴露真实态度的话，他没有立即回答，而是确认她真正的意思；
- 怀孕照顾期，他提出一个很小的实际安排后，安静观察她是否接受；
- 他察觉她可能再次后退，却暂时不以语言截断她；
- 两人之间已经存在沉默张力，而他的专注让沉默不再是空白。

不得仅凭这张图反推具体正文情节、时间点或正史事件。
