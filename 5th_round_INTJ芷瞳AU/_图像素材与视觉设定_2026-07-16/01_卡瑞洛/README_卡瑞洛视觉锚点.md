# 卡瑞洛视觉锚点

## 当前结论

`MC_FACE_REF_001`被选为卡瑞洛的主脸候选，同时也是一个高度匹配的阶段性情绪锚点。

它最适合表达：

- 冷战后期，外部姿态尚未崩塌，眼神里已经有求；
- 怀孕以后，他不知道怎样靠近才不会继续伤害芷瞳，只能克制地等待一个很小的实际回应；
- 在芷瞳面前受挫后，过早形成的掌权者人格短暂后退，露出那个实际上不知道该怎么办的男人。

它不适合直接代表：

- 对外家族事务中的完整权力场；
- 标准工作状态下完全端正、精确、无裂缝的卡瑞洛；
- 卡瑞洛的永久发型、精确身高与肩背；
- 任意阶段都可复用的通用表情。

## 为什么这张脸像卡瑞洛

作者进一步确认：它的角色适配性不只来自深发、蓝灰眼睛、南欧暖底和清楚但不粗犷的骨相，也来自明显的**智性与 INTJ 式认知存在感**。

这张脸看起来像在持续接收和处理信息，而不是展示忧郁、英俊或权力。它的眉眼有专注度，嘴部保持克制，表情信息量低却不空洞，形成“已经看见，但暂时不说”的感觉。这与卡瑞洛的核心能力——看局势、看人心、看见芷瞳没有说出口的反应——高度一致。

原图尤其准确地呈现了一个惯于理解局势、预测别人并找到解决办法的人，第一次在芷瞳的沉默面前无法求解。他仍在观察、判断和校正，只是不知道下一步怎样做才不会让结果更坏。因此，这份“求”并不削弱他的智性，反而暴露了他的整套控制与判断系统在最重要的关系里失效。

后续不得用眯眼、抬下巴、似笑非笑、加宽下颌或肩背来制造“聪明与掌控”。卡瑞洛的智性应表现为高注意力、低表演、内部运算多而外部输出少；权力则继续由站姿、说话节奏、衣装秩序、空间位置与他人的反应共同建立。
