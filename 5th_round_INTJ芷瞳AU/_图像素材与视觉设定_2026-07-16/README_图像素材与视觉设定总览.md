## 3. 素材状态

| 状态 | 含义 |
|---|---|
| `RAW` | 原始素材，只保存，不修改 |
| `CANDIDATE` | 候选参考，尚未由作者确认 |
| `SELECTED` | 已被作者选中，可参与后续校准 |
| `ANCHOR` | 已通过多轮核验的稳定视觉锚点 |
| `DERIVED` | 由其他素材生成或编辑得到的派生图 |
| `PROVISIONAL` | 受角度、身体、年代或设定未决影响的临时结果 |
| `REJECTED` | 明确不采用，但保留以防重复试错 |

当前 `MC_FACE_REF_001` 的状态为：`RAW + SELECTED + PROVISIONAL_IDENTITY_ANCHOR`。它已被选为卡瑞洛主脸候选与特定情绪状态锚点，但尚未获得中性正面、侧面及全身体量验证，因此暂不标为完整 `ANCHOR`。

## 4. 命名规则

推荐格式：

```text
[人物]_[素材类型]_[三位编号]_[状态或场景]_[用途或版本].ext
```

人物代码：

- `MC`：马尔切洛·卡瑞洛
- `ZT`：连芷瞳
- `PAIR`：双人比例或同框

素材类型：

- `FACE_REF`：脸部参考
- `BODY_REF`：身体与体量参考
- `OUTFIT`：服装图
- `SCENE`：场景图
- `MATERIAL`：面料或工艺图

例如：

```text
MC_FACE_REF_001_冷战后期克制请求_原图.jpg
MC_FACE_BASELINE_001_外部权力场_DERIVED_v001.png
PAIR_BODY_REF_001_中性并排_PROVISIONAL_v001.png
```

## 5. 原图保护规则

1. `01_原始参考`中的文件永久只读使用，不裁切、不调色、不覆盖、不去除可见来源标记。
2. 任何生成、重绘、扩图或状态转换都进入 `03_派生图`，并使用新文件名。
3. 派生图必须在旁边记录：父素材ID、使用提示词、模型或工具、生成日期、版本、作者选择理由与否决理由。
4. 不用模型偶然输出反推小说正史，也不把派生图自动升级为人物定稿。
5. 来源和公开使用权限不明确的素材只作内部人物研究与视觉讨论，不直接用于公开发布或商业成品。

## 6. 与服装设计档案的关系

后续生成服装图时，至少同时读取：

- `_服装设计文本开发_2026-07-16/07_核心场景造型卡_第一批12组.md`
- `_服装设计文本开发_2026-07-16/08_服装连续性检查与禁用清单.md`
- `_服装设计文本开发_2026-07-16/09_图像生成第二阶段交接包.md`
- 本目录中对应人物的视觉锚点与评估记录

脸部、身体、服装与分支状态是四套独立接口。某张图只能约束其被授权的字段，不能因为它是“主脸”就同时决定永久发型、精确肤色、身高、肩宽、服装或场景。
