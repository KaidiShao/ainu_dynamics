## R-01｜日内瓦与南美顺序共存

- 裁决日期：2026-07-16
- 原误判：把日内瓦三天与南美—瓦雷斯当成同一功能位上的互斥旅行，并以稿量判断南美覆盖日内瓦。
- 作者确认：**日内瓦是两个人身体距离靠近的阶段；南美是两个人心理距离靠近的阶段。两个场景都需要。**
- 当前状态：CURRENT（主线结构）

### 正确父子顺序

`前期精神较对／身体默认权萌芽 → 日内瓦三天 → 返意后夜间边界不归还 → 那几天 → 第一次真正发生 → 默认权与甜期小样本／误读累积 → 南美 → 瓦雷斯／巧芙／口头回禀／冷战`

### 两段的不同任务

| 阶段 | 距离变化 | 核心证据 | 仍然没有成立的东西 |
|---|---|---|---|
| 日内瓦 | 身体／空间距离靠近 | 无独立房门、第一夜不同床、第二夜边界改写、返意后`房间还在`但夜晚默认权未归还 | 心理信任、自由同意、平等关系 |
| 南美 | 心理距离靠近 | 保护后送离、脱口而出的“那你呢”、等待他回来、检查伤势、自己走近 | 自由退出权、事业参与权、对控制结构的接受 |

### 对瓦雷斯冷战的影响

日内瓦让 Carillo 得到并固化身体上的接近；南美让他得到部分真实的担心与朝向。到瓦雷斯，中文口头回禀揭示芷瞳也曾有策略性给信号时，他失去的不是一个纯假象，而是把“策略与真实混合”防御性判成“全部欺骗”。因此南美的心理靠近是冷战痛感的必要前史。

### 仍待讨论

1. 日内瓦归来至南美启程之间隔多久。
2. 第三幕两人同行的南美与第五幕 Carillo 南美短离如何形成回声，而不让读者误认成同一次事件。

现行连续关系为：

`日内瓦第一夜睡外间 → 第二夜拿走夜间边界 → 返意后不归还原房间的夜晚默认权 → 房间还在 → 第一个吻 → 当晚收进怀里 → 第二天第二个吻 → 会所／吻后余波 → 那几天 → 第一次真正发生 → 次日复盘与白天默认权建立`

## R-03｜日本主线采用现写／原作母版

- 裁决日期：2026-07-16
- 原误判：把主线日本撤离压成纯 B“警方先一步救走”与纯 C“属下找到后她明确拒绝”二选一，忽略现有连续正文已经写出第三种执行。
- 作者确认：**以现写版为准；原作本来也是这样写的。**
- 当前状态：CURRENT（主线事件结果）

### 现行事件链

`日本据点遭袭／Carillo 重伤 → 雷厉风阻止其亲返并派属下 → 属下先接触芷瞳、抓住并试图带走她 → 她询问“他呢”，听见他重伤且想回来接她，没有明确跟随也没有明确拒绝 → 巧芙向外部人员指出她也是受害者 → 外部力量利用属下不敢伤她的迟疑切断提取 → 芷瞳抱住巧芙，说“回家”`

### 版本裁决

| 结果 | 当前状态 | 作用 |
|---|---|---|
| 现写／原作母版：属下接触但提取失败，外部切断 | CURRENT（主线） | 保留外部制度破局、她当时的低行动力、对 Carillo 的真实牵扯，以及获救后才落下的“回家” |
| 纯 B：警方先到，属下没有接触她 | ALT | 更纯粹的制度救援实验，但会删去重伤欲返消息与提取失败现场 |
| 纯 C：属下找到，她当面明确拒绝 | ALT | 显性主体拒绝实验，但会把台湾三年才逐步重建的判断提前压入危机瞬间 |
| A：属下成功带回 | 黑暗 IF 上游 CURRENT／主线非采用 | 重新奖励“不接受失去”，可下游进入不分离或生殖绑定 |

这项裁决不把现写版称为 B／C 混合。它有独立的动作因果和人物功能：旧系统已经碰到她，却第一次没能把她带回去；她得到的是重新形成选择能力的外部条件，而不是在枪火中突然完成全部主体判断。
