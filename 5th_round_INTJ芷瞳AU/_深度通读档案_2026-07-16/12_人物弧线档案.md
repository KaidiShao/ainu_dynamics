# 12｜人物弧线档案

> 范围：`5th_round_INTJ芷瞳AU`。本档案把“共同前史／主线现行候选／事件路线变体／完整 IF”分栏记录；人物在不同路线里的状态不得互相回填。  
> 采用原则：正文行为证据高于讨论推论；后版只有在明确修订、连续承接或总纲确认时才覆盖前版；不同视角不自动构成冲突。

## 1. 芷瞳

### 1.1 不随路线改变的核心

| 维度 | 稳定内核 | 写作限制 |
|---|---|---|
| 认知 | 高密度观察、结构化推理、先收集变量再下判断；并非全知 | 不把她写成替作者解释世界的旁白；分析必须有感官、动作和误差成本 |
| 防御 | 在高压中压低可见反应，以顺从外形换取信息与生存余地 | `不拒绝`、`保持平静`、`接受照顾`均不等于同意或原谅 |
| 主体性 | 不是靠公开反抗证明自己；她的主体性常在保留解释权、身体边界、工作与退出能力 | 不能用“她也有算计”抵消权力不对等，更不能把自保写成对等伤害 |
| 吸引 | 她确实被卡瑞洛的高密度注意、判断力、执行可靠性、感官强度与被看见感吸引 | 吸引是真的，但从来不是持续授权；`心甘情愿`只覆盖当时、当地、该事件 |
| 身体 | 身体会先于理论暴露恐惧、熟悉、欲望和损伤 | 身体记忆不能替代伦理判断；回握、靠近等主动证据须与僵住／未挣扎严格区分 |
| 长线命题 | 从“我能在系统中生存”走向“我有权决定是否进入、何时退出、怎样命名自己的人生” | 结局不能只给她更舒适的笼子，必须给可验证的选择与独立世界 |

### 1.2 共同前史至主线第五幕

| 阶段 | 外部状态 | 内部弧线 | 关键证据／不可误读点 |
|---|---|---|---|
| 拍卖—初入系统 | 被当作可交易对象带入卡瑞洛世界 | 迅速判断权力结构，暂借顺从外形保存信息和体力 | 拍卖并不因“保护动机”而失去暴力性质；雷的交易解释只能作背景分析 |
| 甜期／旅行前后 | 在注意、审美、保护与控制混合的关系里出现真实吸引 | 允许局部靠近，但不断校验对方是否把她当主体 | 甜并非自由证明；越是顺畅，越会遮住退出机制不存在的问题 |
| 报告—瓦雷斯—冷战 | 报告揭开权力事实；私人关系被制度现实击穿 | 从解释、试探、有限反击转向拒绝替系统自证 | 她不是因“误会”生气；核心是事实、选择权与解释权被控制 |
| 日本撤离 | 属下已接触并试图提取，外部力量利用其不敢伤她的迟疑切断控制 | 她当时仍被“他重伤还想回来接她”牵住，没有突然获得完整判断；获救后抱住巧芙说“回家”，先得到重建主体的外部条件 | 现写／原作母版为 CURRENT；纯警方先到、当面明确拒绝、属下成功带回是不同 ALT／IF 结果，不得倒灌 |
| 三年重建 | 台湾生活、学业／研究、身体训练、音乐呼吸与声音、语言、行动能力逐层恢复 | 从“能承受”转向“能生活、能表达、能拒绝、能再次判断” | 重建不是疗愈蒙太奇；顺序以身体与日常功能为底，再到语言、行动与学术身份 |
| 巴塞罗那—Luca 绑架 | 以独立学术身份进入公共世界，被旧权力余波重新卷入 | 她的能力已可见，但药物和系统风险证明能力不等于免疫 | 她问“是不是你的命令／为什么你以为我会满意”，把责任与欲望同时摆回他面前 |
| 意大利暂住／第五幕现有末端 | 被卡瑞洛亲自扣留，逐步争取房间、信息、日间行动边界 | 不急于和解；以日常边界测试“他是否能停止替她决定” | 包、通讯、安全消息、侧厅、外间、牧师、倾城事件都是可验证权力变化；尚不能称自由已归还 |

### 1.3 主线仍待完成的弧线

1. 她需要从“在别人给出的安全区内扩大行动”走向拥有真正退出选项。
2. 她的学术与工作线必须继续存在，不能在重逢后退化成关系观察员。
3. 她必须获得一场不以创伤解释为中心的主动选择：可以离开，也可以在离开能力成立后回来。
4. 若写亲密恢复，正文证据必须是她能说“不”、对方会停，以及她在此条件下的明确主动；不能用冻住、流泪、睡着或未推开代替。

### 1.4 无孩子 IF

|---|---|---|

## 2. Carillo／Marcello

### 2.1 核心矛盾

| 表层能力 | 深层缺口 | 关系后果 |
|---|---|---|
| 高执行力、风险判断、资源调动与保护能力 | 把可控性误当安全，把观察到的顺从误当意愿 | 越想确认对方不会离开，越摧毁“留下”作为爱的证据价值 |
| 能准确看见他人细节 | 不愿承担对方真实拒绝带来的不确定性 | `看见`若不伴随停止伤害，只会成为更精密的控制 |
| 私人情感真实且强烈 | 容易把真实感情当作越权许可 | 爱与伤害可同时真实；前者不能抵销后者 |
| 家主／系统负责人 | 私人自我长期被 `Carillo` 姓氏吞没 | `Marcello` 私名只有在不再把家庭语言当控制工具后才可能恢复 |

### 2.2 主线弧线

| 阶段 | 他相信什么 | 发生了什么 | 应有推进 |
|---|---|---|---|
| 初期占有 | 拿到、保护、安排即可形成稳定 | 芷瞳在规则内生存并产生真实吸引，使他误把适应当接受 | 从兴趣／审美／保护欲进入依赖，却未理解许可边界 |
| 甜期 | 她的靠近证明系统有效 | 关系越顺，他越依赖可控环境制造的证据 | 甜期必须埋入不稳定性，而不是证明双方已经平等 |
| 报告与瓦雷斯 | 事实、资源和命令能修复裂缝 | 制度真相与他的现实控制让私人关系破裂 | 先承认不是沟通失败，而是权力行为本身造成伤害 |
| 冷战 | 仍试图通过信息、空间、命令降低不确定 | 她越来越安静，证据价值越来越低 | 从“她是否还在”转向“她是否有能力离开” |
| 日本与三年分离 | 失去她后仍想通过远距信息保持稳定 | 她重建，而他只能承受没有回报的等待与系统责任 | 不追、不索取回应、不把后悔表演给她看；处理旧系统而非只惩罚自己 |
| Luca 事件与第五幕 | 旧系统仍能伤及她，他仍本能地先扣留再处理 | 他承认责任，减少触碰，逐步给局部边界，但尚未归还退出权 | 现阶段不是“已经学会尊重”，而是控制方式开始失效、学习开始可见 |
| 终点条件 | — | — | 他必须允许她离开，并不把承诺当证据；只有自由后的回返才可能重建关系 |

### 2.3 无孩子 IF

数日持续越界是主线伦理阈值的极端化。他的最小弧线不是“因为爱所以失控”，而是终于看见：继续留住她等于毁掉她。他停止并释放她只能算停止加害，不能算赎罪完成。后续旧案、黑夜系统或远距等待要写的是他如何放弃全能控制，而不是如何用受苦换回她。

### 2.4 有孩子 IF

| 阶段 | 人物状态 | 有效成长证据 | 无效／危险写法 |
|---|---|---|---|
| 强迫形成孩子 | 把不可逆孩子想象成不会消失的关系支架 | 暂无；愿望“只想与她有孩子”只能说明欲望专一，不能减轻强迫 | 用深情、失控、继承压力或父爱抵销生殖暴力 |

| 女儿知情 | Alba 不再接受家主叙事；他的私名和父亲位置都被重新审视 | 接受女儿边界，不让她负责修复父母 | 让女儿的理解成为他的无罪证明 |

| 主动回归与修复（CURRENT 离散样本） | 她回来后，他仍须承认旧事错误且选择可撤回 | 不阻止再次离开；把房间、资产、名字和身体边界还给她 | 把 `夫人`、婚姻、私名、身体熟悉写成自动同意 |

## 3. Alba／知遥

### 3.1 角色定位

Alba 是有孩子 IF 才存在的下一代主体。她同时继承 Carillo 家族资源、父亲的制度性冷静、母亲的观察与命名能力，也承受一个被刻意做成“正常家庭”的起源秘密。她不是主线角色，也不能被反向投射进无孩子 IF。

### 3.2 成长弧线

| 年龄／阶段 | 她知道什么 | 她如何行动 | 对父母弧线的作用 |
|---|---|---|---|
| 幼年 | 先体验真实照料、分房家庭、父母之间的缺口 | 以名字、生日、语言和日常问题寻找家庭形状 | 让幻影家庭变得真实可爱，也因此使结构性缺口更痛 |
| 童年中文学习阶段（具体年龄未锁） | 感知母亲的研究世界、父亲的家主语言、称呼与空间不对称 | 主动索要中文名字；`知遥`由母亲提供来处，父亲暂不进入这一命名层 | 命名成为母女共同主体空间，不是父亲赐予；不可把低维流形稿的七八岁移植成问名年龄 |
| 9—15岁线索累积 | 从9岁路线审批、11岁名字（仅工作锚，问名年龄未锁）、13岁父母距离、14岁后比较，到15岁婚礼空白，逐层看见`夫人`、母亲房间与外部关系的不一致 | 从零散提问进入证据链，不因一条拍卖信息立刻全知 | 必须保留认知渐进，避免工具化侦探儿童 |
| 16岁以上真相／撤离期 | 触及台湾与拍卖真相，知道父母“妻子／婚姻故事”与母亲有家内实权却无最终退出权的冲突 | 直接询问母亲、设边界并制定撤离计划；实际取得同意和撤离过程仍待写 | 她推动结构显形，但不替母亲决定；撤离后可回意大利继续学校与人生 |
| 分离后 | 父母成为两个独立生活主体 | 在两边保有女儿身份，也容许普通亲子摩擦 | 她的幸福不依赖父母复合；家庭可重新定义而非必须复原 |

### 3.3 Alba 写作红线

- 不能把她写成比所有成年人都成熟的调解者。
- 她可以理解父亲，不等于替父亲辩护；可以爱父亲，也可以拒绝他的家庭叙事。
- 她陪母亲离开是一段行动，不是母女永久绑定；她需要返回自己的学校、朋友与成长线。
- 中文名`知遥`本身，以及“芷瞳早已在心中留名、女儿后来主动问出”是当前最稳口径；具体提出年龄、Alba出生名由谁执行、何时登记／公开使用、姓氏与意大利法域仍未锁定。
- 她的存在不能成为“强迫最终创造了值得的家庭”的论证。

## 6. 东方倾城

她连接雷、外部家族／社会关系与第五幕的现实后果。主线第五幕的昏迷、醒来、森林等多视角属于同一事件族的不同切面，不自动构成 IF。她的重要性在于：迫使卡瑞洛与芷瞳的私人关系重新进入有人受伤、有人作证、有人拥有自己利益的公共世界，阻止第五幕缩成封闭双人疗愈室。

## 7. Pastor

Pastor 是制度内部的边界见证者，不是道德裁判或代言作者。第五幕 `Pastor v12` 的价值在于让命令、房间、守卫与责任能被第三方看见；他可以执行、迟疑、调整，但不能替卡瑞洛完成尊重，也不能替芷瞳判定安全。

## 9. 芷瞳父母

父母线目前最大问题不是人格，而是**知情阶段不统一**：有材料显示他们已从巧芙处知道危险／控制碎片，另一些场景仍把事件当普通情侣或夫妻矛盾。可采用四段知情矩阵：

1. 只知道女儿长期在海外且关系不透明；
2. 从巧芙或间接渠道知道存在控制风险，但不知道拍卖和生殖事实；
3. 得知部分旧案／拍卖／无退出权，开始改写对“婚姻”的理解；
4. 是否知道身体与生殖细节，必须由芷瞳决定，不自动从 Alba 或第三方处获得。

父母提供的应是有限、笨拙但可回到的普通家庭，不是突然具备专业创伤语言的完美支持系统。

## 13. 写作时的人物弧线快速检查

- 本场人物知道什么？是亲历、被告知，还是理论推断？
- 本场人物是否拥有说不、离开、改变话题或保留沉默的真实能力？
- 某个动作是主动趋近，还是冻结、礼貌、习惯、体力不支或减少冲突？
- 本场属于共同前史、主线、完整 IF、事件变体，还是场景试写？是否误借了别线结果？
- 配角是否拥有自己的风险、利益和信息盲区，还是只替主角递答案？
- Alba 是否被成人化？巧芙是否被全能化？Pastor 是否被道德代言化？Luca 是否被工具化？
- Marcello 的“理解”是否落实为停止、归还边界和承担后果，而非更精确地解释芷瞳？
- 芷瞳的独立世界是否仍在：研究、语言、朋友、身体、空间和可支配资源至少要有一项在场。
