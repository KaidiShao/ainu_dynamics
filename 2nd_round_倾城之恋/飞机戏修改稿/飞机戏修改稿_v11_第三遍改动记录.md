## 2026-04-15

### 第一段：去掉两处批注感较重的连接句

#### 改动 1

原句：

```md
可真正让他没有立刻收回视线的，并不是这份安静。
```

现改为：

```md
雷厉风却没立刻收回视线。
```

改动意图：
- 去掉“作者先下判断再解释”的批注腔
- 改成更贴镜头、贴人物注意力的推进
- 保留原有节奏，不改段落功能

当前判断：
- 改后更自然
- 第一段的镜头主权更稳

#### 改动 2

原句：

```md
他抬手碰了碰自己的颈侧。那道伤还在隐隐发热。几个小时前，她回身出手时没有半分迟疑，那一下太快，也太利落，直到现在还留在他身上。正因为如此，眼前这张安静得近乎无害的脸，反倒更叫人不能轻慢。她睡着了，那股锋利却像还留在这里，连同那双不躲不让的眼睛，一起停在他记忆里。
```

现改为：

```md
他抬手碰了碰自己的颈侧。那道伤还在隐隐发热。几个小时前，她回身出手时没有半分迟疑，那一下太快，也太利落，直到现在还留在他身上。如今她睡着了，这张脸安静得近乎无害，反倒更叫人不能轻慢。那股锋利却像还留在这里，连同那双不躲不让的眼睛，一起停在他记忆里。
```

改动意图：
- 去掉 `正因为如此` 这种解释性连接
- 把“伤口记忆”和“眼前安静”改成自然并置
- 保留第一段的核心逻辑：
  - 伤口是引信
  - 眼睛是余震

当前判断：
- 段落更顺
- 说明感下降
- 第一段整体暂时可视为低优先级区域

### 第二段：去掉解释性口气说明，收紧卡瑞洛与雷厉风的判断

- 去掉 `这话不全是推让` 这种替读者做阅读理解的句子

当前判断：

- 关系信息没有丢
- 比原版本更顺、更贴人物

#### 改动 2

改动意图：
- 删掉 `没有立刻接话 / 停了半拍` 的重复表达

当前判断：
- 第二段明显更利落

### 第五段：去掉重复停顿，收紧雷厉风的“接手”口气

补充微调：

原句：

```md
机舱里一时没有人接话。

雷厉风没有立刻接话。

他先看了东方倾城一眼。话说到这里，他心里那点本就不愿她再经别人手的念头，终于有了一个可以明着落成安排的理由。

“到瓦雷斯以前，”他终于开口，语气仍旧平稳，“人先放在我这边。”

他顿了一下，才又淡淡补上：

“下去以后，我会先把她安置好。她醒过来之前，让你照看。”
```

现改为：

```md
机舱里一时没有人接话。

雷厉风先看了东方倾城一眼。话说到这里，他心里那点本就不愿她再经别人手的念头，终于有了一个可以明着落成安排的理由。

“到瓦雷斯以前，人先放在我这边。”

他顿了顿。

“下去以后，我先把她带到我那边。她醒过来之前，你照看。”
```

原因：
- 去掉 `机舱里一时没有人接话 / 雷厉风没有立刻接话` 的重复停顿
- 把雷厉风前半的接手动作写得更利落
- 将 `安置好` 改为 `带到我那边`，减少正常照顾感，增强“接到自己手里”的黑感

### 第六段：删去结尾总结句，保留冷场本身

补充微调：

原句：


原因：
- 保留真正刺中芷瞳的原话本身
- 去掉“侥幸”这个不准确的概括词
- 把伤点改清楚：不是她笃定自己特殊，而是那点不敢细想的“也许总归不同”被压掉了

补充微调：

原句：

```md
现在他这样看着她，她甚至不知道自己还能把话说到哪里。

芷瞳没有立刻抬头。后怕、难堪，还有那点刚被压下去又翻起来的受伤一起堵在胸口。可压在毛毯边上的手还没有松开。

她不是不想把话收回去，只是已经说到这里，再往回缩，等到了瓦雷斯，东方倾城后面要受的，就不会只停在这一层毛毯和一句“处理”上了。

这句话一出口，她只能先把那点刚被刺出来的受伤压住。别的都还可以往后放，唯独这一下，她没法把自己当成全然不在其中。
```

原因：
- 把芷瞳这段从“解释自己为什么不退”收成更承受型、低位型的语言
- 少用偏硬的动作词，多写她明明想缩回去、却没有完全缩回去
- 让她的主体性更像“我没法不”，而不是“我要去拦”
- 并把她真正担心的内容写得更具体：她怕的不是抽象“后面更糟”，而是到了瓦雷斯之后，这件事不会只停在现在这一层毛毯和一句“处理”上
