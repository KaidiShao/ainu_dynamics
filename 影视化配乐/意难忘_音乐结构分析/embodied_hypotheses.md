# 具身情绪机制：从声音变化到可检验假设

本文件在音频计算分析与候选复查之后形成。**没有收集本曲的独立听感、身体位置或生理数据；没有证实本曲通过特定音符激活特定身体部位。** 关于动机身份与和声的未决项见 [motif_analysis.md](motif_analysis.md)。

## 1. 先回答核心问题：重复为什么可能没有变成麻木

目前不能把“没有麻木”当成全体听众的既成事实。它首先是用户的体验。录音给出的可检验线索是：多处重复保持了时间轨迹，同时改变了能量、频谱和低频语境；同一轮材料的后续也不完全一样。

因此至少要分开三个过程：

- **再认出**：相同材料让人知道“这句回来过”。
- **更新预期**：此次低音、包络或接续不同，使“接下来会怎样”并非完全固定。
- **体验的历史依赖**：相同声音出现在已经经历过几轮推进和回落之后，可能不再等同于第一次听见。

这些是竞争性且可能共存的 L3 假设，不是本次分析证实的机制。甚至完全相同的片段也可能因为熟悉、注意和记忆改变体验；反过来，变形也可能让人疲劳或失去辨认感。

## 3. “紧张、沉重、扩张、悬置、释放”应怎样具体化

这些词可以作为用户自选的描述，不能直接由一个音频指标输出。

- **紧张/悬置**：优先问“是否预期下一事件出现”“它是否出现”，再问紧张；不要把高谱质心直接命名为紧张。
- **沉重**：同时记录低频体验、音量和叙事联想。04:12.5 后低频比例较高是候选线索，但其成因也可能是其他频带被撤去。
- **扩张/包裹**：需要试听声场，并控制设备和播放位置。side/mid 数据不能单独证明空间感，更不能证明身体扩张。
- **释放**：至少区分能量变小、句法完成、情绪松动三件事。05:44.6 后只有第一件获得强声学证据；后两件仍待听辨和主观记录。

如用户原先感受到身体位置依次变化，应先保留未经分析标签污染的记录。之后再问这些变化是否靠近 M4 各轮、M5 后的收缩或 M6 的回返；不要倒过来先指定哪些位置“应该”动。

## 4. 哪种音乐因素最重要：现有数据无法排序因果

录音中的旋律、低频、起音、动态和混音常常共同变化，本次只有一个完成的混音版本，不能独立估计各因素贡献。可以提出如下优先级，而不是因果排名：

1. **M1–M3** 适合研究材料再认出与句组预测，因为上层和低频较稳定。
2. **M4** 适合研究同族材料与音响条件交互，但必须先确认旋律身份；不能把弱成员当作已知同一动机。
3. **M5** 适合研究上下文，因为相近片段后接向不同的大段落后果。
4. **M6** 适合研究弱声量中的背景重释，因为并未继续增响。

这些位置的用途不同。不存在一张从 RMS、质心、chroma 自动合成的“情绪浓度曲线”。

## 5. 必须保留的替代解释

| 替代解释 | 怎样控制或记录 |
| --- | --- |
| 声量变化本身，而非旋律变形 | 保留原始版本，再做整体或片段感知响度匹配；匹配会改变艺术曲线，不能只保留匹配版 |
| 已熟悉作品，记得即将来临的段落 | 记录熟悉度和当天已听次数；区分本轮学到的预测与长期记忆 |
| 曲名、影视剧情或《爱奴》的联想 | 第一轮不呈现剧情和分析标签；另轮才加入场景，比较差别 |
| 阅读本报告导致期待与身体定位暗示 | 先完整盲听并封存记录；之后才展开候选表 |
| 听音设备、房间低频、耳机贴合 | 固定设备和音量，另日重复；需要时再换设备，避免把振动差异误作普遍音乐机制 |
| 疲劳、姿势、呼吸和当日状态 | 简短记录，不把所有身体变化归因于音乐 |
| 回忆性叙事与反应延迟 | 播放后复述可能把体验串成更整齐的顺序；同时保留少量即时标记，但即时任务也会干扰聆听 |
| 单纯熟悉带来的喜欢，或刺激累积 | 在原创样本中比较完全重复、单变量变化与顺序打乱；不能仅比较第一次和最后一次 |
| 算法误把伴奏当旋律 | 先做独立结构听辨；若身份不成立，撤回对应的动机机制解释 |

## 6. 最小研究流程

### 第一步：先取得独立记录

使用本地试听页，先整曲播放，候选面板保持收起。不要在播放前填任何身体部位。记录：时间或时间范围、实际体验、位置（自由描述，可空）、强度、是否确信、当时预期、设备/音量、熟悉度、状态。允许“无感觉”“只觉得好听”“疲劳”“无法定位”。

单次聆听不建议同时连续评分多个维度。可以先听后记录，再针对自行标出的时段复听；若用即时标记，单独记录该任务可能改变注意。

### 第二步：另一日重复，不先看上次记录

检查体验时间顺序是否保留，而不是要求位置、强度逐秒完全一致。报告自发记录的时间误差；不要为了让身体变化对齐动机，任意移动感受时间。反应时可做多个合理偏移的敏感性检查，但必须说明这是事后探索。

### 第三步：独立进行音乐听辨

确认 M1–M6 哪些确属旋律重复、哪些是共享伴奏。身体体验记录与结构标注由不同轮次完成。若条件允许，请另一位听者只做结构标注，不告诉其身体假设。

### 第四步：用原创受控样本检验因果

这次不生成配乐。后续可制作同一原创短动机的等时长版本：完全重复、只换低频声部、只换接续时值、只改织体、只改变前文顺序。每次实验先改一个变量，之后才比较组合变化。用中性编号、平衡顺序，保留音量/音色对照。

本曲的片段比较用于提出问题，不适合单凭原混音裁切来声称已分离旋律与和声因果。HPSS 也没有提供可靠的旋律和低音独立音轨。

### 第五步：判断能否转为影视语言

加入对白和真实环境声后重新评估。若只有专注戴耳机聆听时有效，而对白一进入便失去身份，尚不算合格的影视主导动机。也要保留“完全无配乐”的场景版本。

单一用户的结果可服务个人创作，不推出群体普遍机制。没有身体反应不算失败；细微、稳定、适合剧情的变化同样有价值。

## 7. 相关研究支持什么，不支持什么

以下只提供一般研究背景，不用于补写本曲缺失的和声或听辨事实。

- **Gold 等（2019）**使用音乐期待模型研究可预测性、不确定性与喜欢程度，并包含重复呈现；其结果支持把预测与学习作为可检验变量，不能直接推出本曲的悲痛或身体顺序。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6867811/)，DOI：10.1523/JNEUROSCI.0428-19.2019。
- **Salimpoor 等（2011）**在特定强烈愉悦音乐反应条件下，区分了期待与高峰体验相关的神经活动。这不是“任何动机重复都释放多巴胺”的证据，也不能解释某位听众的指定身体部位。[原始研究](https://www.nature.com/articles/nn.2726)，DOI：10.1038/nn.2726。
- **Putkinen 等（2024）**用音乐片段与身体自报告图，在所研究的西方及东亚样本中发现音乐特征、情绪评价和身体感受之间的关联。该设计主要比较片段及群体图样，并未验证一首曲子内部某个动机按时间依次激活身体位置；自报告也不等于器官活动测量。[作者机构提供的全文](https://emotion.utu.fi/wp-content/uploads/2023/02/Putkinen_et_al_23.pdf)，DOI：10.1073/pnas.2308859121。

这些研究使问题值得检验，但**本曲的具体机制仍须由本曲的声音证据、独立体验记录和控制实验共同支持**。
