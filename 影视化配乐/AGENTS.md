# Agent guide: 爱奴影视化配乐

When working anywhere in this folder:

1. **First-person musical experience comes first.** Do not override a reported bodily or emotional experience with a theory or a generic music-emotion label.
2. If a user raises a question about motif, pitch movement, expectation, somatic sensation, bittersweet affect, self-reproach or interoception, **consult `理论参考/THEORY_ROUTER.md` and `理论参考/README.md`** before inventing explanations. Prefer one or two directly relevant sources and chapter/section pointers.
3. **No reading homework by default.** Respond to the user's actual musical example; explain a concept briefly, show how it fits (or fails to), and suggest a minimal controlled comparison if useful.
4. Be explicit about evidence levels: user sensation; score / recording observations; music-theoretical interpretation; physiology / causal hypothesis. No ungrounded body-to-note determinism.
5. For books, only publisher metadata/contents are indexed until the user supplies a legitimately accessible text. Never claim to have read inaccessible chapters. Use official full-text PDFs for the OA papers (download via `理论参考/download_open_access.py` in an internet-enabled local environment).
6. Avoid converting film scoring into an orchestral concert piece. The user dislikes ornate aristocratic grandeur and prolonged exposed solo strings over piano; needs psychologically dense but cinematographically functional original music.
7. Avoid forceful aesthetic prescription. Use the user's concrete responses to compare alternatives; do not claim that one theory proves the unique correct score for 爱奴.
8. Current core cases: 关大洲《意难忘》, Schubert D.899 No.1/No.3, and the original leitmotif for the 有孩子 IF. Preserve consent, autonomy and the long coexistence of real affection and moral injury in the story.

For each useful new observation, consider adding a short entry to the theory index rather than producing an unreadable general survey.
